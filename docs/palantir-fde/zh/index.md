# Palantir FDE 工程师培训指南

> Frontend Development Engineer 入门与进阶
> 面向希望在 Palantir 平台进行前端开发的工程师

---

## 课程简介

**FDE（Frontend Development Engineer）** 是 Palantir 的核心工程角色之一，专注于在 Palantir 平台上构建面向业务用户的数据驱动应用。

与传统的 Web 前端开发不同，Palantir FDE 的工作核心是：
- 在 **Foundry** 平台上构建交互式数据应用
- 通过 **Ontology（本体）** 将数据转化为业务对象
- 使用 **Template Builder** 和 **React/TypeScript** 开发自定义 UI
- 借助 **AIP（AI Platform）** 集成 AI 能力

### 学完你能做到什么？

- ✅ 理解 Palantir Foundry 平台架构与核心概念
- ✅ 掌握 TypeScript + React 在 Foundry 中的应用模式
- ✅ 能够设计和实现 Ontology 本体模型
- ✅ 使用 Template Builder 快速构建业务面板
- ✅ 开发自定义 React 组件和模板
- ✅ 使用 AIP 构建 AI 驱动的应用
- ✅ 独立完成从 Ontology 设计到应用部署的全流程

## 课程结构

本课程共 **5 个模块**，约 **13 节课 + 3 个实战项目**：

| 模块 | 内容 | 预计时长 |
|------|------|----------|
| 模块一 | 认识 FDE | 30 分钟 |
| 模块二 | 前端基础巩固 | 60 分钟 |
| 模块三 | Foundry 应用开发 | 75 分钟 |
| 模块四 | AIP 与高级特性 | 45 分钟 |
| 模块五 | 实战项目 | 90 分钟 |

**总计约 5-6 小时**，学完即可独立开展 Foundry 前端开发工作。
