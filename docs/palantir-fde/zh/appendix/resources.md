## 推荐入门顺序

```
1. 注册 Palantir 账号（试用版或企业版）
2. 浏览 Foundry 文档，理解核心概念
3. 在 Demo 环境中动手操作
4. 学习 TypeScript + React 在 Foundry 中的应用
5. 尝试构建第一个 Template
6. 学习 AIP Agent 开发
```
