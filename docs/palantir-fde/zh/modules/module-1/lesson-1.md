## 一、FDE 在 Palantir 的位置

### 1.1 什么是 FDE？

**FDE = Frontend Development Engineer（前端开发工程师）**

在 Palantir，FDE 是一个独特的角色——它不是传统意义上的"做页面"的前端工程师，而是**构建数据驱动业务应用的平台工程师**。

```
Palantir 核心工程角色对比：
┌─────────────────────────────────────────────────────────────┐
│  角色          │  主要职责                              │
├─────────────────────────────────────────────────────────────┤
│  FDE           │  在 Foundry 上构建前端应用和 UI       │
│  BE（后端）     │  数据管道、API、ETL                    │
│  DS（数据科学家）│  建模、分析、算法                      │
│  PO（产品顾问）  │  客户需求分析、方案设计               │
│  OT（运营技术）  │  平台运维、部署、监控                 │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 FDE 的核心价值

FDE 是 Palantir 产品交付的**关键桥梁**：

```
数据（Foundry） → FDE 构建应用 → 业务用户操作决策
     ↑__________________________________↓
              反馈与迭代
```

- **对客户**：FDE 构建的应用是客户日常使用的工具
- **对平台**：FDE 反馈需求，推动 Foundry/AIP 平台持续进化
- **对业务**：FDE 开发的应用直接产生商业价值

## 二、FDE 的日常工作

### 典型工作日

```
上午：
  - 站会同步进度
  - Code Review 同事的模板/组件
  - 开发新的 Ontology 操作或 React 组件

下午：
  - 与客户工程师对接需求
  - 调试复杂的数据可视化问题
  - 编写技术文档

不定期：
  - 参与客户现场部署和培训
  - 内部技术分享
  - 平台功能改进建议
```

### 主要工作内容

| 工作类型 | 说明 | 占比 |
|---------|------|------|
| **模板开发** | 用 Template Builder 或 React 构建业务面板 | 40% |
| **Ontology 建模** | 设计业务对象、操作、关系 | 25% |
| **数据可视化** | 图表、地图、流程图等 | 15% |
| **API 集成** | 连接 Foundry API、外部系统 | 10% |
| **代码审查** | Review 团队成员的代码 | 10% |

## 三、技能要求

### 必备技能

```
┌─────────────────────────────────────────┐
│         FDE 核心技能金字塔              │
├─────────────────────────────────────────┤
│         🥇 深度：平台架构               │
│        Ontology / AIP / Platform       │
├─────────────────────────────────────────┤
│        🥈 中坚：前端工程                 │
│    React / TypeScript / 组件库         │
├─────────────────────────────────────────┤
│       🥉 基础：通用前端能力             │
│  JavaScript / HTML/CSS / Git / API     │
└─────────────────────────────────────────┘
```

### 详细技能清单

**前端基础（必须熟练）：**
- TypeScript（类型系统、泛型、工具类型）
- React（Hooks、状态管理、性能优化）
- CSS（Flexbox、Grid、CSS Modules/Tailwind）
- 前端工程化（Webpack/Vite、测试、CI/CD）

**Palantir 平台（课程重点）：**
- Foundry 应用架构
- Ontology 本体建模
- Template Builder / TypeScript Templates
- AIP（AI Platform）基础
- Foundry API 集成

**软技能：**
- 与客户沟通需求的能力
- 将业务语言翻译为技术实现
- 技术文档写作

## 四、学习路径

### 阶段 1：基础巩固（1-2 周）

```
目标：确保前端基础扎实
- 复习 TypeScript 高级类型
- 巩固 React Hooks 模式
- 了解前端测试（Jest + React Testing Library）
```

### 阶段 2：平台入门（2-3 周）

```
目标：理解 Foundry 核心概念
- 学习 Foundry 平台架构
- 掌握 Ontology 建模基础
- 学会使用 Template Builder
```

### 阶段 3：应用开发（3-4 周）

```
目标：能够独立开发 Foundry 应用
- 自定义 React 模板开发
- Ontology 操作实现
- 数据可视化组件
```

### 阶段 4：高级进阶（持续）

```
目标：掌握 AIP 和平台高级特性
- AIP Agent 开发
- Ontology API 深度使用
- 性能优化与最佳实践
```
