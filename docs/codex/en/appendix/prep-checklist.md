# Pre-course Checklist

> 📌 Before you start learning, please make sure you have prepared the following items.

---

## I. Account Preparation

- [ ] **ChatGPT Account**
  - Registration URL: https://chatgpt.com
  - Recommended version: Plus ($20/month) or Pro ($200/month)
  - Free version works too, but has limited quota

- [ ] **Email Verification**
  - Make sure your registered email has been verified
  - Check your spam folder to confirm the verification email was received

---

## II. Device Preparation

- [ ] **Computer Operating System**
  - macOS users: macOS 12.0 or later
  - Windows users: Windows 10 or later
  - Chromebook users: Chrome OS supported

- [ ] **Browser**
  - Recommended: Latest version of Chrome, Edge, or Firefox
  - Make sure your browser is updated to the latest version

- [ ] **Storage Space**
  - Reserve at least 500MB for installation and cache

---

## III. Network Environment

- [ ] **Stable Internet Connection**
  - Recommended broadband speed: 50Mbps or higher
  - If using WiFi, ensure good signal strength
  - Avoid using on public WiFi (may affect connection stability)

---

## IV. Practice Materials

- [ ] **A Folder to Organize**
  - Create a folder named "Codex Practice" on your desktop
  - Put some different types of files in it for practice:
    - 2-3 text files (.txt)
    - 2-3 image files (.jpg or .png)
    - 1-2 PDF files
    - 1 Excel file (.xlsx)

- [ ] **A Notebook**
  - Record questions and solutions you encounter during learning
  - Record useful prompt templates you discover

---

## V. Mindset Preparation

- [ ] **Stay Curious** — Try different prompts and see what Codex can do
- [ ] **Don't Fear Mistakes** — Making mistakes is part of learning; learning to fix is more important than not making mistakes
- [ ] **Take It Step by Step** — Don't rush through each module; practice hands-on

---

## VI. Security Check

- [ ] **Back Up Important Files** — Backup before letting Codex operate on important files
- [ ] **Set Appropriate Permissions** — Beginners should use "Default Permission" mode
- [ ] **Don't Enter Sensitive Information** — Passwords, bank card numbers, etc. should never be entered to AI

---

## VII. All Set!

Once you've checked all the items above, you're ready to start Lesson 1!
