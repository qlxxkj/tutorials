# Lesson 10: Web Search & Research

> 📌 **Learning Objectives**: Learn to have Codex search the web for information and organize it into reports
> ⏱️ **Estimated Time**: 20 minutes
> 🎯 **Teaching Rhythm**: Explanation + hands-on practice

---

## I. Codex Can Search the Web

Codex has built-in web search capability. When you need the latest information, it can search the internet directly.

### When to Use Web Search?

| Scenario | Needs Internet? |
|----------|----------------|
| Answering general knowledge questions | ✅ Yes |
| Looking up the latest news | ✅ Yes |
| Finding product reviews | ✅ Yes |
| Answering programming technical questions | ✅ Yes |
| Analyzing local file content | ❌ No |

---

## II. Practice 1: Let Codex Research a Topic for You

### Task
Research "AI development trends in 2026."

### Steps

1. Open Codex
2. Type this command:
   ```
   Help me research the development trends in the AI field for 2026, including:
   - Latest progress in large language models
   - AI applications in office scenarios
   - Impact of AI on the job market
   Give 3 key points for each section, and cite the sources.
   ```
3. Codex will search the web for relevant information and organize it into a structured report.

### What You Might Get Back

```
📊 2026 AI Development Trends Research Report

I. Latest Progress in Large Models
1. Multimodal capabilities becoming standard... [Source: TechCrunch]
2. Open-source model performance improving rapidly... [Source: Hacker News]
3. ...

II. AI Applications in Office Scenarios
1. ...
2. ...
3. ...

III. Impact of AI on the Job Market
1. ...
2. ...
3. ...
```

---

## III. Practice 2: Let Codex Summarize a Long Article from the Web

### Task
You have a long article and want Codex to summarize the key points.

### Steps

1. Find a long article you'd like to read (e.g., a tech blog post).
2. Send the article link to Codex:
   ```
   Help me read this article https://example.com/article and summarize the 5 key points.
   ```
3. Codex will visit the webpage, extract the content, and generate a summary.

### Advanced Usage

```
Help me read this article, find all the tools/products mentioned, and briefly explain what they do.
```

```
Based on this article's content, write a recommendation post suitable for sharing on social media.
```

---

## IV. In-Lesson Practice Tasks

1. Use Codex to research a topic you're interested in (e.g., "best laptops for students 2026").
2. Save the generated report.
3. Try the advanced usage above with a real article URL.
