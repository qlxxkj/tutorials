
# Codex 从零到一

> 从零开始掌握 OpenAI Codex  
> 让 AI 帮你搞定编程与办公自动化

---

## 课程简介

Codex 是 OpenAI 推出的 AI 编程助手，能够理解你的需求并生成代码、调试错误、操作文件。无论你是程序员还是完全零基础，都能通过这门课学会如何用自然语言让 AI 成为你的编程搭档。

**核心能力：** 文件管理、代码生成、调试排错、技能系统、联网搜索

---

## 课程结构

| 模块 | 内容 | 时长 |

| 模块一 | 认识 Codex | 45 分钟 |
