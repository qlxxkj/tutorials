# 课前准备清单

> 📌 在开始学习之前，请确保你已经准备好以下内容。

---

## 一、账号准备

- [ ] **ChatGPT 账号**
  - 注册地址：https://chatgpt.com
  - 推荐版本：Plus（$20/月）或 Pro（$200/月）
  - 免费版也可以体验，但额度有限

- [ ] **邮箱验证**
  - 确保你的注册邮箱已完成验证
  - 检查垃圾邮件文件夹，确认验证邮件已收到

---

## 二、设备准备

- [ ] **电脑操作系统**
  - macOS 用户：macOS 12.0 及以上
  - Windows 用户：Windows 10 及以上
  - Chromebook 用户：支持 Chrome OS 即可

- [ ] **浏览器**
  - 推荐使用最新版 Chrome、Edge 或 Firefox
  - 确保浏览器已更新到最新版本

- [ ] **存储空间**
  - 至少预留 500MB 可用空间用于安装和缓存

---

## 三、网络环境

- [ ] **稳定的网络连接**
  - 建议宽带速度 50Mbps 以上
  - 如果使用 WiFi，确保信号强度良好
  - 避免在公共 WiFi 环境下使用（可能影响连接稳定性）

---

## 四、练习材料

- [ ] **一个待整理的文件夹**
  - 在桌面创建一个名为"Codex 练习"的文件夹
  - 在里面放入一些不同类型的文件用于练习：
    - 2-3 个文本文件（.txt）
    - 2-3 个图片文件（.jpg 或 .png）
    - 1-2 个 PDF 文件
    - 1 个 Excel 文件（.xlsx）

- [ ] **一个笔记本**
  - 记录你在学习过程中遇到的问题和解决方案
  - 记录你觉得有用的指令模板

---

## 五、心理准备

- [ ] **保持好奇心** — 多尝试不同的指令，看看 Codex 能做什么
- [ ] **不怕犯错** — 出错是学习的一部分，学会修正比不犯错更重要
- [ ] **循序渐进** — 不要急于求成，每个模块都要动手实操

---

## 六、安全检查

- [ ] **备份重要文件** — 在让 Codex 操作重要文件前，先做好备份
- [ ] **设置合适的权限** — 初学者建议使用"默认权限"模式
- [ ] **不输入敏感信息** — 密码、银行卡号等永远不要输入给 AI

---

## 七、准备完成

当你勾选了以上所有项目后，就可以开始学习第一课了！
