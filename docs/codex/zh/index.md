## 课程介绍

你有没有过这样的经历？

- 想写个小工具整理文件，但不知道怎么编程
- 需要做 PPT，花半天时间找素材、排版
- 想分析一堆数据，但 Excel 公式和搜索引擎都帮不上忙
- 听说 AI 能写代码、帮办公，但不知道从哪开始

如果你有任何一条共鸣，这门课就是为你准备的。

**Codex 是 OpenAI 的 AI 编程智能体。** 它不是简单的"聊天机器人"——它能读取你的项目、写代码、运行命令、调用工具，甚至帮你整理电脑文件夹、生成 PPT、做数据分析。

最重要的是：**你不需要会编程**。只要你能够正常说话，就能用 Codex 完成这些任务。

在 OpenAI 内部，律师用 Codex 整理合同条款，招聘人员用 Codex 筛选简历，运营人员用 Codex 制作数据报表。你也可以。
