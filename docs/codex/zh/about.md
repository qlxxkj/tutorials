# 关于课程

本课程面向零编程基础的职场人士和内容创作者，教大家如何使用 OpenAI 的 Codex —— 一个能读写文件、编写代码、运行命令、用自然语言自动化任务的 AI 编程智能体。

**无需编程基础。** 只要能够正常说话，就能用 Codex 完成实际任务。

## 课程内容

- **模块一：** 认识 Codex（3 课）
- **模块二：** 上手准备（4 课）
- **模块三：** 核心功能（4 课）
- **模块四：** 实用技巧（3 课）
- **模块五：** 项目实战（4 个项目）
- **模块六：** 总结与进阶（2 课）

## 你将学到

- 文件操作：整理文件夹、批量重命名、分类文件
- 自然语言编程：用大白话描述需求，让 Codex 生成代码
- 联网检索：让 Codex 搜索互联网并整理报告
- 自动化任务：让 Codex 处理重复性工作
- 技能调用：使用内置技能完成复杂任务（比如生成 PPT）

## 适合人群

- 零编程基础的职场人士
- 想自动化工作流的创作者
- 任何希望利用 AI 提升效率的人

---

## 课程定位

面向零编程基础的职场人士和内容创作者，让学员理解 Codex 是什么、能做什么，并能独立用 Codex 完成实际任务。

## 课程目标

- 理解 AI 编程助手与聊天机器人的区别
- 掌握 Codex 的安装、登录和基本操作
- 能用自然语言指挥 Codex 完成文件操作、数据分析、网页生成等任务
- 独立完成 4 个实战项目
