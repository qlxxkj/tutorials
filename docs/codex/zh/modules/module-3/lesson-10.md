# 第 10 课：联网与资料检索

> 📌 **学习目标**：学会让 Codex 联网搜索信息并整理成报告  
> ⏱️ **预计时长**：20 分钟  
> 🎯 **本节节奏**：讲解 + 实操

---

## 一、Codex 可以联网搜索

Codex 内置了联网搜索功能。当你需要最新的信息时，它可以直接上网查找。

### 何时使用联网搜索？

| 场景 | 是否需要联网 |
|------|-------------|
| 回答常识性问题 | ✅ 是 |
| 查询最新新闻 | ✅ 是 |
| 查找产品评测 | ✅ 是 |
| 回答编程技术问题 | ✅ 是 |
| 分析本地文件内容 | ❌ 否 |

## 二、实操一：让 Codex 帮你调研某个话题

### 任务

调研"2026 年 AI 发展趋势"。

### 步骤

1. 打开 Codex
2. 输入指令：
   ```
   帮我调研一下 2026 年 AI 领域的发展趋势，包括：
   - 大模型的最新进展
   - AI 在办公场景的应用
   - AI 对就业市场的影响
   每部分给出 3 个要点，并注明信息来源
   ```
3. Codex 会联网搜索相关信息，整理成结构化的报告

### 你可能得到的结果

```
📊 2026 年 AI 发展趋势调研报告

一、大模型的最新进展
1. 多模态能力成为标配... [来源：TechCrunch]
2. 开源模型性能快速提升... [来源：Hacker News]
3. ...

二、AI 在办公场景的应用
1. ...
2. ...
3. ...

三、AI 对就业市场的影响
1. ...
2. ...
3. ...
```

## 三、实操二：让 Codex 根据网上资料生成一份总结报告

### 任务

你有一篇长文章，想让 Codex 帮你总结要点。

### 步骤

1. 找到一篇你想看的长文章（比如一篇技术博客）
2. 把文章链接发给 Codex：
   ```
   帮我阅读这篇文章 https://example.com/article，总结出 5 个核心观点
   ```
3. Codex 会访问该网页，提取内容，生成摘要

### 进阶用法

```
帮我阅读这篇文章，找出其中提到的所有工具/产品，并简要说明它们的用途
```

```
根据这篇文章的内容，写一份适合发在朋友圈的推荐文案"
