# 课程回顾与下一步

## 你学到的内容

| 模块 | 核心技能 |
|------|---------|
| 模块一 | AI 漫剧概念、流程、技术选型 |
| 模块二 | Python + FFmpeg 环境搭建、API 配置 |
| 模块三 | LLM 写剧本、正则解析分镜 |
| 模块四 | 角色参考图生成、Prompt 工程、批量出图 |
| 模块五 | TTS 配音、口型同步方案、FFmpeg 视频合成 |
| 模块六 | 完整流水线搭建 |

## 下一步可以做什么

### 短期（1-2 周）

- [ ] 用本课知识制作第一部完整漫剧
- [ ] 建立自己的 Prompt 模板库
- [ ] 尝试不同画风（水彩/赛博朋克/黑白 noir）
- [ ] 学习 FFmpeg 高级滤镜（转场、特效）

### 中期（1-2 月）

- [ ] 本地部署 Stable Diffusion，降低成本
- [ ] 搭建自动化的 CI/CD 流水线
- [ ] 尝试批量生产系列短剧
- [ ] 学习 SadTalker 本地口型同步

### 长期（持续）

- [ ] 探索多模态 AI 新能力（视频生成模型）
- [ ] 建立角色数据库和风格指南
- [ ] 研究平台算法，优化内容表现
- [ ] 将制作流程产品化/SaaS 化
