## 一、为什么 AI 漫剧需要特殊的剧本格式？

普通电影剧本只需要告诉演员和导演**"发生了什么"**。

AI 漫剧的剧本还需要告诉 AI **"画面长什么样"**——因为每一句描述都会直接影响图像生成和视频生成的结果。

一个合格的漫剧剧本，需要同时满足三个消费者：
1. **LLM**（写剧本时）——需要结构化输入才能输出高质量内容
2. **图像/视频生成模型**（生成分镜时）——需要具体的视觉描述
3. **TTS 系统**（配音时）——需要清晰的台词和角色标识

## 二、标准剧本格式

### 完整模板

```markdown
【第 N 集：集标题】

【场景 N - 地点·时间·光线】
镜头角度：[特写/近景/中景/全景/俯拍/仰拍/过肩]
画面描述：[具体的视觉描述，1-2句话，包含环境、人物动作、关键元素]
角色：[角色名]
情绪：[当前情绪状态]
对话/旁白："[台词内容]"
动作：[角色动作，可选]
```

### 逐字段说明

| 字段 | 必填 | 作用 | 示例 |
|------|------|------|------|
| **场景** | ✅ | 定义时空背景，影响画面整体氛围 | `室内·卧室·深夜·月光` |
| **镜头角度** | ✅ | 决定构图方式，直接影响画面张力 | `特写`、`俯拍`、`过肩` |
| **画面描述** | ✅ | AI 绘图的核心依据，越具体越好 | `窗帘微动，月光照在凌乱的床上` |
| **角色** | ✅ | 标识画面中出现的人物 | `小林（女，22岁）` |
| **情绪** | ✅ | 决定角色表情和整体色调 | `恐惧`、`释然`、`迷茫` |
| **对话/旁白** | 可选 | 配音的直接来源 | `"你到底是谁……"` |
| **动作** | 可选 | 补充角色行为，影响视频生成 | `缓缓起身，走向窗边` |

## 三、镜头角度详解

镜头角度决定了观众看到什么、看不到什么，是叙事的重要手段。

### 景别分类

| 景别 | 英文名 | 画面范围 | 叙事作用 |
|------|--------|---------|---------|
| **大特写** | Extreme Close-up | 眼睛、嘴唇等局部 | 强调情绪细节 |
| **特写** | Close-up | 脸部完整 | 表情、内心活动 |
| **近景** | Medium Close-up | 肩部以上 | 对话、情感交流 |
| **中景** | Medium Shot | 腰部以上 | 日常互动、动作 |
| **全景** | Wide Shot | 全身+环境 | 空间关系、位置 |
| **大远景** | Extreme Wide Shot | 人物很小，环境为主 | 氛围、孤独感 |

### 拍摄角度

| 角度 | 效果 | 适用场景 |
|------|------|---------|
| 平视 | 自然、客观 | 日常对话 |
| 俯拍 | 压抑、渺小 | 危险处境、孤独 |
| 仰拍 | 威严、压迫 | 反派登场、权力展示 |
| 过肩 | 对话相对感 | 两人对话 |
| 主观视角 | 代入感 | 角色所见所想 |

## 四、画面描述的写作原则

### 原则 1：可视化优先

描述必须是**能被画出来**的具体内容，不要抽象概念。

```
❌ 画面描述：房间里很压抑
✅ 画面描述：狭小的出租屋， walls 贴着泛黄的海报，桌上堆满泡面盒和空酒瓶，唯一的光源是电脑屏幕的蓝光
```

### 原则 2：光影即情绪

光线是营造氛围最经济的手段，善用光影描述可以节省大量文字。

```
场景格式建议：【场景 N - 地点·时间·光线】

光线关键词：
- 月光——清冷、孤独、神秘
- 霓虹——都市、浮躁、迷幻
- 顶光——压抑、审视
- 侧光——戏剧性、悬疑
- 背光——剪影、未知
- 柔光——温暖、回忆
```

### 原则 3：动静结合

剧本中的动作描述，既是给图像生成看的，也是给后续视频生成看的。好的动作描述能让视频片段更自然。

```
❌ 动作：他走过去开门
✅ 动作：他停下脚步，手悬在门把上犹豫了三秒，然后缓缓拧开
```

## 五、完整示例：悬疑短篇

```markdown
【第一集：深夜的访客】

【场景 1 - 室内·客厅·深夜·月光】
镜头角度：缓慢推进
画面描述：老旧公寓的客厅，窗外暴雨如注，桌上散落着空泡面盒和键盘，唯一光源是显示器的蓝光
角色：陈默（男，28岁，程序员，黑眼圈）
情绪：疲惫
旁白："又一个凌晨三点……还有最后一个 bug。"
动作：揉眼睛，打哈欠，看了眼墙上的钟

【场景 2 - 特写·电脑屏幕】
镜头角度：固定，屏幕轻微闪烁
画面描述：VS Code 编辑器，满屏红色报错信息，光标在最后一行不停闪烁
角色：无
情绪：焦虑
对话："到底哪里错了……再跑一次。"
动作：手指在键盘上飞快敲击

【场景 3 - 近景·陈默】
镜头角度：固定
画面描述：陈默凑近屏幕，瞳孔在镜片上反射出代码的光
角色：陈默
情绪：困惑
对话："这行代码明明没问题……"

【场景 4 - 特写·屏幕】
镜头角度：固定，画面轻微抖动
画面描述：屏幕突然闪了一下，黑色终端窗口弹出来，自动输入了一行字
角色：无
情绪：震惊
旁白："终端里浮现出一行不是自己敲的字——'你看到了吗？'"

【场景 5 - 近景·陈默】
镜头角度：手持晃动效果
画面描述：陈默猛地后仰，椅子发出刺耳的摩擦声，脸色瞬间苍白
角色：陈默
情绪：惊恐
对话："谁……谁在搞恶作剧？"
动作：慌乱地拔掉网线

【场景 6 - 全景·房间】
镜头角度：固定，光线骤暗
画面描述：整间公寓的灯同时熄灭，只有终端屏幕还亮着，字符一行一行浮现
角色：无
情绪：紧张
旁白："灯灭了，但屏幕上的字还在继续——'你就算拔掉网线，我也已经在里面了。'"

【场景 7 - 特写·终端】
镜头角度：固定
画面描述：屏幕上逐字打出新的内容
角色：无
情绪：恐惧
旁白："'别怕，我不是来害你的。我是你——三年后的你。'"

【场景 8 - 近景·陈默】
镜头角度：固定
画面描述：陈默颤抖着手重新插上网线，盯着屏幕，嘴唇发白
角色：陈默
情绪：震惊→好奇
对话："什么……什么意思？"

【场景 9 - 特写·屏幕】
镜头角度：固定
画面描述：光标闪烁，一行字慢慢出现
角色：无
情绪：悬念
旁白："'听我说，时间不多。你有七分钟。'"

【结尾字幕】
画面：黑屏
字幕："下集待续"
情绪：悬念
```

## 六、剧本格式的自动化解析

好的格式设计不仅方便人读，也方便机器解析。上面采用的格式可以用正则表达式稳定解析：

```python
# 场景标题匹配
re.match(r'【场景\s*(\d+)\s*-\s*(.+?)】', line)

# 字段匹配（支持中英文冒号）
re.match(r'(镜头角度|画面描述|角色|情绪)[：:]\s*(.+)', line)

# 对话匹配
re.match(r'(对话|旁白)[：:"\s]*(.+)', line)
```

这就是为什么格式必须规范——**规范的格式 = 可自动化的流程**。

## 七、随堂练习

选择一个故事想法，写出前 3 个场景的分镜剧本，注意：

1. 每个场景都包含所有必填字段
2. 画面描述不少于 20 字，具体到可见元素
3. 第 1 个场景的镜头角度要能"钩住"观众
4. 第 3 个场景末尾要有悬念或转折
