# 第 7 课：漫剧剧本格式

> 📌 **学习目标**：掌握 AI 漫剧剧本的标准格式，理解分镜标注的关键要素
> ⏱️ **预计时长**：20 分钟
> 🎯 **本节节奏**：格式规范 → 逐字段解析 → 实战示例

---

## 一、为什么需要专门的剧本格式？

普通剧本（电影/电视剧）关注的是**演员表演和对话**。

AI 漫剧的剧本需要额外告诉 AI：
- **画面长什么样**（场景描述、光线、构图）
- **镜头怎么移动**（特写/中景/全景）
- **角色什么表情**（情绪标记）
- **谁在说话**（角色标识）

这些信息直接决定了后续图像生成和配音的质量。

---

## 二、标准剧本格式

### 基本结构

```markdown
【第 N 集：集标题】

【场景 1 - 地点·时间】
镜头角度：xxx
画面描述：xxx
角色：xxx
情绪：xxx
对话/旁白："xxx"

【场景 2 - 地点·时间】
...
```

### 逐字段说明

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| **场景** | ✅ | 地点 + 时间 | `室内·办公室·白天` |
| **镜头角度** | ✅ | 景别和构图 | `中景`、`特写`、`俯拍` |
| **画面描述** | ✅ | 具体视觉内容 | `阳光从窗户斜射进来` |
| **角色** | ✅ | 出现在画面中的角色 | `小明`、`神秘人`、`无` |
| **情绪** | ✅ | 当前情绪状态 | `疲惫`、`震惊`、`恐惧` |
| **对话/旁白** | 可选 | 台词或叙述 | `"又一个深夜……"` |

---

## 三、镜头角度关键词

| 角度 | 英文名 | 适用场景 |
|------|--------|---------|
| 特写 | Close-up | 表情、细节、物品 |
| 近景 | Medium Close-up | 上半身、对话 |
| 中景 | Medium Shot | 全身 + 部分环境 |
| 全景 | Wide Shot | 环境全貌 |
| 俯拍 | Overhead | 上帝视角、地图 |
| 仰拍 | Low Angle | 威严、压迫感 |
| 过肩 | Over-the-Shoulder | 对话相对 |
| 侧拍 | Side Profile | 轮廓、剪影 |

## 四、完整示例

### 悬疑短篇《深夜访客》

```markdown
【第一集：深夜访客】

【场景 1 - 室内·客厅·夜】
镜头角度：缓慢推进
画面描述：灯光昏暗的客厅，窗外下着雨，桌上散落着空咖啡杯
角色：小明（男，25岁，程序员）
情绪：疲惫
旁白："又一个深夜，代码还没写完……"

【场景 2 - 特写·电脑屏幕】
镜头角度：固定
画面描述：发光的电脑屏幕，空白文档，光标不停闪烁
角色：无
情绪：焦虑
对话："还有三行……就三行……"

【场景 3 - 中景·小明】
镜头角度：固定
画面描述：小明揉了揉眼睛，打了个哈欠，看了眼时钟（显示 03:47）
角色：小明
情绪：困倦
对话："不行了，得睡觉了……明天再说。"

【场景 4 - 特写·屏幕】
镜头角度：固定，轻微抖动效果
画面描述：屏幕突然闪了一下，原本空白的文档出现了一行字
角色：无
情绪：震惊
旁白：屏幕上浮现出一行字——"你想不想看看另一个自己？"

【场景 5 - 近景·小明】
镜头角度：手持晃动效果
画面描述：小明瞪大眼睛，手在发抖，盯着屏幕
角色：小明
情绪：惊恐
对话："什么……这是什么意思？谁在恶作剧？"

【场景 6 - 全景·房间】
镜头角度：固定，光线骤暗
画面描述：房间灯光突然熄灭，只剩下屏幕的蓝光
角色：无
情绪：紧张
旁白：灯光熄灭了，整个房间陷入黑暗，只有屏幕还亮着……

【场景 7 - 特写·门】
镜头角度：固定
画面描述：房门缓缓自动打开，门口站着一个模糊的身影
角色：神秘人（轮廓不清，穿着和小明一样的卫衣）
情绪：恐惧
旁白：门开了，走进来的——是另一个他。

【结尾字幕】
画面：黑屏
字幕："下集待续"
情绪：悬念
```

## 五、剧本写作技巧

### 5.1 场景转换要清晰

每次场景变化都明确标注，不要让观众猜：

```
✅ 【场景 5 - 室外·街道·夜】
❌ （无标注，直接跳到下一个）
```

### 5.2 画面描述要"可视化"

描述要能让 AI 画出来，避免抽象概念：

```
✅ 画面描述：小明坐在桌前，双手抱头，屏幕上满是红色报错信息
❌ 画面描述：小明很沮丧
```

### 5.3 对话要简洁有力

漫剧单集时长有限，每句台词最好控制在 20 字以内：

```
✅ "代码还没写完……"
❌ "哎呀这个bug怎么修都修不好，感觉今晚又要在公司熬夜了，真的好累啊……"
```

### 5.4 情绪标记影响配音和画面

同样的台词，不同情绪生成的画面和语音完全不同：

```
【场景 A】
情绪：愤怒
对话："你滚！"

【场景 B】
情绪：悲伤
对话："你滚……"
```

## 六、随堂练习

尝试为以下故事开头写 3-5 个场景的分镜剧本：

> **故事开头**：一个快递员收到一个神秘包裹，拆开后发现里面是一面镜子，镜子里映出的不是他自己……

提示：
1. 给主角起个名字
2. 标注好场景、镜头角度、画面描述
3. 每个场景都要有情绪标记
4. 对话简洁
