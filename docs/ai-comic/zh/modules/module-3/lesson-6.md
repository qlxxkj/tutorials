# 第 6 课：角色设定与参考图

> 📌 **学习目标**：学会设定角色形象，生成并使用角色参考图
> ⏱️ **预计时长**：20 分钟
> 🎯 **本节节奏**：角色设计原则 → 参考图生成 → 保持一致性的技巧

---

## 一、角色设计三要素

一个好的漫剧角色需要三个层面的设计：

### 1. 外貌设计（让别人认得出）

```
核心原则：简洁、有记忆点
```

| 要素 | 设计建议 |
|------|---------|
| 发型 | 固定一种风格，不要频繁变更 |
| 配饰 | 眼镜、帽子、项链等有辨识度的单品 |
| 服装 | 确定主色调和风格（卫衣/西装/制服） |
| 体型 | 偏瘦/偏壮/中等，保持一致 |
| 面部特征 | 一个显著特征（痣/疤/特殊眼型） |

**示例**：
```
主角：陈默
- 黑色短发，略显凌乱
- 黑框眼镜（标志性配饰）
- 灰色连帽卫衣（固定服装）
- 偏瘦身材
- 眼下有淡淡的黑眼圈
```

### 2. 性格设计（让角色有灵魂）

```
用 3-5 个关键词概括：
```

```
陈默：内向、细心、有点焦虑、内心善良
```

性格会影响：
- 面对事件时的反应方式
- 说话的风格和用词
- 肢体语言和表情习惯

### 3. 声音设计（让角色能被"听"出来）

不同角色用不同音色，方便观众区分：

```
主角（陈默）：年轻男声，略带疲惫感
旁白：低沉男声，冷静客观
反派/神秘人：沙哑男声，有压迫感
女配角：明亮女声，温柔但坚定
```

## 二、生成角色参考图

### 什么是角色参考图？

角色参考图是一张"身份证"——它定义了角色的长相、发型、服装。后续所有分镜画面都会参考这张图，保证角色在不同镜头中保持一致。

### 用 AI 生成参考图

**步骤 1**：打开图像生成工具（即梦/可灵/Midjourney）

**步骤 2**：输入 Prompt

```
Character design reference sheet,
28-year-old Asian male, short messy black hair,
black rectangular glasses, grey hooded sweatshirt,
slim build, tired eyes with slight dark circles,
neutral expression, facing forward,
clean white background,
front view and side view,
anime style, cel shaded, vibrant colors,
high quality detailed illustration,
No text, no watermark
```

**步骤 3**：生成 4 张，挑选最满意的一张

**步骤 4**：保存为 `角色名.png`，放到项目的 `characters/` 文件夹

### 参考图的质量标准

- ✅ 正面全身照，背景干净
- ✅ 服装、发型清晰可见
- ✅ 表情中性（不要夸张情绪）
- ✅ 分辨率足够高（至少 1024x1024）
- ❌ 不要有文字、水印、杂物

## 三、保持角色一致性的技巧

这是 AI 漫剧制作中最难的部分。分享几个实用的方法：

### 方法 1：复用参考图（最简单）

每次生成新的分镜画面时，都把角色参考图作为参考输入：

```
工具操作：
即梦/可灵 → 上传参考图 → 输入分镜描述 → 生成
```

### 方法 2：在描述中重复关键特征

每次生成分镜画面时，Prompt 中都带上角色的核心特征：

```
❌ 差："一个男人在办公室里"
✅ 好："一个戴着黑框眼镜、穿灰色卫衣的年轻男人坐在办公室"
```

### 方法 3：固定 Seed 值

如果工具支持 seed 设置，给每个角色分配一个固定的 seed：

```
主角陈默：seed = 1001
女配小林：seed = 1002
```

相同 seed + 相似描述 → 相似角色。

### 方法 4：建立角色卡片

把每个角色的固定特征写成一个卡片，每次生成画面时复制粘贴：

```
【角色卡片：陈默】
- 年龄：28 岁
- 发型：黑色短发，略显凌乱
- 配饰：黑框眼镜
- 服装：灰色连帽卫衣，深色裤子
- 体型：偏瘦
- 特征：眼下有黑眼圈
- 种子值：1001
```

## 四、多角色管理

一部漫剧通常有 2-5 个主要角色。建议：

1. **先确定主要角色数量**，不要临时增加新角色
2. **每个角色一张参考图**，保存到统一目录
3. **角色卡片规范化**，方便后续复用
4. **配角可以模糊处理**（背影、剪影、远景），降低一致性压力

## 五、本章小结

| 要点 | 说明 |
|------|------|
| 角色设计 | 外貌 + 性格 + 声音，三层叠加 |
| 参考图 | 干净背景的正面全身照，中性表情 |
| 一致性 | 复用参考图 + 重复特征描述 + 固定 seed |
| 角色卡片 | 把固定特征写下来，每次生成时复制 |
