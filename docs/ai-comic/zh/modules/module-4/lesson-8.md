# 第 8 课：视频生成（多图参考）

> 📌 **学习目标**：学会用多图参考的视频生成工具，将静态分镜转化为动态视频片段
> ⏱️ **预计时长**：25 分钟
> 🎯 **本节节奏**：工具选择 → 操作步骤 → Prompt 技巧 → 片段拼接

---

## 一、为什么需要视频生成？

纯图片+配音的"幻灯片式"漫剧效果有限——画面是静止的，只有声音在动。

加上视频生成后：
- 人物会眨眼、转头、呼吸
- 头发会随风飘动
- 光影会微微变化
- 镜头可以有缓慢推进/拉远

观众沉浸感大幅提升，但**不是每个镜头都需要视频**。

## 三、哪些镜头需要生成视频？

不是每个分镜都要做视频，合理分配能节省大量成本：

| 镜头类型 | 是否生成视频 | 原因 |
|---------|------------|------|
| 特写表情 | ✅ 推荐 | 微表情增加代入感 |
| 对话场景 | ✅ 推荐 | 人物动作让对话更生动 |
| 情绪转折 | ✅ 推荐 | 动态增强冲击力 |
| 环境空镜 | ❌ 不需要 | 静态图即可 |
| 转场镜头 | ❌ 不需要 | 用剪辑转场效果替代 |
| 远景交代 | ⚠️ 可选 | 有动态更好，没有也行 |

**建议比例**：约 40-60% 的分镜生成视频。

## 四、操作步骤（以 Seedance 为例）

### Step 1：准备素材

你需要准备两张图：
1. **角色参考图**：之前生成的角色正面全身照
2. **分镜画面**：对应这个镜头的图片（如果没有可以先用 AI 生成静态图）

### Step 2：打开工具，选择"图生视频"

```
Seedance 2.0 → 选择"多图参考生成视频"模式
```

### Step 3：上传参考图

```
角色参考图 → 上传（固定角色形象）
分镜画面   → 上传（确定构图和场景）
```

### Step 4：输入运动描述

用英文描述你想让画面怎么动：

```
Camera slowly pushes in toward the character's face,
he slowly turns his head to look at the screen,
subtle breathing motion,
blue monitor light flickers gently,
maintaining the same anime art style,
cinematic quality, smooth motion, no distortion
```

**常见运动描述词汇：**

| 想表达的效果 | 英文 Prompt |
|------------|-----------|
| 缓慢推进 | `Camera slowly pushes in` |
| 人物转头 | `character slowly turns head` |
| 眨眼 | `character blinks naturally` |
| 风吹发丝 | `hair gently blowing in the wind` |
| 呼吸起伏 | `gentle breathing motion` |
| 手持晃动 | `slight handheld camera shake` |
| 光影闪烁 | `light flickers slightly` |

### Step 5：设置参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 时长 | 5-8 秒 | 每个片段不宜过长 |
| 分辨率 | 1080x1920 | 竖屏短视频标准 |
| 帧率 | 24fps | 足够流畅且文件小 |

### Step 6：生成并下载

点击生成，等待 1-3 分钟，下载 MP4 文件。

## 五、多个片段如何拼接成长视频

一部漫剧可能生成 8-12 个视频片段，需要拼接起来。

### 方法 1：剪映手动拼接（推荐新手）

1. 打开剪映专业版
2. 导入所有视频片段
3. 按剧本顺序排列
4. 相邻片段之间添加转场效果（交叉溶解 0.3 秒）
5. 导入音频轨道
6. 导出 MP4

### 方法 2：FFmpeg 自动拼接（适合批量）

```bash
# 创建文件列表
echo "file 'clip_01.mp4'" > list.txt
echo "file 'clip_02.mp4'" >> list.txt
echo "file 'clip_03.mp4'" >> list.txt
# ...

# 拼接
ffmpeg -f concat -safe 0 -i list.txt -c copy output.mp4
```

## 六、视频生成后的审核

每个视频片段生成后，检查：

- [ ] 角色形象和参考图一致
- [ ] 运动自然，没有扭曲或畸变
- [ ] 时长合适（不要太长或太短）
- [ ] 和相邻镜头衔接流畅
- [ ] 音质清晰（如果有配音）

**常见问题处理：**

| 问题 | 原因 | 解决 |
|------|------|------|
| 角色脸部变形 | 运动幅度太大 | 降低运动强度，减少 Prompt 中的动作描述 |
| 画面闪烁 | 帧间不一致 | 提高视频长度，让过渡更平滑 |
| 和参考图不像 | 参考图权重不够 | 提高参考图权重或在 Prompt 中重复特征描述 |

## 七、成本估算

以一部 20 镜头、其中 10 个镜头生成视频为例：

| 项目 | 数量 | 单价 | 合计 |
|------|------|------|------|
| Seedance API | 10 片段 × 5秒 | ~¥1.5/秒 | ¥75 |
| 或可灵视频 | 10 片段 × 5秒 | 免费额度内 | ¥0 |

**节省技巧**：先用可灵/即梦的免费额度跑通流程，确认效果后再用 Seedance 做精品镜头。
