# 项目四：制作第一个产品广告视频

> 📌 **学习目标**：将 AI 漫剧技术应用于商业场景，制作一套完整的产品广告视频
> ⏱️ **预计时长**：45 分钟
> 🎯 **本节节奏**：需求分析 → 脚本策划 → 画面制作 → 配音合成 → 成品输出

---

## 一、为什么用 AI 漫剧做产品广告？

传统产品广告的制作流程：创意 → 脚本 → 拍摄/美术 → 后期 → 成片，成本高、周期长。

AI 漫剧广告的优势：
- **成本低**：一部 30 秒广告，传统制作数万，AI 制作几百元
- **迭代快**：改一个镜头只需要重新生成，不用重拍
- **风格统一**：固定角色和画风，适合系列广告投放
- **批量生产**：同一产品可以出多个版本，测试不同创意

---

## 二、广告类型与适用场景

### 2.1 产品功能演示型

展示产品如何使用、解决什么问题。

```
适用：APP、软件工具、智能硬件
时长：30-60 秒
结构：问题引入 → 产品展示 → 使用演示 → 效果对比 → 行动号召
```

**示例**：一个效率 APP 的广告
- 开场：程序员被工作淹没，焦虑疲惫
- 转折：发现并使用这个 APP
- 演示：快速完成任务的画面
- 结尾：轻松下班，字幕"你的时间，值得更好用"

### 2.2 品牌故事型

通过故事传递品牌价值观。

```
适用：消费品、服装品牌、食品
时长：30-90 秒
结构：日常场景 → 品牌介入 → 生活方式改变 → 情感共鸣
```

**示例**：一款护眼灯的广告
- 开场：深夜加班的孩子，揉着眼睛
- 转折：妈妈打开了护眼灯
- 演示：温暖的光照亮书桌，孩子继续专注学习
- 结尾：温暖的亲子画面，字幕"陪伴每一刻专注"

### 2.3 卖点突出型

直接展示产品核心卖点，节奏快、冲击力强。

```
适用：电商产品、快消品、促销活动
时长：15-30 秒
结构：痛点暴击 → 产品亮相 → 卖点列举 → 优惠信息 → 购买引导
```

## 三、完整制作流程

### Step 1：明确广告需求

在开始之前，先回答这 5 个问题：

```
1. 卖的是什么产品？（核心功能）
2. 目标用户是谁？（年龄、身份、痛点）
3. 想传达什么核心信息？（一句话概括）
4. 广告放在哪里？（抖音/快手/B站/朋友圈）
5. 期望时长多少？（15秒/30秒/60秒）
```

**示例**：
```
产品：智能降噪耳机
目标用户：22-35岁上班族，通勤时间长，需要专注工作环境
核心信息：戴上它，世界安静了
投放平台：抖音、微信朋友圈
时长：30 秒
```

---

### Step 2：撰写广告脚本

广告脚本和普通漫剧剧本有区别——**前 3 秒必须抓住注意力**。

#### 广告脚本结构（30秒版）

```
【0-3秒】钩子：直接呈现痛点或提出悬念
【3-10秒】引入：产品出现，解决问题
【10-20秒】演示：展示核心功能/卖点
【20-27秒】升华：情感共鸣或使用效果
【27-30秒】号召：品牌 Logo + 行动引导
```

#### 脚本示例（智能降噪耳机）

```markdown
【第一幕：通勤的烦恼】（0-3秒）

【场景 1 - 地铁车厢·早高峰·嘈杂】
镜头角度：特写
画面描述：拥挤的地铁车厢，人群嘈杂，一个年轻人皱着眉头，手捂着耳朵
角色：小张（男，26岁，上班族）
情绪：烦躁
旁白："每天早上，最难熬的不是迟到，是吵。"

【第二幕：安静的力量】（3-10秒）

【场景 2 - 特写·耳机】
镜头角度：特写
画面描述：手指将一副简约的黑色耳机戴入耳中，按钮轻按
角色：无
情绪：期待
旁白："直到我遇到了它。"

【场景 3 - 近景·小张】
镜头角度：固定
画面描述：戴上耳机瞬间，小张的表情从烦躁变为平静，周围嘈杂的人群变成模糊背景
角色：小张
情绪：放松
旁白："戴上它的瞬间，整个世界都安静了。"

【第三幕：核心功能展示】（10-20秒）

【场景 4 - 特写·耳机细节】
镜头角度：旋转展示
画面描述：耳机在纯色背景上缓缓旋转，展示流线型设计和质感材质
角色：无
情绪：高级感
旁白："40小时超长续航，一键降噪，Type-C快充。"

【场景 5 - 中景·小张在办公室】
镜头角度：固定
画面描述：小张戴着耳机专注工作，周围同事交谈但他完全不受影响
角色：小张
情绪：专注
旁白："即使在最吵的环境里，也能保持专注。"

【第四幕：情感升华】（20-27秒）

【场景 6 - 近景·小张下班路上】
镜头角度：缓慢推进
画面描述：夕阳下，小张戴着耳机走在路上，步伐轻快，嘴角微扬
角色：小张
情绪：愉悦
旁白："不是逃避世界，是找到属于自己的节奏。"

【第五幕：品牌号召】（27-30秒）

【场景 7 - 黑屏·品牌展示】
镜头角度：固定
画面描述：黑色背景上出现品牌 Logo 和 Slogan
角色：无
情绪：专业
旁白："静音者 X1，听见更安静的自己。限时特惠，点击链接了解详情。"
```

### Step 3：生成角色和画面

与之前的流程一致：

1. **生成主角参考图**：根据脚本中的角色描述，在即梦/可灵中生成
2. **生成分镜画面**：按剧本逐镜头生成，注意广告的特殊要求——
   - 产品特写镜头要清晰突出
   - 人物表情要自然真实
   - 画面色调要符合品牌调性

**广告画面的特殊技巧：**

| 技巧 | 说明 |
|------|------|
| 产品聚焦 | 有产品出镜的镜头，确保产品是画面焦点 |
| 色调统一 | 整支广告的色调保持一致，强化品牌印象 |
| 少即是多 | 广告画面不要太复杂，重点突出一个信息 |
| 人物亲和 | 主角的表情和动作要贴近目标用户 |

---

### Step 4：配音与 BGM

#### 配音要求

广告配音与普通漫剧不同：
- **语速稍快**：广告节奏更快，旁白要干脆利落
- **情感克制**：不要过度夸张，保持专业感
- **结尾有力**：品牌号召部分要清晰、有感染力

音色选择建议：
- 产品广告：选稳重、可信的音色（如 alloy/onyx）
- 年轻用户产品：选活力、清新的音色（如 nova/fable）

#### BGM 选择

广告 BGM 的选择直接影响整体质感：

| 广告类型 | 推荐 BGM 风格 |
|---------|-------------|
| 科技产品 | 电子/极简，节奏感强 |
| 生活用品 | 温馨/轻快，钢琴或吉他 |
| 高端品牌 | 大气/史诗，弦乐为主 |
| 促销广告 | 动感/欢快，鼓点明显 |

**关键原则**：BGM 音量控制在 8-12%，不能盖过旁白。

---

### Step 5：字幕与品牌元素

广告的字幕比普通漫剧更重要，因为：
- 很多用户在静音状态下观看
- 核心卖点需要用文字强化
- 品牌信息需要反复出现

#### 字幕设计要点

```
主标题（品牌/Slogan）：
  - 字体：品牌标准字体或思源黑体
  - 大小：足够醒目，占画面高度的 5-8%
  - 颜色：与品牌色一致
  - 位置：底部居中或画面下方 1/3 处

卖点文字（动画强调）：
  - 随旁白逐条出现
  - 使用简单的淡入淡出动画
  - 每条不超过 10 个字
```

#### 品牌元素植入

- 片头：品牌 Logo 淡入（1-2秒）
- 片尾：品牌 Logo + Slogan + 购买引导（3-5秒）
- 片中：必要时在产品特写时叠加品牌标识

---

### Step 6：合成与导出

#### 剪映操作要点

1. **时间控制**：严格把控每个镜头的时长，广告切忌拖沓
2. **节奏感**：镜头切换节奏要快，配合 BGM 的节拍
3. **转场简洁**：广告不用花哨的转场，交叉溶解或硬切即可
4. **音效加持**：关键节点添加音效增强记忆点
   - 耳机戴上：轻微的"咔哒"声
   - 降噪开启：低频"嗡"声后突然安静
   - 产品亮相：清脆的音效

#### 导出参数

| 平台 | 分辨率 | 帧率 | 注意事项 |
|------|--------|------|---------|
| 抖音 | 1080x1920 | 30fps | 竖屏，前3秒最关键 |
| 微信朋友圈 | 1080x1080 | 30fps | 正方形，适合品牌调性 |
| B站 | 1080x1920 | 30fps | 竖屏，可稍长 |
| 拼多多/淘宝 | 1080x1080 | 30fps | 正方形，卖点突出 |

## 四、广告与漫剧的区别

| 维度 | 漫剧 | 广告视频 |
|------|------|---------|
| **核心目的** | 讲故事，吸引追看 | 卖产品，促成行动 |
| **时长** | 60-90 秒 | 15-60 秒 |
| **节奏** | 有起承转合 | 快节奏，信息密度高 |
| **角色** | 有性格，有成长 | 代表目标用户即可 |
| **结尾** | 悬念，引导追更 | 行动号召，引导购买 |
| **品牌露出** | 可有可无 | 必须有，贯穿始终 |
| **画面复杂度** | 可以丰富 | 要简洁，突出产品 |

## 六、本章小结

做 AI 广告视频的核心要点：

| 要点 | 说明 |
|------|------|
| 前 3 秒定生死 | 开头必须抓住注意力，不要铺垫 |
| 产品是主角 | 画面围绕产品展开，人物只是辅助 |
| 卖点要重复 | 核心卖点用画面+文字双重强调 |
| 号召要明确 | 结尾告诉观众"下一步该做什么" |
| 风格要统一 | 色调、字体、配音风格保持一致 |
