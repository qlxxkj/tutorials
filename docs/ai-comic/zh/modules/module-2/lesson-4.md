# 第 4 课：漫剧剧本怎么写

> 📌 **学习目标**：学会写出适合 AI 工具处理的结构化剧本
> ⏱️ **预计时长**：25 分钟
> 🎯 **本节节奏**：剧本格式 → 字段详解 → 写作原则 → 完整示例

---

## 一、AI 漫剧剧本是什么？

普通电影剧本是写给导演和演员看的，告诉他们在现场怎么做。

AI 漫剧剧本是写给**AI 工具**看的——它需要同时告诉三个系统：

| 系统 | 需要的信息 | 示例 |
|------|----------|------|
| **图像/视频生成** | 画面长什么样 | "昏暗的客厅，窗外下雨，桌上有泡面盒" |
| **配音系统** | 谁在说什么 | 角色名 + 台词 + 情绪 |
| **剪辑系统** | 节奏怎么安排 | 镜头角度 + 时长估算 |

所以 AI 漫剧剧本 = **可视化描述 + 台词 + 结构化标记**。

---

## 二、标准剧本格式

每个镜头都按这个格式来写：

```markdown
【场景 N - 地点·时间·光线】
镜头角度：[特写/近景/中景/全景/俯拍/仰拍]
画面描述：[具体的视觉描述，1-2句话]
角色：[角色名]
情绪：[当前情绪]
对话/旁白："[台词内容]"
动作：[角色动作，可选]
```

### 一个完整的剧本示例

```markdown
【第一集：深夜的访客】

【场景 1 - 室内·公寓客厅·深夜·月光】
镜头角度：缓慢推进
画面描述：老旧的客厅，窗外暴雨如注，桌上散落着泡面盒和键盘，唯一的光源是显示器的蓝光
角色：陈默（男，28岁，程序员）
情绪：疲惫
旁白："又一个凌晨三点……还有最后一个 bug。"
动作：揉眼睛，打哈欠，看了眼墙上的钟

【场景 2 - 特写·电脑屏幕】
镜头角度：固定
画面描述：VS Code 编辑器，满屏红色报错信息，光标在最后一行不停闪烁
角色：无
情绪：焦虑
对话："到底哪里错了……再跑一次。"
动作：手指在键盘上飞快敲击

【场景 3 - 近景·陈默】
镜头角度：固定
画面描述：陈默凑近屏幕，眼镜片上反射着代码的光
角色：陈默
情绪：困惑
对话："这行代码明明没问题……"

【场景 4 - 特写·屏幕】
镜头角度：固定，画面轻微抖动
画面描述：屏幕突然闪了一下，黑色终端窗口弹出，自动输入了一行字
角色：无
情绪：震惊
旁白："终端里浮现出一行不是自己敲的字——'你看到了吗？'"

【场景 5 - 近景·陈默】
镜头角度：手持晃动效果
画面描述：陈默猛地后仰，椅子发出刺耳的摩擦声，脸色瞬间苍白
角色：陈默
情绪：惊恐
对话："谁……谁在搞恶作剧？"
动作：慌乱地拔掉网线

【场景 6 - 全景·房间】
镜头角度：固定，光线骤暗
画面描述：整间公寓的灯同时熄灭，只有终端屏幕还亮着
角色：无
情绪：紧张
旁白："灯灭了，但屏幕上的字还在继续——'别怕，我不是来害你的。'"

【场景 7 - 特写·终端】
镜头角度：固定
画面描述：屏幕上逐字打出新的内容
角色：无
情绪：恐惧
旁白："'我是你——三年后的你。'"

【场景 8 - 近景·陈默】
镜头角度：固定
画面描述：陈默颤抖着手重新插上网线，盯着屏幕，嘴唇发白
角色：陈默
情绪：震惊→好奇
对话："什么……什么意思？"

【场景 9 - 特写·屏幕】
镜头角度：固定
画面描述：光标闪烁，一行字慢慢出现
角色：无
情绪：悬念
旁白："'听我说，时间不多。你有七分钟。'"

【结尾字幕】
画面：黑屏
字幕："下集待续"
```

## 三、逐字段详解

### 场景标记

格式：`【场景 N - 地点·时间·光线】`

光线是最重要的——它直接决定画面的色调和氛围。

| 光线关键词 | 适用氛围 |
|-----------|---------|
| 月光 | 清冷、孤独、神秘 |
| 霓虹 | 都市、浮躁、迷幻 |
| 昏暗 | 压抑、悬疑、恐怖 |
| 暖光 | 温馨、回忆、舒适 |
| 顶光 | 审讯、压迫、神圣 |
| 背光 | 剪影、未知、恐惧 |

### 镜头角度

| 角度 | 效果 | 适合用在哪 |
|------|------|----------|
| 特写 | 强调表情细节 | 震惊、恐惧、悲伤等情绪爆发点 |
| 近景 | 上半身，看表情 | 对话场景 |
| 中景 | 腰部以上 | 日常互动 |
| 全景 | 全身+环境 | 场景转换、空间关系 |
| 俯拍 | 从上往下看 | 压抑感、无力感 |
| 仰拍 | 从下往上看 | 威严、压迫、英雄登场 |

### 画面描述

这是**最关键**的字段——AI 绘图和视频生成都依赖它。

**三条原则：**

1. **具体化**：不要写"很害怕"，要写"手在发抖，呼吸急促，瞳孔放大"
2. **可绘制**：描述必须是能被画出来的东西，不要抽象概念
3. **光影明确**：光源在哪、什么颜色、强度如何

```
❌ 差："房间里很压抑"
✅ 好："狭小的出租屋，墙上贴着泛黄的海报，桌上堆满泡面盒，唯一的光源是电脑屏幕的蓝光"

❌ 差："他很害怕"
✅ 好："手在发抖，呼吸急促，瞳孔放大，身体微微后退"
```

### 角色

格式：`角色：陈默（男，28岁，程序员）`

名字后面括号里的描述很重要——后续 AI 生成画面时会用到这些信息来保持一致性。

### 情绪

格式：`情绪：疲惫/震惊/恐惧/平静/愤怒/兴奋/悲伤/神秘`

情绪影响三个方面：
- 图像生成：角色表情、肢体语言
- TTS 配音：语速、语调
- 视频生成：动作幅度和速度

### 对话/旁白

- **对话**：角色之间说的话，带引号
- **旁白**：叙述者的解说

对话要简短有力，每句不超过 20 字。

---

## 四、剧本长度控制

| 时长 | 镜头数 | 适合平台 |
|------|--------|---------|
| 30 秒 | 8-12 个镜头 | 抖音/快手短视频 |
| 60 秒 | 15-20 个镜头 | 抖音主战场 ⭐推荐 |
| 90 秒 | 20-30 个镜头 | B站/YouTube |

**建议**：第一部漫剧控制在 60 秒以内（15-20 个镜头）。

---

## 五、写作练习

选择以下一个主题，写出前 5 个场景的分镜剧本：

1. **外卖员送错地址，误入一栋不存在的老楼**
2. **两个陌生人在地铁末班车上相遇**
3. **一只猫眼中的主人回家**
4. **凌晨便利店的奇遇**

写作时注意：
- 每个场景都写全所有字段
- 画面描述具体到能看到什么
- 第 1 个场景要有钩子（吸引观众看下去）
- 第 5 个场景末尾要有悬念
