# 第 3 课：技术选型与工具链

> 📌 **学习目标**：根据项目需求选择合适的技术方案和工具组合
> ⏱️ **预计时长**：20 分钟
> 🎯 **本节节奏**：方案对比 → 选型决策 → 环境搭建

---

## 一、图像生成方案对比

### 方案 A：OpenAI GPT-Image-1 / DALL-E 3

```
优点：
✅ API 简单，一行代码调用
✅ 角色一致性较好（有 image reference 功能）
✅ 质量稳定，出图成功率高
✅ 支持 1080p 竖屏输出

缺点：
❌ 单价较高（~$0.04/张）
❌ 需要联网
❌ 自定义程度有限

适用：快速原型、商业项目
预算：约 ¥300/100 张图
```

### 方案 B：Stable Diffusion + ComfyUI（本地）

```
优点：
✅ 完全免费（本地运行）
✅ 插件丰富（ControlNet、IP-Adapter）
✅ 角色一致性极强（Reference Only + LoRA）
✅ 无 API 限流

缺点：
❌ 需要 NVIDIA 显卡（推荐 8GB+ VRAM）
❌ 部署和维护成本较高
❌ 首次上手曲线陡峭

适用：长期批量生产、对成本敏感
硬件要求：RTX 3060 或以上
```

### 方案 C：Agnes AI / 国内代理

```
优点：
✅ OpenAI 兼容 API，接入成本低
✅ 国内访问稳定
✅ 价格可能更优惠

缺点：
❌ 依赖第三方服务稳定性
❌ 功能更新可能滞后

适用：不想折腾部署，又要低成本
```

**本课默认方案：OpenAI GPT-Image-1**（最简单，效果足够好）

## 二、TTS 配音方案对比

| 方案 | 音色质量 | 多语言 | 价格 | 延迟 |
|------|---------|--------|------|------|
| **OpenAI TTS** | ★★★★★ | 17 种 | ~¥0.015/字符 | 快 |
| **Azure Neural TTS** | ★★★★★ | 100+ | 免费额度 | 快 |
| **火山引擎/讯飞** | ★★★★ | 中文优秀 | 按量付费 | 快 |
| **VALL-E X（本地）** | ★★★ | 英文为主 | 免费 | 慢 |
| **Whisper + VITS** | ★★★ | 依赖训练数据 | 免费 | 慢 |

**本课默认方案：OpenAI TTS**（集成简单，质量高）

## 三、口型同步方案对比

| 方案 | 使用方式 | 费用 | 质量 | 部署难度 |
|------|---------|------|------|---------|
| **HeyGen** | API | ~$0.1/秒 | ★★★★★ | 低 |
| **D-ID** | API | ~$0.08/秒 | ★★★★ | 低 |
| **Hedra** | API | 免费额度 | ★★★★ | 低 |
| **SadTalker** | 本地 | 免费 | ★★★ | 中 |
| **Wav2Lip** | 本地 | 免费 | ★★★ | 中 |

**本课策略：**
- 快速原型：跳过口型同步（静态漫画风格）
- 高质量需求：使用 HeyGen API
- 离线需求：本地 SadTalker

## 四、视频合成方案对比

| 方案 | 优势 | 劣势 | 适用 |
|------|------|------|------|
| **FFmpeg** | 强大、灵活、免费 | 命令行学习曲线 | 自动化流水线 |
| **MoviePy** | Python API，易用 | 性能较慢 | 中小项目 |
| **Remotion** | 编程式视频，React | 需要 Node.js | Web 应用 |
| **FFnch** | 现代化，跨平台 | 较新，生态小 | 新兴项目 |

**本课默认方案：FFmpeg + Python subprocess**（最可靠）

## 五、完整工具链推荐

### 入门方案（推荐新手）

```
图像生成：  GPT-Image-1（OpenAI API）
TTS 配音：  OpenAI TTS
口型同步：  暂不实现（静态漫画风格）
视频合成：  FFmpeg
剧本生成：  GPT-4o
开发语言：  Python 3.10+
```

### 进阶方案（批量生产）

```
图像生成：  Stable Diffusion + ComfyUI（本地）
TTS 配音：  Azure Neural TTS / 本地 VITS
口型同步：  SadTalker（本地）
视频合成：  FFmpeg + MoviePy
剧本生成：  Claude / GPT-4o
调度工具：  Airflow / cron
```

### 商业化方案（团队协作）

```
图像生成：  Midjourney（人工筛选）+ SD 本地精修
TTS 配音：  专业声优 + AI 辅助修正
口型同步：  HeyGen API
视频合成：  Adobe Premiere / DaVinci Resolve
项目管理：  Notion / 飞书多维表格
CI/CD：    GitHub Actions 自动化
```

## 六、本章小结

没有"最好"的方案，只有"最适合"的方案：

- **入门阶段**：用 OpenAI API 快速验证想法，成本可控
- **量产阶段**：迁移到本地 SD + 开源工具，降本增效
- **商业阶段**：混合方案，关键环节人工介入保证质量
