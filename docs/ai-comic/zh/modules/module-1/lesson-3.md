# 第 3 课：技术选型与工具链

> 📌 **学习目标**：根据项目需求选择合适的图像生成和视频生成方案，理解各自优劣
> ⏱️ **预计时长**：20 分钟
> 🎯 **本节节奏**：图像方案对比 → 视频方案对比 → 组合决策

---

## 一、图像生成方案对比

AI 漫剧的第一步是产出画面，图像生成方案直接决定画质上限和成本。

### 方案 A：GPT-Image-2（API 托管）

```
优点：
✅ 接入最简单，OpenAI 兼容 API 一行代码
✅ 角色一致性较好（有 image reference 功能）
✅ 质量稳定，出图成功率高
✅ 支持任意比例输出

缺点：
❌ 单价较高（~$0.04～$0.08/张）
❌ 需要联网，依赖 OpenAI 服务稳定性
❌ 风格可控性有限

适用场景：快速原型、小批量生产、不想折腾部署
成本参考：约 ¥3～6/张
```

### 方案 B：Nano-Banana（API 托管）

```
优点：
✅ 国内访问稳定，延迟低
✅ 价格比 GPT-Image 更便宜
✅ 对中文 Prompt 理解更好
❌ 生态较小，文档和社区资源少
❌ 角色一致性不如 GPT-Image

适用场景：国内项目、成本敏感型生产
```

### 方案 C：ComfyUI + 开源模型（本地部署）⭐ 推荐

```
优点：
✅ 完全免费（本地运行，无 API 费用）
✅ 插件生态极其丰富（ControlNet、IP-Adapter、Reference Only）
✅ 角色一致性最强（IP-Adapter FaceID + LoRA）
✅ 无 API 限流，批量无压力
✅ 可以精确控制构图（ControlNet 深度图/边缘图/姿势）

缺点：
❌ 需要 NVIDIA 显卡（推荐 RTX 3060 8GB+）
❌ 首次部署耗时 1～2 小时
❌ 学习曲线较陡

推荐搭配模型：
┌─────────────────┬──────────────┬──────────────────┐
│ 模型            │ 特点          │ 推荐用途          │
├─────────────────┼──────────────┼──────────────────┤
│ Flux            │ 画质顶尖      │ 高质量分镜画面    │
│ Z-image-tuber   │ 动漫专精      │ 动漫风格漫剧      │
│ SDXL            │ 稳定均衡      │ 通用场景          │
│ 自定义 LoRA     │ 风格定制      │ 统一画风          │
└─────────────────┴──────────────┴──────────────────┘

适用场景：长期批量生产、对画质和一致性要求高
硬件要求：RTX 3060 8GB 或更高
```

## 二、视频生成方案对比

图像生成后，下一步是让画面动起来。这是 AI 漫剧的最新突破口。

### 方案 A：火山引擎 Seedance 2.0

```
优点：
✅ 国产，访问稳定，延迟低
✅ 多图参考能力强，角色一致性好
✅ API 调用简单，无需本地部署
✅ 支持 5-15 秒视频片段生成

缺点：
❌ 按量计费，批量成本高
❌ 自定义程度有限
❌ 需要注册企业资质（个人可能受限）

成本参考：约 ¥0.5～2/秒
```

### 方案 B：MiniMax H3（API）

```
优点：
✅ 国产，对中文理解好
✅ 生成速度快
✅ 角色扮演能力强

缺点：
❌ 画面质量参差不齐
❌ 可控性不如 ComfyUI 方案

适用场景：快速验证、对画面精度要求不高
```

### 方案 C：ComfyUI + MiniMax H3（本地）⭐ 推荐

```
优点：
✅ 完全免费，无 API 费用
✅ 结合 ControlNet 可精确控制镜头运动
✅ 多图参考输入，保证角色一致性
✅ 每次生成 5-15 秒片段，可拼接成长视频

缺点：
❌ 需要高性能 GPU（推荐 RTX 4090 24GB+）
❌ 单次生成耗时 2-5 分钟
❌ 需要定期更新模型

工作流程：
┌──────────┐    ┌─────────────┐    ┌─────────────┐
│ 参考图A   │    │ 参考图B      │    │ 运动控制    │
│ (角色正面) │───→│ (场景参考)   │───→│ (CameraMove) │
└──────────┘    └─────────────┘    └──────┬──────┘
                                          │
                                   ┌──────▼──────┐
                                   │ MiniMax H3  │
                                   │ 生成 5-15s  │
                                   │ 视频片段     │
                                   └──────┬──────┘
                                          │
                                   ┌──────▼──────┐
                                   │ FFmpeg 拼接  │
                                   │ → 最终视频   │
                                   └─────────────┘

适用场景：批量生产、追求高质量、有本地 GPU
```

## 三、方案组合决策

根据你的条件选择最佳组合：

| 条件 | 推荐组合 | 原因 |
|------|---------|------|
| **有 GPU，长期生产** | ComfyUI(Flux/Z-image) + ComfyUI(MiniMax-H3) | 零边际成本，质量最高 |
| **无 GPU，短期项目** | GPT-Image-2 + Seedance 2.0 API | 接入快，省心 |
| **国内访问，成本敏感** | Nano-Banana + MiniMax API | 国内稳定，价格低 |
| **学习研究，探索玩法** | ComfyUI(Flux) + Seedance API | 本地画图 + 云端生成视频 |

---

## 四、本课采用方案

考虑到教程的普适性和可操作性，本课采用 **混合方案**：

```
图像生成：  GPT-Image-2（API，最简单上手）
           ↓  后续可替换为 ComfyUI + Flux
视频生成：  Seedance 2.0（API，国产稳定）
           ↓  后续可替换为 ComfyUI + MiniMax-H3
配音：      OpenAI TTS
合成：      FFmpeg
```

这个方案的特点是：**先用最简单的 API 跑通全流程，再逐步替换为本地方案降本增效**。

---

## 五、成本估算

以一部 **20 镜头、约 2 分钟** 的漫剧为例：

| 方案 | 图像成本 | 视频成本 | 配音 | 总计 |
|------|---------|---------|------|------|
| 全 API | ~¥80 | ~¥200 | ~¥3 | **¥283** |
| ComfyUI 图像 + API 视频 | ~¥0 | ~¥200 | ~¥3 | **¥203** |
| 全本地 | ~¥0 | ~¥0 | ~¥0 | **¥3** |

> 全本地方案的瓶颈在于 GPU 硬件投入（约 ¥3000-8000），但长期批量生产摊薄后成本极低。
