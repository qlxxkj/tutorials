# 第 2 课：核心工作流程

> 📌 **学习目标**：掌握 AI 漫剧的完整生产流水线，理解每个环节的技术要点
> ⏱️ **预计时长**：20 分钟
> 🎯 **本节节奏**：流程总览 → 逐环节拆解 → 关键技术点

---

## 一、全流程总览

一部 AI 漫剧从构思到成片，经历 **6 个核心环节**：

```
                    ┌─────────────┐
                    │  1. 剧本创作  │
                    └──────┬──────┘
                           ▼
              ┌────────────────────────┐
              │   2. 角色设定与参考图    │
              └────────────┬───────────┘
                           ▼
              ┌────────────────────────┐
              │   3. 分镜画面批量生成    │
              └────────────┬───────────┘
                           ▼
              ┌────────────────────────┐
              │   4. TTS 配音生成       │
              └────────────┬───────────┘
                           ▼
              ┌────────────────────────┐
              │   5. 口型同步（可选）    │
              └────────────┬───────────┘
                           ▼
              ┌────────────────────────┐
              │   6. 视频合成与后期     │
              └────────────┬───────────┘
                           ▼
                    ┌─────────────┐
                    │   成品输出   │
                    └─────────────┘
```

## 二、逐环节详解

### 环节 1：剧本创作

**输入：** 一个故事主题或大纲
**输出：** 格式化的分镜剧本（Markdown）

剧本格式是每个镜头一条记录，包含：
- 场景描述（地点、时间、光线）
- 镜头角度（特写/中景/全景）
- 角色动作与表情
- 对话或旁白
- 情绪标记

```markdown
【镜头 1】
场景：室内·客厅·夜·灯光昏暗
镜头：缓慢推进
角色：小明（男，25岁）
情绪：疲惫
旁白："又一个深夜，代码还没写完……"
```

**关键技术：** 用 LLM（GPT-4o / Claude）生成剧本，需要定义好输出格式。

---

### 环节 2：角色设定

**输入：** 角色描述文本
**输出：** 角色参考图（PNG）

角色参考图是整个流程中**最关键的一环**——它决定了后续所有画面中角色是否一致。

参考图通常需要：
- 正面全身像
- 侧面/背面视角（可选）
- 干净背景（白色或透明）
- 细节丰富（服装、发型、配饰清晰可见）

**关键技术：**
- 图像生成 API 的基础调用
- **角色一致性**：固定 seed、复用参考图、在每次 prompt 中重复关键特征

---

### 环节 3：分镜画面生成

**输入：** 剧本分镜 + 角色参考图
**输出：** 每镜头一张 PNG 图片

这是最耗时的环节——一部 20 镜头的漫剧需要生成 20 张图。

**Prompt 构建公式：**
```
[画风] + [场景描述] + [角色描述] + [镜头角度] + [情绪/表情] + [光影] + [质量词]
```

**关键技术：**
- Prompt engineering 是核心技能
- 批量生成时的 API 限流处理
- 风格统一性控制

---

### 环节 4：TTS 配音

**输入：** 剧本中的对话/旁白文本
**输出：** 每段音频 MP3 文件

不同角色用不同音色，同一角色保持一致。

**OpenAI TTS 音色选择：**

| 音色 | 特点 | 适用角色 |
|------|------|---------|
| alloy | 中性男声 | 旁白、男性角色 |
| onyx | 低沉男声 | 年长男性、反派 |
| echo | 温暖男声 | 叙述者 |
| fable | 英国女声 | 女性角色 |
| nova | 明亮女声 | 年轻女性 |
| shani | 有力女声 | 强势女性角色 |

**关键技术：**
- 语速调整（根据情绪）
- 多角色音色映射
- 音频格式标准化

---

### 环节 5：口型同步

**输入：** 角色参考图 + 配音音频
**输出：** 角色开口说话的短视频片段

> ⚠️ 这一步**可选**。如果画面本身就是静态漫画风格（类似动态漫画），可以跳过口型同步，直接做幻灯片式播放。

**常用方案对比：**

| 方案 | 精度 | 速度 | 费用 | 适合场景 |
|------|------|------|------|---------|
| HeyGen API | ★★★★★ | 快 | ~$0.1/秒 | 高质量成品 |
| D-ID API | ★★★★ | 中 | ~$0.08/秒 | 中等质量 |
| Hedra API | ★★★★ | 快 | 有免费额度 | 测试/低成本 |
| SadTalker | ★★★ | 慢 | 免费（本地） | 离线部署 |
| Wav2Lip | ★★★ | 中 | 免费（本地） | 自部署 |

---

### 环节 6：视频合成

**输入：** 分镜图片序列 + 音频轨道 + BGM
**输出：** 最终 MP4 视频

**合成流程：**
```
图片序列 → 缩放适配 → 设置时长 → 添加转场 → 叠加字幕
音频轨道 → 音量调整 → 混音 → 与画面对齐
BGM → 淡入淡出 → 音量压低（不盖过配音）
最终 → H.264 编码 → MP4 输出
```

**关键技术：**
- FFmpeg 命令行/Python 封装
- 字幕 SRT 文件格式
- 音频响度标准化（loudnorm）

```
└──────────┘    └──────────┘    └──────────┘    └──────────┘
     │                │                │                │
     ▼                ▼                ▼                ▼
  GPT-4o/Llm    GPT-Image-1       OpenAI TTS      FFmpeg
  写剧本        生成分镜图         生成配音        合成视频
```

## 四、成本控制

以一部 **20 镜头、1 分钟**的漫剧为例：

| 环节 | API | 估算成本（人民币） |
|------|-----|------------------|
| 剧本生成 | GPT-4o | ¥0.5 ～ 1 |
| 角色参考图 | GPT-Image-1 × 1 | ¥0.3 |
| 分镜画面 | GPT-Image-1 × 20 | ¥6 ～ 8 |
| TTS 配音 | OpenAI TTS × 20段 | ¥1 ～ 2 |
| 口型同步 | HeyGen（可选） | ¥5 ～ 10 |
| BGM | 免版权音乐库 | ¥0 |
| **合计** | | **¥8 ～ 22** |

> 如果全部使用本地部署的开源模型（Stable Diffusion + Whisper + SadTalker），成本可降至接近零。

## 五、本章小结

| 环节 | 核心任务 | 关键技术 |
|------|---------|---------|
| 剧本创作 | 生成结构化分镜脚本 | LLM Prompt Engineering |
| 角色设定 | 创建一致性参考图 | 图像生成 + Seed 控制 |
| 画面生成 | 批量产出分镜图 | Prompt 模板 + 批量 API |
| 配音生成 | 多角色 TTS 合成 | OpenAI TTS API |
| 口型同步 | 让角色"开口说话" | HeyGen / SadTalker |
| 视频合成 | 拼接输出成品 | FFmpeg + MoviePy |
