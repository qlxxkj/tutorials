# 第 10 课：视频合成与后期

> 📌 **学习目标**：学会用剪映完成视频合成，添加字幕、BGM 和转场效果
> ⏱️ **预计时长**：25 分钟
> 🎯 **本节节奏**：合成步骤 → 字幕添加 → BGM 配置 → 导出设置

---

| 工具 | 适合人群 | 费用 | 学习成本 |

## 二、完整合成流程

```
① 导入素材    →    ② 排列顺序    →    ③ 添加字幕    →    ④ 添加BGM    →    ⑤ 导出
  图片+音频      按剧本顺序         自动/手动        压低音量        设置参数
```

---

## 三、详细操作步骤

### Step 1：导入素材

打开剪映专业版 → 新建项目 → 导入：
- 所有分镜图片（`assets/shots/` 目录）
- 所有配音音频（`assets/audio/` 目录）
- 背景音乐（可选）

**提示**：项目比例选择 **9:16**（竖屏短视频标准）。

### Step 2：排列顺序

1. 将图片按顺序拖到主轨道
2. 将对应的音频拖到音频轨道（图片下方）
3. 调整每张图片的时长，使其与对应音频长度匹配
4. 检查顺序是否正确

**小技巧**：
- 右键图片 → 设置持续时间，精确控制每帧时长
- 快捷键 `Ctrl+R` 可以快速裁剪多余部分
- 使用"吸附"功能（磁吸图标），让素材自动对齐

### Step 3：添加字幕

**方法 A：剪映自动识别字幕**

1. 点击「文本」→「智能字幕」→「识别字幕」
2. 剪映会自动根据音频生成字幕
3. 检查并修正识别错误的文字
4. 调整字幕样式（字体、大小、颜色、位置）

**方法 B：手动添加字幕**

对于没有配音的旁白镜头，手动添加文字：

1. 点击「文本」→「新建文本」
2. 输入旁白内容
3. 调整出现和消失的时间点
4. 设置样式（推荐：白色字体 + 黑色描边，底部居中）

**字幕样式推荐：**
```
字体：思源黑体 / 阿里巴巴普惠体
大小：48-60（根据分辨率调整）
颜色：白色 #FFFFFF
描边：黑色，宽度 2-3px
位置：画面底部，距离底边 15%
```

### Step 4：添加转场效果

相邻镜头之间添加转场，让切换更自然：

1. 将鼠标移到两个素材之间的缝隙
2. 点击出现的转场图标
3. 选择转场效果（推荐"交叉溶解"，时长 0.3 秒）
4. 应用到所有镜头之间（可批量选择后统一应用）

**推荐转场效果：**
| 场景 | 推荐转场 | 时长 |
|------|---------|------|
| 正常切换 | 交叉溶解 | 0.3s |
| 情绪转折 | 黑场过渡 | 0.5s |
| 回忆/闪回 | 淡入淡出 | 0.5s |
| 悬念时刻 | 快速闪白 | 0.1s |

### Step 5：添加背景音乐

1. 点击「音频」→「音乐」→ 选择一个合适的 BGM
2. 将 BGM 拖到音频轨道的最下方
3. 调整 BGM 音量：**10-15%**（不能盖过配音）
4. 给 BGM 添加淡入淡出效果（开头 2 秒淡入，结尾 3 秒淡出）

**BGM 选择原则：**
- 悬疑风格：低沉、缓慢、有张力
- 情感风格：温柔、舒缓、钢琴/弦乐
- 避免：有歌词的音乐（会和配音冲突）
- 推荐来源：剪映自带音乐库、YouTube Audio Library（免费）

### Step 6：微调时间线

最后整体检查一遍：

- [ ] 每个镜头的时长是否合适（不要过短或过长）
- [ ] 字幕出现和消失时间是否准确
- [ ] BGM 音量是否合适（听得到但不抢戏）
- [ ] 转场效果是否自然
- [ ] 整体节奏是否流畅

## 四、导出设置

剪映导出参数推荐：

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 分辨率 | 1080x1920 | 竖屏标准 |
| 帧率 | 30fps | 足够流畅 |
| 码率 | 推荐或更高 | 保证画质 |
| 格式 | MP4 | 通用兼容 |
| 编码 | H.264 | 兼容性最好 |

**各平台推荐参数：**

| 平台 | 分辨率 | 码率建议 |
|------|--------|---------|
| 抖音 | 1080x1920 | 8-12 Mbps |
| 快手 | 1080x1920 | 8-12 Mbps |
| B站 | 1080x1920 | 10-15 Mbps |
| 视频号 | 1080x1920 | 8-12 Mbps |

---

## 五、发布前的检查清单

导出前逐项检查：

- [ ] 视频时长在目标范围内（60-90 秒为宜）
- [ ] 画面清晰，没有模糊或拉伸变形
- [ ] 角色形象一致，没有突然换脸
- [ ] 配音清晰，没有杂音或断断续续
- [ ] 字幕没有错别字，显示时间正确
- [ ] BGM 音量合适，不盖过配音
- [ ] 结尾有"下集待续"或关注引导
- [ ] 封面图吸引人（可选）

## 六、本章小结

| 步骤 | 操作 | 关键要点 |
|------|------|---------|
| 导入素材 | 图片和音频拖入时间轴 | 按剧本顺序排列 |
| 排列时长 | 图片时长 = 对应音频时长 | 精确到帧 |
| 添加字幕 | 智能识别或手动添加 | 底部居中，白字黑边 |
| 添加转场 | 相邻镜头间加交叉溶解 | 0.3 秒，不要太花哨 |
| 添加 BGM | 低音量铺底 | 10-15%，有歌词的不选 |
| 导出发布 | 1080x1920，H.264 | 检查无误后导出 |
