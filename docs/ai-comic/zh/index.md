# AI 漫剧制作完全指南

> 从零开始，用 AI 制作自己的漫画剧集
> 适合有基础编程知识的内容创作者、独立动画师和 AI 爱好者

---

## 课程简介

你有没有想过：

- 看到自己喜欢的小说，能不能把它变成漫画？
- 想用动画讲述自己的故事，但不会画画？
- 听说 AI 能生成图片和视频，但不知道从何下手？
- 想批量生产短视频内容，但人力成本太高？

**AI 漫剧**正是解决这些痛点的方案——用人工智能全流程辅助完成从剧本创作到视频成品的生产流水线。

这门课将带你走完从**剧本创作 → 分镜解析 → 画面生成 → 视频合成**的完整流程，核心聚焦于：

- **剧本写作**：如何写出适合 AI 生成的结构化分镜剧本
- **分镜拆解**：从文本到镜头语言的转换技巧
- **Prompt 工程**：图像和视频生成的高质量 Prompt 构建
- **批量生产**：角色一致性控制、成本控制、效率优化

### 技术选型

| 环节 | 入门方案 | 进阶方案 |
|------|---------|---------|
| 图像生成 | GPT-Image-2 / Nano-Banana | ComfyUI + Flux / Z-image-tuber |
| 视频生成 | Seedance 2.0 API / MiniMax H3 | ComfyUI + 本地 MiniMax H3 |
| 配音 | OpenAI TTS | Azure Neural TTS / 火山引擎 |
| 合成 | FFmpeg | FFmpeg + MoviePy |

| 模块 | 内容 | 预计时长 |
|------|------|----------|
