# Claude Code 入门教程 — 课程总览

> 面向零编程基础的职场人士和内容创作者  
> 用自然语言，让 AI 成为你的私人助手

---

## 课程简介

本课程系统讲解 **Claude Code** 的使用方法——Anthropic 推出的 AI 编程智能体。它不是简单的聊天机器人，而是能读文件、写代码、运行命令、操作电脑的智能助手。

**核心优势：** 不需要会编程，只要你会说人话，就能让 AI 帮你完成各种任务。

## 学习路线

### 完整学习路线（推荐）

按模块顺序学习，总计约 5-7 小时：

| 模块 | 内容 | 建议时长 |
|------|------|---------|
| 模块一 | 认识 Claude Code | 45 分钟 |
| 模块二 | 基础操作 | 60 分钟 |
| 模块三 | 进阶技巧 | 90 分钟 |
| 模块四 | 最佳实践 | 45 分钟 |
| 模块五 | 项目实战 | 120 分钟 |
| 模块六 | 总结与进阶 | 30 分钟 |

### 速成路线（时间紧张）

1. **模块一**（认识 Claude Code）→ 15 分钟
2. **模块二**（基础操作）→ 30 分钟
3. **模块五·项目一**（搭建个人知识库）→ 20 分钟

即可掌握最实用的功能。

## 学完你能做到什么？

- ✅ 让 Claude Code 帮你整理文件夹、批量重命名、归类文件
- ✅ 用自然语言描述需求，让 Claude Code 生成 Python 脚本
- ✅ 让 Claude Code 联网搜索资料并整理成报告
- ✅ 让 Claude Code 执行重复性任务，节省时间
- ✅ 使用技能快速完成复杂任务（生成 PPT、写简历、写博客）
- ✅ 独立完成 4 个实战项目
- ✅ 设计自动化工作流，提升工作效率
