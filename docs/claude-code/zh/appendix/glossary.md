# 附录：术语表

## A

**Agent（智能体）**
AI 系统中能够自主完成任务的程序。与简单的聊天机器人不同，Agent 可以主动执行操作、调用工具、完成复杂任务。

**API（应用程序编程接口）**
不同软件之间通信的接口。Claude Code 通过 API 与 Anthropic 的 AI 模型通信。

## C

**Claude Code**
Anthropic 推出的 AI 编程智能体，运行在终端中，能够通过自然语言指令操作电脑、编写代码、执行任务。

**Context（上下文）**
对话的背景信息。Claude Code 会记住之前的对话内容，以便理解当前任务的上下文。

## G

**GUI（图形用户界面）**
通过图形界面与计算机交互的方式。Claude Code 主要是命令行界面，但也有图形化工具。

## N

**Natural Language（自然语言）**
人类日常使用的语言，如中文、英文。与自然语言相对的是编程语言（如 Python、Java）。

## P

**Prompt（提示词）**
用户输入给 AI 的指令或问题。好的提示词能让 AI 更准确地理解任务。

**Prompt Engineering（提示词工程）**
设计和优化提示词的技术，让 AI 更好地理解任务并给出准确答案。

## T

**Terminal（终端）**
命令行界面，用户通过输入命令与计算机交互。Claude Code 运行在终端中。

**Tool（工具）**
AI 可以调用的外部功能，如文件操作、网络搜索、代码执行等。

## U

**UI（用户界面）**
用户与软件交互的界面。Claude Code 的 UI 是命令行界面。

## V

**Vibe Coding**
一种编程方式，用户用自然语言描述需求，AI 自动生成代码。不需要用户懂编程。
