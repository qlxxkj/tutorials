# 附录：课前准备清单

在开始学习之前，请确认你已经准备好以下内容：

## 必备条件

- [ ] **一台电脑**
  - Windows 10 或更高版本
  - macOS 11.0 或更高版本
  - 建议内存 8GB 以上

- [ ] **稳定的网络连接**
  - Claude Code 需要联网使用
  - 建议带宽 50Mbps 以上

- [ ] **Node.js 环境**
  - 版本 18.0 或更高
  - 检查命令：`node --version`

- [ ] **npm 包管理器**
  - 版本 8.0 或更高
  - 检查命令：`npm --version`

- [ ] **Anthropic API 密钥**
  - 访问 https://console.anthropic.com/ 注册
  - 生成 API 密钥
  - 设置环境变量

## 可选准备

- [ ] **一个练习文件夹**
  - 创建用于练习的文件夹
  - 准备一些示例文件

- [ ] **基础编程概念了解**
  - 不需要会编程，但了解基本概念更好
  - 如：变量、函数、文件等

## 检查清单

```bash
# 检查 Node.js
node --version

# 检查 npm
npm --version

# 安装 Claude Code
npm install -g @anthropic-ai/claude-code

# 验证安装
claude --version
```

## 开始学习

准备完成后，就可以开始学习第 1 课了！
