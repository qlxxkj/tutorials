> 📌 **学习目标**：学会用自然语言让 Claude Code 管理文件和文件夹

## 一、文件操作：读、写、改

### 1.1 读取文件

**指令示例：**
```
读取 E:/data/report.txt 的内容
```
```
打开 notes.md，告诉我里面写了什么
```
```
看看这个 CSV 文件里有哪些数据：E:/data/sales.csv
```

Claude 会显示文件内容，并可以根据内容回答你的问题。

### 1.2 创建文件

**指令示例：**
```
在 E:/projects 创建一个新文件 todo.txt，
内容是：待办事项清单
```
```
帮我写一个 Python 脚本 save_data.py，
功能是保存用户输入到 text 文件中
```

### 1.3 修改文件

**指令示例：**
```
在 todo.txt 的最后加上这三条：
- 完成周报
- 回复客户邮件
- 准备明天会议材料
```
```
把 report.txt 里的所有"2025"改成"2026"
```

## 三、批量操作：一次处理多个文件

这是 Claude Code 最强大的能力之一。

### 3.1 批量重命名

**场景：** 100 张截图需要按日期命名。

```
把 E:/screenshots 下所有 .png 文件重命名，
格式：shot_序号.png，序号从 001 开始
```

**场景：** 给所有文件加上项目前缀。

```
把 E:/project 下所有 .txt 文件的文件名前面加上 "proj_"
```

### 3.2 批量转换

**场景：** Word 转 PDF。

```
把 E:/docs 下所有 .docx 文件转换为 .pdf，
输出到 E:/docs/pdf/ 文件夹
```

**场景：** 图片格式转换。

```
把 E:/photos 下所有 .png 图片转换为 .jpg，
质量设为 90%
```

### 3.3 批量查找和替换

**场景：** 在多个文件中查找并替换内容。

```
在 E:/project 的所有 .js 文件中，
把 "oldFunction" 替换为 "newFunction"
```

## 六、实用技巧

### 技巧 1：用通配符描述文件

```
*.txt        # 所有 txt 文件
*.jpg        # 所有 jpg 图片
*2026*       # 文件名包含 2026 的文件
report_*     # 以 report_ 开头的文件
```

### 技巧 2：分批处理大任务

如果文件很多（比如 1000+），可以分批处理：
```
先处理 E:/data 下前 50 个 .csv 文件，
把它们的列名统一为英文
```

### 技巧 3：先查看再操作

对于不确定的操作，可以先让 Claude 列出文件：
```
先帮我列出 E:/downloads 下所有 .pdf 文件，
确认后再移动
```

## 七、本节小结

| 操作类型 | 典型指令 |
|---------|---------|
| 读取文件 | "读取 xxx 文件的内容" |
| 创建文件 | "创建一个 xxx 文件，内容是..." |
| 修改文件 | "把 xxx 里的 yyy 改成 zzz" |
| 创建文件夹 | "创建名为 xxx 的文件夹" |
| 移动文件 | "把 xxx 移到 yyy 文件夹" |
| 批量重命名 | "把所有 .txt 文件重命名为 xxx_序号.txt" |
| 搜索文件 | "找所有包含 yyy 的 .txt 文件" |

**核心原则：用自然语言描述你想做什么，Claude 会帮你完成。**
