# 第 7 课：使用技能完成复杂任务

> 📌 **学习目标**：学会使用 Claude Code 的内置技能（skills）完成复杂任务
> ⏱️ **预计时长**：20 分钟
> 🎯 **本节节奏**：认识技能 → 使用技能 → 自定义技能

---

## 一、什么是技能（Skills）？

技能是 Claude Code 的"工具箱"。

普通的对话是"你问 AI 答"，但技能是"你让 AI 按固定流程做事"。

比如：
- 生成 PPT → 一个技能
- 写博客文章 → 一个技能
- 做数据分析报告 → 一个技能
- 创建网页 → 一个技能

每个技能都有明确的步骤和输出格式，Claude 会按照技能的要求一步步执行。

---

## 二、如何使用技能

### 方法 1：直接调用

在对话中直接使用斜杠命令：
```
/blog 写一篇关于 AI 助力办公的文章
```
```
/ppt 做一个 10 页的 PPT，主题是人工智能发展趋势
```
```
/resume 根据我的经历写一份简历
```

### 方法 2：自然语言描述

你也可以直接描述你想要的技能：
```
帮我用 blog 技能写一篇技术博客
```
```
用 ppt 技能生成一个产品介绍的演示文稿
```

## 三、常用技能详解

### 3.1 博客技能（/blog）

**用途：** 快速生成博客文章

**使用方式：**
```
/blog 写一篇关于远程办公效率提升的文章，
要求 1500 字左右，语气轻松，
包含 3 个实用技巧
```

**输出内容：**
- 标题
- 正文（分段清晰）
- 合适的子标题
- 可选的标签和摘要

### 3.2 PPT 技能（/ppt）

**用途：** 生成演示文稿

**使用方式：**
```
/ppt 做一个 8 页的 PPT，
主题是"AI 如何改变我们的工作方式"，
要求每页有标题、要点和简单的说明
```

**输出内容：**
- 每页 PPT 的内容大纲
- 可以直接用于制作 PPT 的文字
- 可选：生成 HTML 格式的演示文稿

### 3.3 简历技能（/resume）

**用途：** 生成专业简历

**使用方式：**
```
/resume 帮我写一份产品经理的简历，
我的经历：
- 3 年互联网产品经验
- 主导过 2 个从 0 到 1 的项目
- 熟悉数据分析工具
```

**输出内容：**
- 个人信息
- 工作经历
- 项目经验
- 技能清单
- 教育背景

### 3.4 数据分析技能（/dataviz）

**用途：** 数据可视化和分析

**使用方式：**
```
/dataviz 帮我分析 E:/data/sales.csv，
生成图表并保存到 E:/output/ 文件夹
```

**输出内容：**
- 数据分析结果
- 可视化图表（HTML/图片）
- 关键发现总结

## 四、技能的高级用法

### 4.1 组合技能

你可以让 Claude 组合多个技能完成复杂任务：
```
先用 blog 技能写一篇关于 AI 办公的文章，
然后用 ppt 技能把这篇文章做成 10 页的 PPT
```

### 4.2 自定义技能

如果你有经常重复的任务，可以创建自己的技能：
```
帮我创建一个自定义技能，
每次运行这个技能时，
自动完成以下任务：
1. 读取 E:/data/*.csv
2. 统计每个文件的行数和列数
3. 生成一个汇总报告
4. 保存到 E:/output/report.md
```

Claude 会帮你保存这个技能，下次直接运行即可。

### 4.3 修改技能

技能不满意？让 Claude 修改：
```
刚才的 PPT 技能生成的内容太简单了，
帮我改一下，要求每页有详细的说明文字
```

## 五、实战练习

### 练习 1：生成一篇文章

```
/blog 写一篇关于"AI 工具如何帮助普通人提高工作效率"的文章，
要求：
- 1000-1500 字
- 包含 3 个实际案例
- 语气亲切，适合职场人士阅读
- 最后给出行动建议
```

### 练习 2：生成一份 PPT

```
/ppt 做一个 6 页的 PPT，
主题是"Claude Code 入门指南"，
包含：什么是 Claude Code、能做什么、如何使用、实际案例、总结
```

### 练习 3：生成简历

```
/resume 帮我写一份前端开发工程师的简历，
我的经历：
- 2 年前端开发经验
- 熟悉 React 和 Vue
- 参与过 3 个完整项目
- 有团队协作经验
```
