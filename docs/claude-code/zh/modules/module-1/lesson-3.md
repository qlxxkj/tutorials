## 一、什么是 Claude Code？

Claude Code 是一个运行在你电脑终端里的 AI 编程助手。你不需要打开网页，不需要切换窗口——直接在终端里和 AI 对话，让它帮你操作电脑。

### 安装方式

**Windows 用户：**
```bash
npm install -g @anthropic-ai/claude-code
```

**macOS 用户：**
```bash
npm install -g @anthropic-ai/claude-code
```

安装完成后，在终端输入：
```bash
claude
```
即可启动 Claude Code。

## 二、界面认识

启动 Claude Code 后，你会看到这样的界面：

```
 claude

 Welcome to Claude Code!

 What would you like me to help with?
 >
```

### 界面各部分说明

| 区域 | 说明 |
|------|------|
| **提示符 `>`** | 你在这里输入指令，和 AI 对话 |
| **AI 回复区** | Claude 的回答和执行结果会显示在这里 |
| **文件路径** | Claude 会在回复中显示它正在操作的文件 |
| **命令执行** | Claude 执行的终端命令会直接显示出来 |

### 常用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+C` | 取消当前操作 |
| `Ctrl+D` | 退出 Claude Code |
| `/clear` | 清空当前对话 |
| `/help` | 查看帮助 |
| `/model` | 切换 AI 模型 |
| `↑` / `↓` | 上下翻看历史输入 |

## 三、第一次对话：让 AI 帮你做件事

### 示例 1：了解当前目录

在提示符 `>` 后面输入：

```
我现在在哪个文件夹？列出里面的文件。
```

Claude 会执行 `pwd`（显示当前路径）和 `ls`（列出文件），然后告诉你结果。

### 示例 2：创建一个文件

```
在当前目录创建一个名为 hello.txt 的文件，
内容写"你好，Claude Code！"
```

Claude 会：
1. 创建文件
2. 写入内容
3. 告诉你文件已创建

### 示例 3：读取文件

```
读取 hello.txt 的内容，告诉我写了什么。
```

Claude 会读取文件并显示内容。

## 四、Claude Code 的工作原理

理解了这个，你就知道怎么更好地使用它了。

### 工作流程

```
你输入指令
    ↓
Claude 理解你的意图
    ↓
Claude 决定需要做什么（读文件？写代码？运行命令？）
    ↓
Claude 执行操作（在终端运行命令）
    ↓
Claude 告诉你结果
    ↓
你可以继续提问或要求修改
```

### 关键点

1. **Claude 能看到你的文件** — 它会自动读取当前目录的文件
2. **Claude 能运行命令** — 它会在终端执行命令，你看到输出
3. **Claude 能修改文件** — 它可以直接创建、编辑、删除文件
4. **你需要确认** — 对于重要操作（删除文件、修改代码），Claude 会先问你"要这样做吗？"

## 六、常见问题

### Q：Claude Code 会破坏我的文件吗？

**不会。** Claude Code 在执行任何修改操作前，都会先告诉你它要做什么，并等待你的确认。对于删除操作，它会特别谨慎。

### Q：我怎么看 Claude 执行了什么命令？

Claude 执行的每条命令都会显示在终端里。你会看到类似这样的输出：

```
> Reading file: hello.txt
> Writing to file: hello.txt
```

### Q：如果 Claude 做错了怎么办？

直接告诉它！比如：
```
不对，我想要的是另一种格式，请改成...
```
Claude 会根据你的反馈修正。

### Q：我可以同时做多个任务吗？

可以！你可以连续输入多个指令，Claude 会按顺序执行。也可以一次性描述一个复杂任务，Claude 会自己分解步骤。
