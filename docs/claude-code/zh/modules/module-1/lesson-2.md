# 第 2 课：Claude Code 能帮你做什么？

> 📌 **学习目标**：了解 Claude Code 的实际应用场景，找到适合你自己的使用方向
> ⏱️ **预计时长**：20 分钟
> 🎯 **本节节奏**：场景演示 → 分类讲解 → 找到你的用途

---

## 一、办公自动化：告别重复劳动

### 场景 1：整理文件夹

你电脑里有没有这样一个文件夹——下载了三年，文件堆积如山，找东西靠感觉？

**以前：** 一个个打开、分类、创建文件夹、移动文件，耗时半天。

**用 Claude Code：**

```
帮我整理 E:/Downloads 文件夹：
- 图片文件（.jpg .png .gif）移到 images 子文件夹
- 视频文件（.mp4 .mov .avi）移到 videos 子文件夹
- PDF 文件移到 documents
- 压缩包（.zip .rar）移到 archives
- 其他文件按后缀名分类
```

Claude Code 会直接在你的电脑上执行操作，告诉你整理了多少文件，创建了什么文件夹。

### 场景 2：批量处理文件

**需求：** 把 100 张截图重新命名，加上日期前缀。

```
把 E:/screenshots 文件夹下所有 .png 文件重命名，
格式为 2026-08-07_序号.png，从 001 开始编号。
```

**需求：** 把 50 个 Word 文档批量转换成 PDF。

```
把 E:/docs 文件夹下所有 .docx 文件转换为 .pdf，
输出到同目录的 pdf_output 文件夹中。
```

### 场景 3：自动生成报告

**需求：** 从 Excel 数据生成周报。

```
读取 E:/data/sales_2026.xlsx，
统计每个地区的销售额，
生成一个 Markdown 格式的销售报告，
包含数据表格和简要分析。
```

## 二、网页开发：零基础也能建网站

### 场景 4：生成个人作品集网站

**需求：** 我是一个摄影师，帮我做一个个人作品集网站。

Claude Code 可以直接帮你：
- 创建一个完整的 HTML 网站
- 设计响应式布局（手机电脑都好看）
- 添加图片展示画廊
- 包含联系表单和关于页面

```
帮我创建一个摄影师作品集网站，
要求：深色主题、图片网格布局、
包含首页、作品集、关于我、联系方式四个页面，
用 HTML + CSS + JavaScript 实现。
```

### 场景 5：生成数据可视化仪表板

**需求：** 我有销售数据，想做一个可视化仪表板。

```
读取 E:/data/sales.csv，
用 Python 的 matplotlib 生成一个仪表板，
包含：月度销售趋势图、地区占比饼图、
产品销量排名柱状图，
保存为 HTML 文件可以在浏览器中查看。
```

## 三、数据分析：让数据说话

### 场景 6：分析 Excel / CSV 数据

**需求：** 分析客户数据，找出高价值客户。

```
读取 E:/data/customers.csv，
分析客户的消费金额和频率，
找出消费最高的 20% 客户，
生成一份分析报告，包含：
1. 客户分层（高/中/低价值）
2. 各层级的占比和平均消费
3. 建议的营销策略
```

### 场景 7：数据处理和清洗

**需求：** 数据有缺失值和异常值，需要清洗。

```
读取 E:/data/raw_data.csv，
1. 找出缺失值超过 30% 的列并删除
2. 将日期列统一格式为 YYYY-MM-DD
3. 去除金额列中负数的异常值
4. 保存清洗后的数据到 clean_data.csv
```

## 四、代码学习：让 AI 当你的私教

### 场景 8：解释一段代码

你拿到一段代码，看不懂在干什么？

```
帮我解释这段 Python 代码在做什么，
用简单的语言，不要假设我知道编程术语。
```

Claude Code 会：
1. 逐行解释代码逻辑
2. 用生活化的比喻帮助理解
3. 指出代码中可能的改进点

### 场景 9：学习新概念

**需求：** 我想了解什么是"API"，用给小学生讲故事的语气解释。

```
用讲故事的方式给我解释什么是 API，
假设我是一个完全不懂技术的人。
```

### 场景 10：调试代码错误

**需求：** 我的代码报错了，帮我找出问题。

```
这个 Python 脚本运行时报错：
"TypeError: can't multiply sequence by non-int of type 'float'"
请帮我找出问题并修复。
```

## 五、写作与内容创作

### 场景 11：写邮件和文案

**需求：** 写一封商务邮件。

```
帮我写一封邮件，内容是：
- 收件人：客户张经理

  提出下季度有新的合作方案想讨论，
```

**需求：** 为新产品写一篇小红书笔记。

```
帮我写一篇小红书笔记，推广一款新的智能手表，

- 标题吸引眼球
```

请选择以下至少一个任务，在 Claude Code 中尝试：

1. **整理文件夹**：把你电脑上的一个文件夹按文件类型分类整理
