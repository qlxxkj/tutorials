# 第 1 课：AI 编程助手是什么？

> ⏱️ **预计时长**：15 分钟
> 🎯 **本节节奏**：先体验 → 后讲解 → 再实操

## 一、先体验：让 AI 帮你做件事

在开始之前，我想让你先感受一下"让 AI 帮你干活"是什么感觉。

假设你有一个文件夹，里面有几十个文件名乱七八糟的文件，你想按类型整理好。以前你可能需要一个个手动移动，现在——

**打开 Claude Code，输入下面这句话：**

```
帮我整理 E:/myfiles 文件夹，把所有 .jpg 和 .png 移到 images 文件夹，把所有 .mp4 和 .mov 移到 videos 文件夹，其它文件按后缀名创建对应文件夹。
```

看看 AI 是怎么做的——它会直接在你的电脑上执行命令，创建文件夹，移动文件，最后告诉你完成了多少。

**你没有写一行代码，但你让它帮你完成了一个繁琐的整理任务。**

这就是 AI 编程助手的威力。

## 二、从"聊天机器人"到"能帮你干活的智能体"

### 2.1 聊天机器人 vs AI 编程助手

你可能用过 ChatGPT、文心一言、通义千问这类 AI 工具。它们有一个共同特点：**只能和你聊天**。

你问它问题，它给你文字回复。你可以让它写代码片段，但代码能不能跑、怎么跑、在哪里跑——它不管。

**AI 编程助手（比如 Claude Code）不一样。** 它不仅"能聊"，还能"能干"：

| 能力 | 聊天机器人 | AI 编程助手（Claude Code） |
|------|-----------|---------------------------|
| 回答问题 | ✅ | ✅ |
| 写代码片段 | ✅ | ✅ |
| 读你的项目文件 | ❌ | ✅ |
| 运行代码并调试 | ❌ | ✅ |
| 操作电脑上的文件 | ❌ | ✅ |
| 调用外部工具 | ❌ | ✅ |
| 完成完整任务 | ❌ | ✅ |
| 创建网站、应用 | ❌ | ✅ |

### 2.2 Claude Code 到底是什么？

**Claude Code 是 Anthropic 推出的 AI 编程智能体（coding agent）。**

注意两个关键词：

- **编程**：它的核心能力围绕代码和文件展开——读代码、写代码、调试代码、解释代码、操作文件
- **智能体（Agent）**：它不是被动回答问题的工具，而是能主动执行任务的"助手"

你可以把 Claude Code 想象成一个**会编程的实习生**：

- 你告诉它要做什么（用自然语言）
- 它自己去读相关文件、写代码、运行测试、发现问题、修正错误
- 最后把成果交给你

**你不需要教它编程知识，你只需要告诉它你要什么。**

## 三、生活中的类比

如果还是觉得抽象，我们用几个生活场景来理解：

### 类比 1：Claude Code = 会编程的实习生

你是一家公司的新人主管，招了一个实习生。这个实习生：

- 会写代码
- 能读你给的文件
- 能自己想办法解决问题
- 做错了你会告诉他，他会改
- 做完会把成果交给你审核

**Claude Code 就是这个实习生。** 你不需要会编程，你只需要像主管一样"提需求"。

### 类比 2：Claude Code = 万能秘书

你的秘书能帮你：

- 整理文件（按类型、日期分类）
- 搜索资料（上网查资料并整理成报告）
- 写邮件（根据你给的要点自动生成）
- 做网页（你说想要什么样式，她帮你做出一个网站）

**Claude Code 就是这个秘书，只不过它额外还会写代码、操作电脑。**

### 类比 3：Claude Code = 乐高积木 + 说明书

假设你想搭一个乐高城堡：

- **传统方式**：你自己一块一块拼，需要看懂说明书
- **Claude Code 方式**：你告诉它"我要一个带塔楼和城墙的城堡"，它帮你拼好，你只管验收

## 四、Claude Code 能帮你做什么？

### 办公场景

| 任务 | 用 Claude Code 怎么说 |
|------|----------------------|
| 整理文件夹 | "把Downloads文件夹里的图片移到Pictures，视频移到Videos" |
| 批量重命名 | "把当前文件夹下所有文件按日期重命名为 2026-08-07_001.jpg 这种格式" |
| 生成报表 | "读取这个 Excel 文件，统计每个月的销售额，生成一个汇总表" |
| 写邮件 | "根据这封邮件的内容，帮我写一封回复，语气要正式礼貌" |
| 做 PPT | "帮我用 Python 生成一个 10 页的 PPT，主题是人工智能发展趋势" |

### 编程场景（不需要你会编程）

| 任务 | 用 Claude Code 怎么说 |
|------|----------------------|
| 写一个小工具 | "帮我写一个 Python 脚本，自动备份指定文件夹到云盘" |
| 改一个网页 | "把这个 HTML 页面的背景改成深蓝色，字体改成微软雅黑" |
| 分析数据 | "读取这个 CSV 文件，找出销售额最高的前 10 名，做成图表" |
| 调试问题 | "这个脚本运行报错 'File not found'，帮我看看哪里出了问题" |

### 学习场景

| 任务 | 用 Claude Code 怎么说 |
|------|----------------------|
| 解释概念 | "用简单的话解释一下什么是 API，不要用什么技术术语" |
| 写学习笔记 | "帮我整理这份文档的要点，做成思维导图的格式" |
| 练习对话 | "用英语和我对话，帮我纠正语法错误" |
| 写简历 | "根据我的工作经历，帮我写一份求职简历，投递岗位是产品经理" |

## 五、和 ChatGPT 有什么区别？

很多人会问：**"我已经有 ChatGPT 了，为什么还要用 Claude Code？"**

区别在于：

| 对比项 | ChatGPT | Claude Code |
|--------|---------|-------------|
| 工作位置 | 网页 / App | 你的电脑终端 |
| 能读你的文件 | ❌ | ✅ |
| 能运行代码 | ❌ | ✅ |
| 能操作文件夹 | ❌ | ✅ |
| 能创建网站 | 只能给代码 | 直接帮你建好 |
| 需要你懂编程 | 不需要 | 不需要 |
| 适合场景 | 聊天、查资料、写文案 | 实际操作电脑、处理文件、写程序 |

**简单说：ChatGPT 是"问你答"，Claude Code 是"你提需求它干活"。**

## 六、本节小结

| 知识点 | 核心内容 |
|--------|---------|
| AI 编程助手 vs 聊天机器人 | 前者能干活，后者只能聊天 |
| Claude Code 的核心定位 | Anthropic 的 AI 编程智能体，能读文件、写代码、运行命令 |
| 和普通 ChatGPT 的区别 | 能操作你的电脑，完成实际任务 |
| 类比理解 | Claude Code = 会编程的实习生 / 万能秘书 |
