# 第 12 课：实际项目——搭建个人知识库

> 📌 **学习目标**：用 Claude Code 完成一个完整的项目，整合所学知识
> ⏱️ **预计时长**：30 分钟
> 🎯 **本节节奏**：项目说明 → 分步实现 → 总结

---

## 一、项目目标

我们要搭建一个**个人知识库系统**，包含以下功能：
1. 存储学习笔记和资料
2. 按标签分类管理
3. 支持全文搜索
4. 自动生成索引

---

## 二、分步实现

### 步骤 1：创建项目结构

```
帮我创建一个名为 knowledge-base 的项目，
包含以下目录：
- notes（笔记文件夹）
- tags（标签文件夹）
- search（搜索索引）
- output（输出文件夹）
```

### 步骤 2：创建笔记模板

```
在 notes 文件夹下创建一个笔记模板 note-template.md，
包含：
- 标题
- 日期
- 标签
- 正文
- 链接
```

### 步骤 3：添加示例笔记

```
帮我创建 5 条示例笔记，
主题分别是：
1. Python 基础语法（标签：python, 编程）
2. AI 发展趋势（标签：ai, 科技）
3. 时间管理方法（标签：效率, 个人成长）
4. 产品设计原则（标签：设计, 产品）
5. 数据分析技巧（标签：data, 分析）
```

### 步骤 4：创建搜索脚本

```
帮我写一个 Python 搜索脚本 search.py，
功能是：
1. 读取 notes 文件夹下所有 .md 文件
2. 支持关键词搜索
3. 显示匹配的标题、标签和摘要
4. 输出为表格格式
```

### 步骤 5：创建索引脚本

```
帮我写一个 Python 索引脚本 index.py，
功能是：
1. 扫描所有笔记文件
2. 提取标签
3. 生成标签索引文件 tags-index.md
4. 生成日期索引文件 date-index.md
```

### 步骤 6：创建主页

```
帮我创建一个 HTML 主页 index.html，
功能是：
1. 显示知识库概览（笔记数量、标签数量）
2. 提供搜索框（前端搜索）
3. 显示最近更新的笔记
4. 简洁美观的风格
```

---

## 三、完整项目结构

完成后，你的项目结构应该是：

```
knowledge-base/
├── notes/
│   ├── note-template.md
│   ├── python-basics.md
│   ├── ai-trends.md
│   ├── time-management.md
│   ├── design-principles.md
│   └── data-analysis.md
├── tags/
├── search/
├── output/
├── search.py
├── index.py
└── index.html
```

---

## 四、扩展功能

完成基础版本后，可以尝试添加：

### 4.1 自动备份

```
帮我创建一个备份脚本，
每天自动把 notes 文件夹打包备份到 output/backup/
```

### 4.2 标签云

```
在主页上添加一个标签云，
显示所有标签及其使用频率
```

### 4.3 统计面板

```
帮我创建一个统计面板，
显示：
- 总笔记数
- 本月新增数
- 最活跃的标签
- 平均笔记长度
```
