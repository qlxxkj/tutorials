# 第 8 课：提示词工程——让 AI 更懂你

> 📌 **学习目标**：学会写出高质量的提示词，让 Claude Code 更准确地完成任务
> ⏱️ **预计时长**：20 分钟
> 🎯 **本节节奏**：原理 → 公式 → 实战

---

## 一、为什么同样的指令，效果差别很大？

**差的指令：**
```
帮我写个脚本
```

**好的指令：**
```
帮我写一个 Python 脚本，
功能是：读取 E:/data/sales.csv，
统计每个产品的总销售额，
按销售额从高到低排序，
把结果保存为 result.txt
```

区别在哪？好的指令包含了：
1. **具体动作**（写脚本）
2. **输入**（哪个文件）
3. **处理逻辑**（统计、排序）
4. **输出**（保存到哪里）

## 二、提示词公式

### 2.1 基础公式：ACTOR

| 要素 | 说明 | 示例 |
|------|------|------|
| **A**ction（动作） | 你要 AI 做什么 | "帮我写一个 Python 脚本" |
| **C**ontext（背景） | 为什么做、在什么场景 | "用于自动处理每日销售数据" |
| **T**arget（目标） | 期望的结果是什么 | "输出按销售额排序的表格" |
| **O**utput（输出） | 输出格式和位置 | "保存为 E:/output/report.txt" |
| **R**estrictions（限制） | 有什么要求或限制 | "不要用第三方库" |

### 2.2 完整示例

```
[动作] 帮我写一个 Python 脚本
[背景] 用于自动处理每日销售数据，替代手工整理
[目标] 读取销售 CSV，统计各产品销售额并排序
[输出] 保存为 Markdown 报告到 E:/output/
[限制] 不使用第三方库，代码要有中文注释
```

## 三、进阶技巧

### 技巧 1：给出示例数据

```
输入数据格式示例：
日期,产品,数量,单价
2026-08-01,笔记本电脑,2,5999
2026-08-01,鼠标,5,89
2026-08-02,键盘,3,299

请帮我写一个脚本处理这种格式的数据
```

### 技巧 2：指定输出格式

```
输出格式要求：
- 使用 Markdown 表格
- 包含列：产品名称、总销售额、占比
- 底部加上合计行
- 用人民币符号 ¥
```

### 技巧 3：分步骤描述

```
请帮我完成以下任务，按步骤执行：
步骤 1：读取 E:/data/sales.csv
步骤 2：计算每个产品的总销售额
步骤 3：按销售额降序排列
步骤 4：生成报告并保存
```

### 技巧 4：设定角色

```
你是一位数据分析师，
请帮我分析这份销售数据...
```

### 技巧 5：明确不做的事情

```
请帮我写一个网页，
要求：
- 使用纯 HTML + CSS
- 不要使用任何框架（如 React、Vue）
- 不要引用外部 CDN
- 代码要简洁易读
```

## 四、常见场景的提示词模板

### 场景 1：写 Python 脚本

```
帮我写一个 Python 脚本 {文件名}，
功能是：{具体功能描述}，
输入：{数据来源}，
输出：{输出位置和格式}，
限制：{特殊要求}
```

### 场景 2：处理 Excel/CSV

```
读取 {文件路径}，
执行以下操作：
1. {操作1}
2. {操作2}
3. {操作3}
结果保存为 {输出路径}
```

### 场景 3：生成网页

```
帮我创建一个 {页面类型} 页面，
要求：
- 主题：{主题描述}
- 风格：{风格描述，如简洁/商务/科技感}
- 包含内容：{内容列表}
- 技术：{技术栈要求，如纯 HTML/CSS}
```

### 场景 4：数据分析

```
分析 {数据文件}，
帮我找出：
1. {分析点1}
2. {分析点2}
3. {分析点3}
用表格和文字总结关键发现
```

## 五、写好提示词的 5 个原则

### 原则 1：具体明确
❌ "帮我处理数据"
✅ "帮我统计 E:/data/sales.csv 中每个产品的总销售额"

### 原则 2：给出背景
❌ "写个脚本"
✅ "我需要每天整理销售数据，帮我写一个自动化脚本"

### 原则 3：说明输出
❌ "生成报告"
✅ "生成 Markdown 格式的报告，保存到 E:/output/report.md"

### 原则 4：列出限制
❌ "用 Python 写"
✅ "用 Python 写，不使用第三方库，代码要有注释"

### 原则 5：迭代优化
第一版不满意？继续说：
```
这个脚本可以，但我想：
1. 加上错误处理
2. 输出格式改成表格
3. 加上日志记录
```

## 六、本节小结

| 原则 | 说明 |
|------|------|
| ACTOR 公式 | Action + Context + Target + Output + Restrictions |
| 给示例 | 示例数据比文字描述更清晰 |
| 分步骤 | 复杂任务拆成步骤，一步步说 |
| 说限制 | 告诉 AI 什么不能做，和要做什么一样重要 |
| 迭代优化 | 不满意就继续说，AI 会记住上下文 |
