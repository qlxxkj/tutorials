# 第 10 课：自动化工作流

> 📌 **学习目标**：学会设计自动化工作流，让 Claude Code 一次性完成复杂任务
> ⏱️ **预计时长**：25 分钟
> 🎯 **本节节奏**：概念 → 设计 → 实现

---

## 一、什么是自动化工作流？

自动化工作流 = 把重复性的多步骤任务，打包成一个"一键执行"的流程。

**举例：**
- 每周生成周报 → 自动读取数据 → 生成报告 → 发送邮件
- 每天整理下载文件夹 → 自动分类 → 清理过期文件
- 每月生成财务报表 → 自动汇总 → 生成图表 → 保存归档

---

## 二、设计工作流的步骤

### 步骤 1：拆解任务

把一个大任务拆成小步骤：

**例子：每周销售周报**

```
大任务：生成周报
├── 步骤 1：读取本周销售数据（CSV）
├── 步骤 2：统计各产品销售额
├── 步骤 3：计算环比变化
├── 步骤 4：生成 Markdown 报告
└── 步骤 5：保存到指定文件夹
```

### 步骤 2：描述每一步

用自然语言描述每一步要做什么：

```
步骤 1：读取 E:/data/weekly/*.csv
步骤 2：按产品分组统计销售额
步骤 3：和上周数据对比，计算变化率
步骤 4：生成包含图表的 Markdown 报告
步骤 5：保存到 E:/output/reports/
```

### 步骤 3：让 Claude 执行

把完整的描述交给 Claude Code，它会一步步执行。

## 三、实战示例

### 示例 1：每日数据备份

```
帮我创建一个每日备份工作流：

背景：
我每天会产生新的数据文件在 E:/work/data/，
需要定期备份到 E:/backup/。

工作流：
1. 扫描 E:/work/data/ 下今天新增的文件
2. 按文件类型分类（图片、文档、表格）
3. 复制到 E:/backup/YYYY-MM-DD/ 对应子文件夹
4. 记录备份日志到 E:/backup/log.txt
5. 输出备份统计（共备份多少个文件）
```

### 示例 2：每周报告生成

```
帮我创建一个每周报告工作流：

背景：
每周一需要生成上周的销售报告。

工作流：
1. 读取 E:/data/sales_2026-W32.csv
2. 统计：
   - 总销售额
   - 各产品销售额排名
   - 与上周的环比变化
3. 生成 Markdown 报告，包含：
   - 本周概览
   - TOP5 产品
   - 环比分析
   - 建议
4. 保存到 E:/reports/weekly/
5. 同时生成一个简单的 HTML 版本
```

### 示例 3：文件清理工作流

```
帮我创建一个文件清理工作流：

背景：
E:/downloads 文件夹太乱了，需要定期清理。

工作流：
1. 找出超过 30 天未修改的文件
2. 按文件类型分类统计
3. 删除临时文件（.tmp .temp .bak）
4. 把长期未访问的文件移到 E:/archive/
5. 输出清理报告（删除了多少、移走了多少）
```

## 四、设计工作流的原则

### 原则 1：从简单开始

不要一次设计一个超复杂的工作流。先从简单的开始：
```
先帮我自动整理这个文件夹
```
然后逐步添加功能：
```
再加一个功能：自动删除超过 30 天的文件
```

### 原则 2：每一步都要明确

❌ 模糊：
```
帮我处理这些文件
```

✅ 明确：
```
读取 E:/data 下所有 .csv 文件，
过滤出销售额大于 1000 的记录，
保存到 E:/output/filtered.csv
```

### 原则 3：先测试再自动化

对于重要的工作流，先让 Claude 一步步执行，确认结果正确后，再让它自动化。

### 原则 4：加入错误处理

```
在执行每一步之前，先检查：
- 文件是否存在
- 路径是否正确
- 是否有足够的权限
如果某一步失败，输出错误信息并继续下一步
```

## 五、高级技巧

### 技巧 1：创建可复用脚本

```
帮我写一个通用的文件整理脚本，
输入参数：源文件夹、目标文件夹、文件类型
这样我以后可以直接用，不用每次都重新描述
```

### 技巧 2：设置定时任务

```
帮我创建一个 Python 脚本，
每天上午 9 点自动执行文件整理工作流，
可以用 Windows 任务计划程序来设置定时
```

### 技巧 3：日志和监控

```
在工作流中加入日志记录，
每完成一步都输出日志，
这样我可以知道哪里出了问题
```

## 六、本节小结

| 要点 | 说明 |
|------|------|
| 工作流是什么 | 把多步骤任务打包成一键执行的流程 |
| 设计步骤 | 拆解任务 → 描述每一步 → 让 AI 执行 |
| 原则 | 从简单开始、步骤明确、先测试再自动化 |

## 七、课后练习

**练习：设计你的第一个工作流**

请设计一个自动化工作流，解决你工作中的一个重复性问题。

**步骤：**
1. 描述你的问题和背景
2. 拆解成 3-5 个步骤
3. 用自然语言描述每一步
4. 输入 Claude Code，让它帮你实现

**提示：** 可以从以下场景选择：
- 每日数据汇总
- 每周报告生成
- 文件自动分类
- 邮件自动回复
- 社交媒体内容发布
