# 第 9 课：Web 搜索与信息收集

> 📌 **学习目标**：学会让 Claude Code 联网搜索信息并整理成报告
> ⏱️ **预计时长**：15 分钟
> 🎯 **本节节奏**：搜索 → 整理 → 报告

---

## 一、Claude Code 能联网吗？

可以！Claude Code 支持联网搜索，帮你：
- 查找最新信息
- 收集竞品资料
- 调研市场趋势
- 整理新闻热点
- 查找技术资料

---

## 二、基础搜索指令

### 2.1 简单搜索

```
搜索一下 2026 年 AI 发展趋势的最新报告
```
```
查一下 Python 3.12 有哪些新特性
```
```
搜索最近半年大模型价格的变化
```

### 2.2 对比搜索

```
对比一下 Claude、GPT-4 和 Gemini 的价格和性能
```
```
搜索市面上主流的 AI 写作工具，列出它们的优缺点
```

### 2.3 深度搜索

```
搜索关于"AI 如何改变办公方式"的文章，
要求：
- 至少搜索 5 篇相关文章
- 整理成一份报告
- 包含主要观点和数据来源
```

---

## 三、搜索 + 整理 = 报告

这是 Claude Code 最实用的能力之一。

### 示例 1：竞品分析报告

```
帮我调研一下市场上的 AI 视频翻译工具，
要求：
1. 搜索至少 5 个相关产品
2. 整理成对比表格（产品名称、功能、价格、优缺点）
3. 给出我的推荐建议
4. 输出为 Markdown 格式
```

### 示例 2：行业研究报告

```
搜索 2026 年中国 AI 办公市场的最新动态，
帮我写一份简短的行业分析，
包含：市场规模、主要玩家、发展趋势、机会点
```

### 示例 3：技术选型报告

```
我正在选型一个 AI 编程助手，
请搜索 Claude Code、Cursor、Copilot 的对比信息，
帮我写一份选型建议，
包含：功能对比、价格对比、适用场景
```

---

## 四、搜索 + 写作 = 内容

### 示例 4：博客素材收集

```
帮我搜索关于"AI 改变工作方式"的最新文章，
收集 10 个关键观点和案例，
整理成博客素材格式
```

### 示例 5：会议资料准备

```
下周我要开一个关于 AI 应用的部门会议，
帮我搜索一下：
1. 行业内 AI 应用的最新案例
2. AI 带来的效率提升数据
3. 常见的 AI 应用场景
整理成会议 PPT 的大纲
```

## 五、搜索技巧

### 技巧 1：指定搜索范围

```
在 GitHub 上搜索 Python 视频处理的开源项目
```
```
搜索技术博客中关于 RAG 架构的文章
```

### 技巧 2：指定时间范围

```
搜索最近 3 个月的 AI 新闻
```
```
查找 2026 年最新的大模型评测报告
```

### 技巧 3：指定语言

```
搜索中文技术博客中关于 Prompt Engineering 的文章
```
```
查找英文资料中关于 AI agents 的最佳实践
```

### 技巧 4：多轮搜索

第一轮：
```
搜索一下当前主流的 AI 编程助手有哪些
```

第二轮（基于结果继续）：
```
深入搜索 Cursor 和 Claude Code 的详细对比
```

第三轮：
```
根据搜索结果，帮我写一份选型报告
```

## 六、实战练习

### 练习 1：竞品调研

```
帮我调研一下市场上的 AI 会议记录工具，
搜索至少 5 个产品，
整理成对比表格，
包含：产品名称、核心功能、价格、适合场景
```

### 练习 2：技术趋势报告

```
搜索 2026 年 AI 领域的 5 个重要趋势，
每个趋势用 200 字左右描述，
最后给出我的个人总结
```

### 练习 3：综合任务

```
我要写一份关于"AI 工具提升办公效率"的内部分享材料，
帮我：
1. 搜索 AI 办公工具的最新进展
2. 收集 3-5 个实际案例
3. 整理成分享大纲（包含标题、要点、案例）
4. 输出为 Markdown 格式
```
