# 第 15 课：个人财务追踪器

> 📌 **学习目标**：完成一个实用的个人财务管理工具
> ⏱️ **预计时长**：30 分钟
> 🎯 **本节节奏**：需求分析 → 数据管理 → 可视化 → 报告生成

---

## 一、项目背景

记账是很多人坚持不下去的事情。为什么？因为太麻烦了。

我们用 Claude Code 创建一个**自动化财务追踪系统**，让记账变得简单。

---

## 二、项目目标

创建一个财务追踪系统，包含：
1. 快速记账（支持语音/文字输入）
2. 自动分类
3. 数据可视化
4. 月度报告

---

## 三、分步实现

### 步骤 1：创建数据文件

```
帮我创建一个财务数据文件 expenses.csv，
包含以下列：
日期,金额,类型,分类,备注,支付方式
```

写入 10 条示例数据（餐饮、交通、购物、娱乐等）。

### 步骤 2：创建记账脚本

```
帮我写一个 Python 脚本 add_expense.py，
功能是：
1. 接收用户输入（金额、类型、备注）
2. 自动添加日期和支付方式
3. 保存到 expenses.csv
4. 输出确认信息
```

### 步骤 3：自动分类

```
帮我写一个 Python 脚本 auto_categorize.py，
功能是：
1. 读取 expenses.csv
2. 根据备注内容自动判断分类
3. 更新分类列
4. 显示分类结果
```

### 步骤 4：数据可视化

```
帮我写一个 Python 脚本 visualize.py，
功能是：
1. 读取 expenses.csv
2. 生成月度支出饼图
3. 生成支出趋势折线图
4. 生成分类占比柱状图
5. 保存到 output/ 文件夹
```

### 步骤 5：生成月度报告

```
帮我写一个 Python 脚本 monthly_report.py，
功能是：
1. 读取本月所有支出记录
2. 统计各分类支出
3. 计算总支出和日均支出
4. 与上月对比
5. 生成 Markdown 格式的月度报告
6. 保存到 output/reports/ 文件夹
```
