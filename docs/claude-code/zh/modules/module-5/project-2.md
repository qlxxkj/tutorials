# 第 14 课：自动化内容发布

> 📌 **学习目标**：学会让 Claude Code 自动发布内容到多个平台
> ⏱️ **预计时长**：25 分钟
> 🎯 **本节节奏**：需求分析 → 内容生成 → 多平台发布

---

## 一、项目背景

假设你是一个内容创作者，每天需要在多个平台发布内容：
- 微信公众号
- 小红书
- 知乎
- 微博

手动发布很耗时，我们可以用 Claude Code 自动化。

---

## 二、项目目标

创建一个自动化内容发布系统：
1. 根据主题自动生成内容
2. 适配不同平台的格式要求
3. 自动发布到各平台

---

## 三、分步实现

### 步骤 1：创建内容模板

```
帮我创建一个内容模板，
包含：
- 标题（吸引眼球的）
- 正文（分段落）
- 标签（3-5 个）
- 配图建议
```

### 步骤 2：生成内容脚本

```
帮我写一个 Python 脚本 generate_content.py，
功能是：
1. 接收一个主题
2. 生成适合不同平台的内容
3. 微信公众号：800-1500 字，分段落
4. 小红书：300-500 字，多用 emoji
5. 知乎：500-1000 字，有观点有论证
6. 微博：140 字以内，简洁有力
7. 输出为 JSON 格式
```

### 步骤 3：适配平台格式

```
帮我写一个 Python 脚本 format_content.py，
功能是：
1. 读取 generate_content.py 生成的内容
2. 根据平台要求调整格式
3. 微信公众号：添加排版标签
4. 小红书：添加话题标签
5. 知乎：添加引用和代码块
6. 微博：添加合适的 emoji
```

### 步骤 4：创建发布脚本

```
帮我写一个 Python 脚本 publish.py，
功能是：
1. 读取格式化后的内容
2. 通过 API 发布到各平台
3. 记录发布状态
4. 输出发布报告
```

---

## 四、完整流程

```
输入主题 → generate_content.py → format_content.py → publish.py
                                          ↓
                              各平台内容适配
                                          ↓
                              API 自动发布
```

---

## 五、本节小结

| 知识点 | 核心内容 |
|--------|---------|
| 内容生成 | AI 可以根据主题自动生成不同风格的内容 |
| 格式适配 | 不同平台有不同的格式要求，需要适配 |
| API 发布 | 通过平台 API 实现自动发布 |
| 报告记录 | 记录发布状态，便于追踪 |
