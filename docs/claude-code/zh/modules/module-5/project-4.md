# 第 16 课：会议记录助手

> 📌 **学习目标**：完成一个智能会议记录系统
> ⏱️ **预计时长**：25 分钟
> 🎯 **本节节奏**：需求分析 → 语音转文字 → 智能摘要 → 任务提取

---

## 一、项目背景

开会是现代工作的重要组成部分，但记会议记录很费时。我们可以用 AI 自动化。

---

## 二、项目目标

创建一个会议记录助手，自动完成：
1. 语音转文字（转录）
2. 智能摘要
3. 提取待办事项
4. 生成会议纪要

---

## 三、分步实现

### 步骤 1：创建会议记录模板

```
帮我创建一个会议记录模板 meeting-template.md，
包含：
- 会议主题
- 日期时间
- 参会人员
- 会议内容（分点记录）
- 达成的共识
- 待办事项（责任人 + 截止日期）
- 下次会议时间
```

### 步骤 2：语音转录脚本

```
帮我写一个 Python 脚本 transcribe.py，
功能是：
1. 接收音频文件（mp3/wav）
2. 使用语音识别 API 转成文字
3. 输出转录文本
4. 保存为 txt 文件
```

### 步骤 3：智能摘要脚本

```
帮我写一个 Python 脚本 summarize.py，
功能是：
1. 读取转录文本
2. 使用 AI 生成会议摘要
3. 提取关键决策点
4. 输出结构化摘要
```

### 步骤 4：任务提取脚本

```
帮我写一个 Python 脚本 extract_tasks.py，
功能是：
1. 读取会议内容
2. 识别所有待办事项
3. 提取责任人（如果有）
4. 提取截止日期（如果有）
5. 输出任务列表
```

### 步骤 5：生成会议纪要

```
帮我写一个 Python 脚本 generate_minutes.py，
功能是：
1. 读取摘要和任务列表
2. 按照会议记录模板生成完整纪要
3. 保存到 output/meetings/ 文件夹
```

---

## 四、完整流程

```
会议录音 → 语音转录 → 智能摘要 → 任务提取 → 会议纪要
```

---

## 五、本节小结

| 知识点 | 核心内容 |
|--------|---------|
| 语音转录 | AI 可以把语音转成文字 |
| 智能摘要 | AI 可以从长文本中提取关键点 |
| 任务提取 | AI 可以识别待办事项和责任人 |
| 纪要生成 | 自动按照模板生成完整会议纪要 |
