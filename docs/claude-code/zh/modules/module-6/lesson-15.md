# 第 15 课：总结与进阶

> 📌 **学习目标**：回顾整个课程内容，规划下一步学习方向
> ⏱️ **预计时长**：20 分钟
> 🎯 **本节节奏**：回顾 → 总结 → 进阶路线

## 一、课程回顾

### 我们学了什么？

| 模块 | 内容 | 核心收获 |
|------|------|---------|
| 模块一 | 认识 Claude Code | 理解 AI 编程助手是什么，能和传统聊天机器人区分 |
| 模块二 | 基础操作 | 学会用自然语言管理文件、写代码、调试 |
| 模块三 | 进阶技巧 | 掌握提示词工程、Web 搜索、自动化工作流 |
| 模块四 | 最佳实践 | 学会和 AI 高效协作，避免常见错误 |
| 模块五 | 项目实战 | 完成 4 个完整项目，整合所学知识 |
| 模块六 | 总结进阶 | 回顾课程，规划学习方向 |

### 核心能力清单

学完本课程，你应该能够：

- [ ] 安装和启动 Claude Code
- [ ] 用自然语言管理文件和文件夹
- [ ] 用自然语言写 Python 脚本
- [ ] 让 Claude Code 帮你调试代码
- [ ] 使用技能完成复杂任务（PPT、博客、简历）
- [ ] 让 Claude Code 联网搜索信息
- [ ] 设计自动化工作流
- [ ] 完成完整的项目开发

## 四、持续练习建议

### 每日练习

每天花 15 分钟，让 Claude Code 帮你完成一个实际任务：
- 整理今天收到的邮件
- 生成明天的待办清单
- 写一段处理数据的代码

### 每周项目

每周完成一个小项目：
- 第一周：整理电脑文件夹
- 第二周：生成一个周报脚本
- 第三周：创建一个个人博客页面
- 第四周：完成一个自动化工作流

### 每月进阶

每月学习一个新技能：
- 第一个月：掌握基础操作
- 第二个月：学会写简单脚本
- 第三个月：设计自动化工作流
- 第四个月：完成一个完整项目
