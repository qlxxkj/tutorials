# Claude Code 入门教程

> 面向零编程基础的职场人士和内容创作者  
> 用自然语言，让 AI 成为你的私人助手

---

## 课程简介

你有没有过这样的经历？

- 想写个小工具整理文件，但不会编程
- 要做一份报告，从找资料到排版折腾半天
- 想分析一堆数据，Excel 公式翻遍搜索引擎还是搞不定
- 听说 AI 能帮人写代码、做办公，但自己完全不知道从哪里开始

如果你中了一条以上，这门课就是为你准备的。

**Claude Code 是 Anthropic 推出的 AI 编程智能体（coding agent）。** 它不是简单的"聊天机器人"，也不是只会补全代码的工具——它能读你的项目、写代码、运行命令、调用工具，甚至能帮你整理电脑文件夹、生成 PPT、做数据分析。

更重要的是：**你不需要会编程**。只要你会说人话，就能用 Claude Code 完成这些任务。

---

## 课程结构

本课程共 **6 个模块**，约 **16 节课 + 4 个实战项目**：

| 模块 | 内容 | 时长 |
|------|------|------|
| 模块一 | 认识 Claude Code | 45 分钟 |
| 模块二 | 基础操作 | 60 分钟 |
| 模块三 | 进阶技巧 | 90 分钟 |
| 模块四 | 最佳实践 | 45 分钟 |
| 模块五 | 项目实战 | 120 分钟 |
| 模块六 | 总结与进阶 | 30 分钟 |

**总计约 5-7 小时**，可分模块学习。

## 学完你能做到什么？

- ✅ 让 Claude Code 帮你整理文件夹、批量重命名、归类文件
- ✅ 用自然语言描述需求，让 Claude Code 生成 Python 脚本
- ✅ 让 Claude Code 联网搜索资料并整理成报告
- ✅ 让 Claude Code 执行重复性任务，节省时间
- ✅ 使用技能快速完成复杂任务（如生成 PPT、写简历）
- ✅ 独立完成 4 个实战项目
