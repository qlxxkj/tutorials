# Claude Code Beginner Tutorial — Course Overview

> For working professionals and content creators with zero programming background  
> Use natural language to make AI your personal assistant

---

## Course Overview

This course systematically teaches **Claude Code** — Anthropic's AI coding agent. It's not just a chatbot, but a smart assistant that can read files, write code, run commands, and operate your computer.

**Key advantage:** No programming knowledge needed. As long as you can speak naturally, you can let AI complete various tasks.

## Learning Paths

### Complete Path (Recommended)

Study in module order, total about 5-7 hours.

### Crash Course (Short on time)

1. **Module 1** (Understanding) → 15 min
2. **Module 2** (Basic Operations) → 30 min
3. **Module 5 · Project 1** (Build Knowledge Base) → 20 min

You'll master the most practical features.
