# Appendix: Glossary

## A

**Agent**
An AI system capable of autonomously completing tasks. Unlike simple chatbots, Agents can actively execute operations, call tools, and complete complex tasks.

**API (Application Programming Interface)**
An interface for communication between different software. Claude Code communicates with Anthropic's AI models through APIs.

## C

**Claude Code**
Anthropic's AI coding agent that runs in the terminal and can operate your computer, write code, and execute tasks through natural language instructions.

**Context**
The background information of a conversation. Claude Code remembers previous conversation content to understand the context of current tasks.

## G

**GUI (Graphical User Interface)**
A way to interact with computers through graphical interfaces. Claude Code is primarily command-line based, but there are also GUI tools.

## N

**Natural Language**
Languages used by humans in daily life, such as Chinese and English. Opposite to programming languages (like Python, Java).

## P

**Prompt**
Instructions or questions that users input to AI. Good prompts help AI better understand tasks.

**Prompt Engineering**
The technology of designing and optimizing prompts to help AI better understand tasks and provide accurate answers.

## T

**Terminal**
Command-line interface where users interact with computers by typing commands. Claude Code runs in the terminal.

**Tool**
External functions that AI can call, such as file operations, web search, code execution, etc.

## U

**UI (User Interface)**
The interface through which users interact with software. Claude Code's UI is a command-line interface.

## V

**Vibe Coding**
A programming style where users describe needs in natural language, and AI automatically generates code. Users don't need to know programming.
