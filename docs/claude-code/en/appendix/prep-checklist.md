# Appendix: Pre-course Checklist

Before starting the course, please make sure you have the following ready:

## Required

- [ ] **A computer**
  - Windows 10 or higher
  - macOS 11.0 or higher
  - Recommended 8GB+ memory

- [ ] **Stable internet connection**
  - Claude Code requires internet
  - Recommended 50Mbps+ bandwidth

- [ ] **Node.js environment**
  - Version 18.0 or higher
  - Check: `node --version`

- [ ] **npm package manager**
  - Version 8.0 or higher
  - Check: `npm --version`

- [ ] **Anthropic API key**
  - Visit https://console.anthropic.com/ to register
  - Generate API key
  - Set environment variable

## Optional

- [ ] **A practice folder**
  - Create a folder for practice
  - Prepare some example files

- [ ] **Basic programming concepts**
  - Not required, but helpful to know basic concepts
  - Such as: variables, functions, files, etc.

## Verification Checklist

```bash
# Check Node.js
node --version

# Check npm
npm --version

# Install Claude Code
npm install -g @anthropic-ai/claude-code

# Verify installation
claude --version
```

## Ready to Start

Once prepared, you can start Lesson 1!
