## 🏁 一、每日运营工作清单

| 时间段 | 动作 | 时长 |
|--------|------|------|
| 09:00-09:30 | 登录卖家后台 → 查看账户健康度（订单缺陷率、迟发率、取消率）、预警消息 | 30 min |
| 09:30-10:00 | 广告检查 → ACOS超限广告词调整、预算分配、否定关键词补充 | 30 min |
| 10:00-11:00 | Listing优化 → 主图/标题五点检查、价格促销设置、库存水位监控 | 60 min |
| 11:00-12:00 | 客服与评价 → 回复买家消息、Review跟进、差评处理 | 60 min |
| 14:00-15:00 | 数据分析 → 昨日销售报告、流量来源分析、竞品价格变动跟踪 | 60 min |
| 15:00-16:00 | 选品与开发 → 新品构思、老品拓展机会识别、供应链沟通 | 60 min |
| 16:00-17:00 | 文档记录与日报 → 更新运营日志、异常问题汇总、明日计划 | 60 min |

---

## 🔑 二、核心操作入口（卖家后台路径速查）

| 操作模块 | 后台路径 |
|----------|----------|
| 账户健康 | 卖家中心 → 绩效 → 账户状况 |
| 广告管理 | 广告 → 广告活动管理器 |
| Listing编辑 | 库存 → 管理所有商品 → 编辑 |
| 订单处理 | 订单 → 管理订单 |
| 物流设置 | 库存 → 设置 → 配送方式 |
