# 亚马逊开店与运营准备清单 v1.0

**说明：** 本清单用于开店前的准备工作核查，确保所有必要事项已完成后再启动运营。请逐项勾选。

---

## 📋 一、资质与文件准备

- [ ] **营业执照**（境内/境外均可，需清晰扫描件）
- [ ] **法人身份证**（正反面彩色照片）
- [ ] **双币信用卡**（Visa/MasterCard，支持国际支付，额度充足）
- [ ] **收款账户**（Payoneer/Wise/银行账户，可接收美元结算）
- [ ] **企业邮箱**（非个人邮箱，如 name@yourcompany.com）
- [ ] **联系电话**（可接通的工作座机或手机）
- [ ] **商标注册证书**（如有，用于 Brand Registry 备案）
- [ ] **产品图片**（白底图至少 1 张，副图若干）
- [ ] **产品规格书/参数表**（尺寸、重量、材质等）

---

## 💻 二、设备与环境准备

- [ ] **独立网络设备**：为每个账号准备独立的宽带线路（不同运营商最佳）
- [ ] **专用电脑/虚拟机**：建议用于登录卖家后台，隔离其他浏览器数据
- [ ] **防关联浏览器**（可选）：如 Multilogin、OctBrowser 等（多账号必备）
- [ ] **密码管理器**：安全存储各账号密码和恢复码
- [ ] **2FA 验证器 App**：Google Authenticator / Microsoft Authenticator 等（推荐，非短信）

---

## 🧭 三、市场与选品调研

- [ ] **确定主营类目**：选择 1-2 个熟悉或有供应链优势的品类
- [ ] **完成竞品分析**：至少分析 5 个竞品的 Listing、价格、Review、广告策略
- [ ] **核算单款利润**：确认目标产品毛利 ≥ 35%（扣除所有费用后）
- [ ] **商标检索**：确认无侵权风险（USPTO/EUIPO 等官方渠道查询）
- [ ] **政策审查**：确认所选类目无需特殊认证或受限

---

## 📦 四、供应链与物流准备

- [ ] **找到合格供应商**：已签订采购合同，有样品确认
- [ ] **确定头程物流**：已联系货运代理，获取报价和时效
- [ ] **包装方案确认**：内包装 + 外箱设计，符合运输要求
- [ ] **贴标材料准备**：FNSKU 标签打印机或打印贴纸
- [ ] **首批备货数量**：根据预测销量确定首单数量（建议 300-500 件起测）

---

## 🎨 五、Listing 素材准备

- [ ] **主图**：纯白底，高清（建议 2000×2000px），产品占比 85%+
- [ ] **副图**：7 张以上（场景图、细节图、尺寸图、功能图等）
- [ ] **视频**（可选）：15-30 秒产品展示视频，提升转化率
- [ ] **标题草稿**：包含品牌词 + 核心关键词 + 属性 + 场景，≤200 字符
- [ ] **五点描述**：5 条，每条突出一个核心卖点，含关键词
- [ ] **搜索词列表**：10-15 个目标关键词（含长尾词）
- [ ] **A+ 内容**（品牌备案后）：图文模块准备

---

## ⚙️ 六、后台设置准备

- [ ] **通知设置**：开启邮件和手机端通知提醒
- [ ] **子账号权限**：如需团队操作，提前配置好子账号角色
- [ ] **支付方式确认**：月租信用卡已绑定且余额充足
- [ ] **税务信息填写**：美国站 W-8BEN-E，欧洲站 VAT 申报准备
- [ ] **配送方式设置**：FBA 入仓计划模板，自发货配送规则

---
