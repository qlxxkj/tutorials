# 亚马逊运营常见 FAQ v1.0

**说明：** 本文件汇总了日常运营中遇到的典型问题及标准处理方案，供新人快速查阅参考。

---

## 🏛️ 一、账号与后台问题

### Q1：注册亚马逊账号被拒绝怎么办？
**可能原因：**
- 营业执照信息不一致或已过期
- 信用卡不支持国际支付
- IP 地址之前关联过被封账号
- 联系信息与营业执照不符

**处理步骤：**
1. 检查所有提交信息的准确性
2. 更换纯净网络环境重试
3. 联系卖家支持提供补充材料
4. 如多次失败，考虑更换主体注册新账号

---

### Q2：卖家中心打不开或登录失败
**排查方法：**
- 清除浏览器 Cookie 和缓存
- 使用无痕模式或不同浏览器尝试
- 确认网络连接稳定（避免公共WiFi）
- 检查 2FA 验证码是否正确
- 如仍不行，通过官网"忘记密码"重置

---

## 📦 二、Listing 相关问题

### Q3：Listing 审核不通过/被下架
**常见原因：**
- 图片不符合规范（非白底、有水印、内容过多）
- 标题包含敏感词或绝对化用语
- 缺少必要属性或填写不全
- 涉及侵权（商标/专利/版权）

**解决步骤：**
1. 查看后台具体下架通知原因
2. 逐项整改 Listing（图片重拍、标题重写等）
3. 提交 Appeal（申诉）说明已修正的问题
4. 如有侵权嫌疑，撤回重新设计原创内容

---

### Q4：主图被拒收怎么办？
**检查清单：**
- [ ] 背景是否为纯白 #FFFFFF？
- [ ] 产品占比是否 ≥85%？
- [ ] 是否有阴影/边框/文字/Logo？
- [ ] 尺寸是否 ≥1000 像素？
- [ ] 格式是否为 JPG/TIFF/PNG？

**修改建议：** 用 Photoshop 或在线工具（如 remove.bg）去除背景，确保纯白底色。

---

## 💰 三、广告与流量问题

### Q5：广告花费很高但不出单
**可能原因：**
- Listing 不完善（缺图、差标题、无 Review）
- 价格高于竞品太多
- 关键词匹配太泛（自动广告跑出大量无关词）
- 目标市场季节性问题

**调整方案：**
1. 优化 Listing 质量（主图、标题、五点、图片视频）
2. 检查搜索词报告，否定无效关键词
3. 调低出价或缩减预算
4. 对比竞品定价，适当调整售价

---

### Q6：广告曝光量低
**可能原因：**
- 预算不足
- 出价太低无法竞争到展示位
- 关键词太少或匹配范围太窄
- Listing 质量分低导致广告权重低

**提升方法：**
1. 提高每日预算（至少 $20/天起跑）
2. 逐步提高精准词的出价（每次 +$0.10-$0.20）
3. 增加关键词数量，开启自动广告辅助拓词
4. 优化 Listing 质量以提升广告质量得分

---

## ⚖️ 四、Review 与客服问题

### Q7：如何合法获取 Review？
**唯一合规方式：** Amazon Vine 计划

**流程：**
1. 确保产品评分 ≥4.0，已有至少 5 条 Review
2. 在 Seller Central → Vine → Register Products 报名
3. 审核通过后（1-2周），最多获得 30 个免费样品名额
4. 发送给 Vine 会员，等待其发布真实 Review
5. **严禁：** 任何诱导好评、返现换评、删差评行为

---

### Q8：收到差评怎么办？
**步骤：**
1. 冷静分析差评类型（产品质量？物流误解？期望偏差？）
2. 如有订单，通过站内信礼貌联系买家，了解具体情况并提供解决方案（补发配件、部分退款等）
3. **注意：** 询问中不要提及"请修改评论"，避免违规
4. 判断是否符合亚马逊移除政策（含人身攻击、非本产品评价等），如符合则提交报告申请删除
5. 从差评中反思自身问题，改进产品或 Listing 描述

---

## 📊 五、库存与利润问题

### Q9：库存积压严重怎么处理？
**清理优先级：**

1. **低价促销：** 设置 Coupon（折扣码）或降价促销
2. **捆绑销售：** 将滞销品与热销品组合打包
3. **站内 Deal：** 申请 Lightning Deal 或 Best Deal 活动
4. **站外引流：** 通过 Deal 网站（Slickdeals、RetailMeNot 等）推广
5. **退回国内或销毁：** 成本允许时选择运回或委托销毁（需注意税务影响）

---

### Q10：如何判断某个产品值不值得继续卖？
**四步评估法：**

1. **看毛利：** 扣除所有费用后毛利率是否 ≥ 25%？否则考虑提价或停售
2. **看趋势：** 近 3 个月销量是上升还是持续下滑？下滑需找原因
3. **看 Review：** 评分是否低于 4.0？负面 Review 是否在增多？
4. **看竞争：** 新进入者是否越来越多？头部霸占是否严重？

**决策：**
- 以上四项都 OK → 继续投入资源
- 1-2 项有问题 → 优化调整后再观察
- 3 项以上不理想 → 考虑清仓止损

---

## 🎯 六、新手常问问题

### Q11：新店前一个月能赚多少钱？
**行业参考数据：**
- 第一个月：$0-$500（冷启动期，主要积累数据和 Review）
- 第二个月：$500-$2000（广告见效后逐步放量）
- 第三个月：$2000-$5000+（爆款成型后稳定增长）

**关键影响因素：**
- 选品是否精准合适
- Listing 完成度和质量
- 广告投放效率和预算
- 供应链能否及时补货

### Q12：一个人可以做亚马逊吗？
**可以，但有局限：**

**单人可行的小店模式：**
- 聚焦 1-3 个核心 SKU
- 使用自动化工具减少重复劳动
- 外包美工和客服（按单付费）
- 专注于选品、广告投放和产品优化

**单人瓶颈：**
- 每天只能处理有限数量的消息和订单
- 难以同时管理多个店铺和站点的扩张
- 精力分散可能导致细节遗漏

**建议起步策略：** 单人从小品类试手，验证模式有效后再逐步扩展或招人。

---

**最后提醒：** 亚马逊政策经常更新，遇到不确定问题时，优先查阅官方帮助页面或咨询专业顾问，不要依赖过时经验。
