## ⚙️ 三、操作步骤

### 5.1 标题优化 SOP（Title Writing SOP）

#### 5.1.1 标题结构公式

```
品牌名 + 核心关键词 + 关键属性 + 适用场景 + 包装规格
例：[Brand Name] Stainless Steel Water Bottle 20oz, Double Wall Vacuum Insulated, Leak Proof for Outdoor Hiking/Camping - BPA Free, Double Lid Options (Blue)
```

**⚠️ 最新标题规范要点（2024 年更新）：**

| 项目 | 旧规范 | 新规范（2024） | 说明 |
|------|--------|---------------|------|
| 字符数上限 | ≤200字符 | 多数类目≤200字符，部分类目≤100字符 | 具体上限因类目而异，创建时后台会实时提示 |
| 品牌名使用 | 任何卖家可填 | **仅 Brand Registry 备案后可填** | 未备案者标题中品牌位置留空或写"N/A" |
| 允许标点 | 逗号、连字符等 | **仅限逗号(,)、连字符(-)、斜杠(/)、and/or** | 其他符号如 ! ? @ # $ % ^ & * () [] {} 均禁止 |
| 促销信息 | 禁止 | **仍禁止** | Free Shipping、Best Seller、Guarantee 等均不可出现 |
| 堆砌关键词 | 忽略 | **明确处罚** | 重复关键词可能被降权或屏蔽 |

**例外类目注意：**
- 珠宝类目有特殊规则，允许包含材质纯度（如"14K Gold"）
- 服饰类目允许包含尺码信息（如"L", "Size M"）在标题中

#### 5.1.2 标题写作检查清单（新增）

- [ ] **品牌备案状态确认**：若未做 Brand Registry，标题首项不写品牌名，或写"[N/A]"占位
- [ ] **字符数检查**：创建时后台实时计数，确保不超过类目上限
- [ ] **符号合规**：仅使用英文逗号`,`、连字符`-`、斜杠`/`、单词`and`或`or`
- [ ] **无禁止词**：不含"最佳""第一""免费""保证""销量领先"等绝对化/促销词汇
- [ ] **首字母规则**：每个单词首字母大写（除 and/or/in/on/at/to/by 等短连接词外）
- [ ] **关键词自然融入**：核心搜索词出现在前 80 字符内（移动端截断位置）
- [ ] **无关键词堆砌**：同一关键词不重复出现超过 1 次

#### 5.1.3 标题实操流程

1. **收集竞品信息**：复制 Top 5 竞品的标题，提取高频词汇
2. **核心词确认**：从竞品中提炼出 2-3 个最核心的搜索词（如"stainless steel water bottle"）
3. **属性补充**：根据产品特性添加关键属性（容量、材质、功能特点等）
4. **场景扩展**：添加使用场景词（户外、运动、办公等）
5. **生成草稿**：按上述结构组合成标题草稿，**特别注意字符数和符号合规性**
6. **品牌备案检查**：确认是否已做 Brand Registry，决定标题首部是否写入品牌名
7. **A/B测试**：上新初期可用两个不同标题广告分组测试哪个表现更好，保留优者

### 5.2 五点描述撰写 SOP（Bullet Points）

#### 5.2.1 五点写作框架

每一点遵循「痛点 → 解决方案 → 具体价值」结构：

| 点号 | 写作重点 | 示例 |
|------|----------|------|
| Point 1 | 核心卖点/最大优势 | 采用双层真空保温技术，保冷24小时/保热12小时 |
| Point 2 | 关键差异化特征 | 304食品级不锈钢内胆，无毒无味耐腐蚀 |
| Point 3 | 使用体验/便利性 | 防滑硅胶底座 + 单手按键开盖，户外运动便捷 |
| Point 4 | 质保/售后服务 | 终身质保，质量问题免费更换 |
| Point 5 | 附加价值/套装内容 | 含便携挂绳+清洁刷，送礼自用两相宜 |

#### 5.2.2 五点写作检查清单

- [ ] 每一句话都是一个完整的事实陈述（不含推销用语）
- [ ] 包含至少一个目标关键词（自然融入）
- [ ] 避免绝对化用语（最好、第一、唯一等）
- [ ] 使用用户可感知的语言（不说"优质材料"，说"304不锈钢"）
- [ ] 控制每点字符 ≤ 250字符

### 5.3 图片上传 SOP

#### 5.3.1 主图要求（白底图）

- 背景纯白（RGB 255,255,255），无边框/阴影/Logo
- 产品占比 ≥ 85%，居中展示
- 无模特使用（除非是Brand Registry备案后的Enhanced Content）
- 文件格式：JPEG/TIFF，尺寸 ≥ 1000像素（推荐 2000×2000）
- 文件名不含特殊字符（如 product-title.jpg）

#### 5.3.2 副图内容规划（最多9张副图）

| 图片序号 | 内容建议 | 要点 |
|----------|----------|------|
| 1 | 场景使用图 | 产品在真实环境中的应用 |
| 2 | 细节特写图 | 材质、工艺、配件等细节放大 |
| 3 | 尺寸对比图 | 与常见物品对比直观展示大小 |
| 4 | 功能演示图 | 如何使用、打开方式等动图或静态图 |
| 5 | 包装开箱图 | 内含物品一览 |
| 6 | 多色/多型号展示 | 颜色选择或不同规格选项 |
| 7 | 认证资质图 | ISO、FDA、CE等认证标志 |
| 8 | 对比优势图 | 与普通产品的差异对比 |
| 9 | 品牌故事图 | 品牌理念/历史（如有） |

#### 5.3.3 A+页面内容要求（需Brand Registry）

- 图文结合，不超过6个模块
- 每个模块不超过2张图片 + 一段文字
- 文字简洁，突出消费者利益点
- 可使用对比表格、使用场景图等信息图表形式

### 5.4 关键词埋词策略（Search Terms）

#### 5.4.1 后台 Search Terms 填写技巧

- 总字符限制：250字节（英文），非中文
- 词之间用空格分隔，不要逗号
- 不需要重复（Google自动去重）
- 包含同义词、拼写变体、缩写、长尾词
- 不要堆砌（亚马逊忽略过度重复的词）

**填写示例：**
```
water bottle insulated reusable drinking cup outdoor hiking camping fitness gym stainless steel leak proof portable bpa free travel mug double wall thermos bottle
```

#### 5.4.2 关键词挖掘工具实操

1. **Amazon搜索下拉框：** 在亚马逊搜索栏输入核心词，看联想词（最真实的用户搜索词）
2. **Helium 10 Cerebro / Jungle Scout：** 输入ASIN反查其排名关键词，筛选低竞争高流量词
3. **MerchantWords / KeywordTool.io：** 获取全球各地搜索量数据
4. **手动记录：** 将找到的关键词按搜索量（高低）、相关性（强弱）分类

### 5.5 Listing上架合规自查清单

上架前逐项核对：

- [ ] 标题无绝对化用语（最佳、第一、顶级...）
- [ ] 所有宣称有依据（如"持久保温24小时"需有测试数据支持）
- [ ] 图片无水印、无额外文字说明、无虚假效果
- [ ] 五点描述不承诺未达到的功能效果
- [ ] 关联的产品类目正确（不要跨类目违规）
- [ ] 如有必要已上传认证文件（FCC、CE、FDA等）
- [ ] 价格符合平台无低价倾销政策
- [ ] 库存数量准确，不为零

## 🛠 五、常见问题排查（Q&A）

### Q1：Listing被编辑权限警告怎么办？
- 原因：可能是新账号对Listing进行了大量修改触发了系统监控
- 处理：登录卖家中心 → 绩效 → 账户健康 → 查看详细信息 → 按照指示提交说明文档
- 预防：新账号上架初期尽量保持稳定，不要频繁修改标题和图片

### Q2：主图被拒绝怎么办？
- 常见原因：背景非纯白、产品占比不足、有阴影/边框
- 处理：使用 Photoshop 或在线工具（如 Remove.bg）去除背景，确保纯白 #FFFFFF
- 建议：使用专业电商平台图片处理团队，避免反复提交被拒影响上架效率

### Q3：五点描述写好后如何提高点击转化？
- 对比竞品五点，找出对方没有提到的优势点优先写入
- 针对负面Review中用户抱怨的问题，在你的五点中主动提供解决方案
- 加入具体数字和数据（"保温24小时"比"长效保温"更有说服力）
