# 第6章 广告与流量运营 SOP

**文件编号：** SOP-AMZ-006 | **生效日期：** 2026-07-27 | **适用岗位：** 广告优化师、运营专员

---

## 🎯 一、本章目标

掌握亚马逊站内广告投放全流程，包括广告类型选择、活动搭建、数据分析和站外引流方法，实现精准获客与利润最大化。

---

## 📋 二、前置准备

投放广告前必须确认：
- [ ] Listing完整度达标（主图、标题、五点俱全）
- [ ] 有足够库存支持广告带来的订单
- [ ] 产品利润率能承受广告成本目标ACOS
- [ ] 已设定广告预算上限和每日分配计划

## ⚙️ 三、操作步骤

### 6.1 广告类型与选择指南

#### 6.1.1 四大广告类型对比

| 广告类型 | 全称 | 展示位置 | 适用场景 | 最低预算建议 |
|----------|------|----------|----------|-------------|
| SP | Sponsored Products | 搜索结果页、商品详情页 | 单品推广、新品测词、日常销售引流 | $20/天 |
| SB | Sponsored Brands | 搜索结果顶部品牌专区 | 品牌曝光、多SKU关联销售 | $50/天 |
| SD | Sponsored Display | 站内再营销、站外受众重触达 | 老品回流、浏览未购用户召回 | $30/天 |
| DSP | Demand Side Platform | 站内外程序化购买 | 大品牌大预算、受众定向投放 | $500+/天 |

**新手推荐策略：** 仅投 SP 广告，跑通后再考虑 SB 和 SD。

---

#### 6.1.2 SP广告三种匹配模式

| 匹配类型 | 说明 | 适合阶段 | 出价策略 |
|----------|------|----------|----------|
| 自动匹配 | 亚马逊自动匹配相关关键词 | 新品期/冷启动 | 系统默认或略高 |
| 短语匹配 | 搜索词包含短语内容 | 成长期（需精准词） | 手动调整偏高 |
| 精确匹配 | 搜索词完全一致或近义词 | 成熟期（核心词） | 手动控制最高 |

---

### 6.2 广告活动搭建 SOP（标准流程）

#### 步骤1：创建新活动
```
广告 → 广告活动管理器 → 创建广告活动 → 选择 Sponsored Products → 自动/手动定位
```

#### 步骤2：设置基本参数
- 活动名称规范格式：`[活动类型]_[产品线]_[日期]_auto例：SP_NEW_20260727_auto`
- 投放选择：自动投放（广撒网找词）或 手动投放（精准控词）
- 日期范围：建议开启"持续运行"而非固定结束日
- 每日预算：按产品线分配，新品初期 $20-$50/天

#### 步骤3：选择产品/ASIN
- 选择要推广的具体 ASIN（不要一个活动推多个不同产品）
- 可开启"自动投放所有我的商品"用于新品测试

#### 步骤4：设置出价
- 自动广告建议：使用"动态出价 - 只降低"（系统根据转化自动调整）
- 手动广告：起步价参考竞品平均 CPM + 10%-20%，后续根据数据调整

#### 步骤5：否定关键词管理（关键！）
在活动创建后，每周查看"搜索词报告"，添加以下词为否定关键词：
- 与你产品无关的搜索词（如卖厨房用品出现"宠物"相关词）
- 低转化高消费的长尾词
- 品牌词（避免自己打自己）

### 6.3 日常广告优化流程（周报机制）

#### 3.1 每日检查项（10-15分钟）
- [ ] 广告消耗是否超出预算？如有提前消耗，手动调高出价补量
- [ ] 是否有大额无效点击？（同一IP多次点击等可疑行为）
- [ ] 重点产品的 ACOS 是否异常飙升？

#### 3.2 每周深度优化（30-60分钟）

**第1步：识别高价值关键词**
从搜索词报告中筛选：
- ✅ 留下：有点击、有转化、ACOS ≤ 目标值
- ❌ 否定：无点击或点击无转化、费用高贡献小、与产品无关

**第2步：调整出价策略**
- 好词（高转化/低ACOS）：逐步提高出价 10%-20%
- 中词（有转化但ACOS偏高）：维持或小幅下调
- 差词（无转化/高ACOS）：大幅降低出价或移至否定列表

**第3步：广告活动结构调整**
- 将表现好的手动精准词从自动活动中分离出来，单独新建手动活动并提高出价
- 创建否定关键词组，跨活动批量应用

### 6.4 核心指标监控与计算

#### 6.4.1 关键指标定义及计算公式

| 指标 | 符号 | 公式 | 健康阈值 |
|------|------|------|----------|
| 曝光量 | Impressions | 广告被展示的次数 | 越高越好（反映覆盖力） |
| 点击量 | Clicks | 广告被点击的次数 | — |
| 点击率 | CTR | Clicks ÷ Impressions | ≥ 0.5% 为佳 |
| 花费 | Spend | 实际广告支出 | — |
| 销售额 | Sales | 广告带来的销售额 | — |
| 转化率 | CVR | Orders ÷ Clicks | ≥ 10% 为佳 |
| ACOS | ACoS | Spend ÷ Sales × 100% | ≤ 目标利润率 |
| ROAS | Return on Ad Spend | Sales ÷ Spend | ≥ 目标倒数 |

**例：** 广告花费$50，带来销售额$300 → ACOS = 50÷300×100% = 16.7%，ROAS = 300÷50 = 6

#### 6.4.2 ACOS目标设定原则
```
目标 ACOS ≤ 净利率 × （1 - 其他运营成本占比）
例如：产品净利率40%，其他运营成本（物流/平台佣金等）占25% → 
       目标 ACOS ≤ 40% × (1-25%) = 30%
```

### 6.5 站外引流合规操作（Deal与社媒）

#### 6.5.1 Deal站合作流程（以 Slickdeals 为例）

1. **准备工作：**
   - 确保Listing评分≥4.0星，Review数量≥20条
   - 价格折扣力度 ≥ 平时售价的30%-50%
   - 库存充足，至少能满足Deal爆发期的5倍销量

2. **提交Deal：**
   - 访问 deal posting 页面 → 填写产品链接、折扣码、活动时间
   - 付费部分Deal需要支付上架费（约$300-$800不等）
   - 等待版主审核（通常1-3个工作日）

3. **活动中监控：**
   - 实时监控BSR排名变化
   - 注意Review增长节奏，避免突然大量新增Review触发审核
   - 活动结束后及时调整价格恢复原价

⚠️ **严禁：** 要求买家留下好评换取折扣 —— 违反亚马逊政策会导致账号风险。

#### 6.5.2 社媒引流（Facebook/Instagram/TikTok）

- 建立品牌账号，定期发布产品使用视频/教程
- 投放小额信息流广告（$10-$20/天）测试效果
- 将流量引导至亚马逊Listing（需在帖子中使用"Amazon.com"跳转链接，不可引导至外部站再跳转亚马逊——违规）
- 配合站内Coupon或优惠券增加转化率

每次广告活动优化完成后：

- [ ] 已识别并否定低效搜索词

- [ ] 广告活动命名符合规范

## 🛠 五、常见问题排查（Q&A）

### Q1：广告点击了但没出单怎么办？
可能原因：
- Listing不完善（图片少、标题差、五点不清）
- 价格高于竞品无明显优势
- 无 Review 或 Review 太少影响信任
- 关键词不精准（广告跑了不相关的流量）

处理方案：
1. 先优化 Listing（完善图片、优化标题和五点）
2. 检查关键词匹配度，调整为更精准的短语/精确匹配
3. 适当降低出价，减少浪费点击
4. 若仍无转化，暂停该广告活动检查产品本身问题

### Q2：广告花费很高但ACOS怎么算不对？
注意区分：
- **广告 ACOS** = 该广告活动产生的销售额 ÷ 该广告活动的花费
- **整体店铺 ACOS** = 全部广告花费 ÷ 全部销售额（含自然订单）
两者口径不同，不要用混。建议用后台 Report 的"Advertising"报表精确计算。

### Q3：能否把广告活动和自然订单捆绑在一起优化？
不能直接捆绑，但可以间接影响：良好的Listing优化 → 更好的自然转化率 → 降低所需广告投入 → 整体ACOS下降。所以Listing优化是降本增效的根本。
