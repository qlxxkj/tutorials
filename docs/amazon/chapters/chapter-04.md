# 第4章 供应链与产品开发

**文件编号：** SOP-AMZ-004 | **生效日期：** 2026-07-27 | **适用岗位：** 供应链经理、采购专员、运营负责人

---

## 🎯 一、本章目标

掌握供应商开发全流程，从寻源到打样再到量产管控，确保产品品质稳定、交货准时、成本可控。

---

## 📋 二、前置准备

启动供应链开发前必备条件：
- [ ] 已确定选品方案并拿到样品
- [ ] 明确需求数量、包装要求、质检标准
- [ ] 完成商标/专利风险自查
- [ ] 确认预算和付款条款

## ⚙️ 三、操作步骤

### 3.1 供应商寻源渠道与筛选方法

#### 3.1.1 主流寻源平台对比

| 平台类型 | 代表平台 | 优势 | 劣势 | 适合品类 |
|----------|----------|------|------|----------|
| B2B综合 | 1688.com、阿里巴巴 | 选择多、价格透明 | 需甄别质量 | 通用家居、小商品 |
| 行业展会 | 广交会、华强展会 | 可面对面验厂 | 时间成本高、差旅费 | 新品类开拓 |
| 垂直产业带 | 义乌小商品、深圳电子、东莞家具 | 产业集群集中、专业度高 | 地域限制明显 | 对应产业带产品 |
| 社交渠道 | 微信工厂群、抖音工厂号 | 沟通直接、响应快 | 缺乏第三方背书 | 中小批量试单 |

**实操建议：** 优先通过1688搜索 + 线下产业带走访结合的方式，同时储备2-3家备选供应商。

---

#### 3.1.2 供应商评估清单（5项核心指标）

对候选供应商逐一打分（1-5分）：

| 评估维度 | 考察要点 | 权重 | 得分 |
|----------|----------|------|------|
| ✅ 产能稳定性 | 有无旺季加班能力？订单排期是否合理？ | 25% | □ |
| ✅ 品质控制 | 有无QC流程？过往客诉率如何？ | 25% | □ |
| ✅ 配合度 | 能否按时回复消息？是否愿意改模改包装？ | 20% | □ |
| ✅ 账期灵活性 | 能否接受30/50/30或月结？ | 15% | □ |
| ✅ 证书资质 | ISO认证、专利授权、行业资质 | 15% | □ |

**总分 < 15分（满分25）直接淘汰。**

---

### 3.2 谈判与签约流程

#### 3.2.1 报价单必备要素

要求供应商提供正式报价单，必须包含以下字段：
- 产品名称/型号
- FOB单价（起订量注明，如 MOQ=500pcs @ $X/pc）
- 包装规格（内箱尺寸、外箱尺寸、毛重、净重）
- 生产周期（确认后天数）
- 付款方式（TT比例、尾款发货前付清）
- 样品费用及邮寄方式

#### 3.2.2 标准合同关键条款

```
1. 质量标准：以双方确认的样品为准，允许±5%尺寸公差
2. 付款方式：订金30%，大货生产前50%，出货前结算20%（或月结30天）
3. 交货地点：指定国内港口（如深圳盐田港），FOB条款
4. 违约责任：延迟交货每日按合同总额0.5%扣款
5. 知识产权：供应商保证产品设计不侵犯第三方权利，否则承担全部责任
6. 保密条款：不得将合作信息、客户资料泄露给第三方
```

> **重要提醒：** 涉及模具开发的，必须明确模具所有权归属（通常买方付清后归买方）。

---

### 3.3 样品打样与确认流程

```
阶段1：打样申请 → 付样品费 → 供应商寄样（3-5工作日）
   ↓
阶段2：样品验收 → 测试功能/外观/尺寸 → 签字确认样（PAS样）
   ↓
阶段3：生产前确认 → 供应商依据 PAS样进行首件生产 → 发PP样确认
   ↓
阶段4：大货生产 → 供应商通知备货进度 → 定期跟进生产状态
```

**样品验收检查表：**

- [ ] 产品功能是否正常测试通过
- [ ] 颜色是否与样品一致（色差在可接受范围）
- [ ] 包装箱印刷内容无误（品牌LOGO、条形码、警示语）
- [ ] 配件齐全（说明书、保修卡、充电线等）
- [ ] 无明显瑕疵（划痕、变形、污渍）

**任一项目不合格 → 要求返工重做，不计入正常交货周期。**

---

### 3.4 生产质量监控（三阶段检验）

| 阶段 | 检验时机 | 重点内容 | 执行方 |
|------|----------|----------|--------|
| PPS (Pre-Production Sample) | 开产前 | 首次批量生产样品，确认工艺标准 | 买家或第三方QC |
| DPI (During Production Inspection) | 产量达到40-60% | 抽样检查外观、包装、工艺一致性 | 第三方QC机构 |
| PSI (Pre-Shipment Inspection) | 装箱前 | 全检或AQL抽检（通常AQL 2.5），核对数量 | 第三方QC机构 |

**AQL抽检标准参考：**
- 关键缺陷（Critical）：不允许出现，涉及安全/法律风险
- 严重缺陷（Major）：AQL 2.5%，影响销售或使用
- 轻微缺陷（Minor）：AQL 4.0%，不影响基本功能

## ✅ 四、检查清单（Checklist）

每批货生产关键节点核对：

- [ ] 样品已签字确认（PAS）
- [ ] 生产排期已确认且供应商书面回复
- [ ] PPS样品已验收合格
- [ ] DPI已安排或已执行（如需）
- [ ] PSI合格报告已获取
- [ ] 装箱单/PIL发票与实物一致
- [ ] 报关资料齐全（箱发票、装箱单、合同、提单）

## 🛠 五、常见问题排查（Q&A）

### Q1：供应商交期延误怎么办？
1. 立即书面邮件要求说明原因和新的交货日期
2. 评估延误对亚马逊库存的影响（是否断货或缺货预警）
3. 如需紧急补救，考虑加空运补货（成本增加但保住Listing排名）
4. 后续订单适当减少该供应商份额，启用备选供应商

### Q2：发现大货与样品不符怎么处理？
- 立即暂停出货并拍照取证
- 要求供应商返工或重新生产，费用由供应商承担
- 如果无法返工，考虑部分收货（合格部分先入仓，不合格退货）
- 建立长期黑名单，该供应商不再合作

### Q3：如何管理多个供应商避免打架？
- 建立供应商分级体系：A级（主力）、B级（备用）、C级（观察）
- 每个品类只保留1-2家主要供应商，其余作为备选
- 订单分配原则：A级拿70%，B级拿30%，避免过度依赖单一厂商
