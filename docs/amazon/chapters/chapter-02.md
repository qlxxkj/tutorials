# 第2章 账号注册与合规运营

**文件编号：** SOP-AMZ-002 | **生效日期：** 2026-07-27 | **适用岗位：** 运营专员、店长、财务人员

---

## 🎯 一、本章目标

掌握亚马逊卖家账号注册全流程，理解账号安全规范与关联风险防控，确保账号稳定运营不封号。

---

## 📋 二、前置准备

注册前必须完成以下材料收集：

| 类别 | 具体内容 | 备注 |
|------|----------|------|
| 公司资质 | 营业执照原件扫描件 | 需在有效期内 |
| 法人身份证 | 正反面彩色照片 | 清晰可读 |
| 银行卡/收款账户 | 银行流水或Payoneer/Wise账户信息 | 用于接收结算款 |
| 双币信用卡 | Visa/MasterCard | 月租$39.99扣款用 |
| 联系方式 | 企业邮箱（非QQ/163等） | 便于接收官方通知 |
| 网络环境 | 纯净静态IP地址 | 不可与之前账号共用 |

## ⚙️ 三、操作步骤

### 3.1 账号注册流程（北美站示例）

**步骤1：进入注册页面**
```
网址：https://sellercentral.amazon.com/register → 点击"Create your Amazon account"
```

**步骤2：填写基本信息**
- 公司名称（与营业执照一致）
- 联系人姓名（法人或授权代表）
- 企业邮箱（推荐使用域名邮箱，如 name@yourcompany.com）
- 联系电话（可接通的工作座机或手机）

**步骤3：身份验证**
- 上传营业执照扫描图
- 上传法人身份证正反面
- 系统可能发起视频验证或电话核对

**步骤4：银行卡设置**
- 添加信用卡用于月租扣款（Visa/Master/Amex）
- 确认信用卡支持国际支付且额度充足

**步骤5：店铺信息配置**
- 选择销售计划（专业卖家）
- 设定店铺名称（英文，建议与公司品牌相关）
- 完成税务问卷（美国站点需填写W-8BEN-E表格）

**步骤6：账户激活**
- 等待审核（通常1-3个工作日，有时可能更长）
- 收到"Welcome to Seller Central"邮件后登录后台

> **关键提醒：** 所有信息与营业执照必须完全一致，任何细微差异都可能导致审核失败或被冻结。

---

### 3.2 多站点开通操作

已开通美站后，如需同步开通其他站点：

1. 登录美国卖家中心 → 右上角 "Settings" → "User Permissions" → 进入 "Amazon Global Selling"
2. 选择目标站点（英国/德国/日本等）→ 提交所需额外资质
3. 欧洲站点需注意：VAT税号申报是强制要求，建议在注册前咨询税务顾问或使用VAT代理服务
4. 日本站点相对简单，主要提供日语客服支持

---

### 3.3 账号安全配置（注册后立即执行）

#### 3.3.1 两步验证（2FA）开启路径
```
Settings → User Permissions → Two Step Verification (2SV) → Enable
```
推荐方式：使用 Authenticator App（Google Authenticator / Microsoft Authenticator），而非短信验证码。

#### 3.3.2 角色权限管理
- 为不同岗位员工创建独立子账户（不要共享主账号密码）
- 遵循最小权限原则：客服只给订单查看权，不给修改权限；广告人员只给广告权限

#### 3.3.3 登录设备白名单
- 固定办公设备进行登录，避免在公共WiFi下操作后台
- 使用专用电脑或虚拟机运行亚马逊卖家后台，隔离浏览器缓存和Cookie

## ✅ 四、检查清单（Checklist）

注册完成后逐项核对：

- [ ] 账号状态显示为"Active"且无黄色警告
- [ ] 银行账户已测试收款成功（小额打款验证）
- [ ] 2FA 已开启并保存好恢复代码
- [ ] 子账号权限已按岗位分配完毕
- [ ] 主邮箱和备用邮箱均已绑定
- [ ] 通讯录已添加卖家支持联系方式

## ⚠️ 五、关联风险控制 SOP

### 5.1 什么会导致账号关联？

亚马逊通过指纹识别技术判断多个账号是否属于同一运营者，触发因素包括：

| 触发维度 | 具体关联因子 |
|----------|-------------|
| 网络环境 | 同一IP地址登录多个账号 |
| 硬件信息 | 同一台电脑/浏览器/网卡MAC地址 |
| 联系信息 | 相同电话、邮箱、注册地址 |
| 收款账户 | 同一张银行卡或Payoneer ID |
| 产品信息 | 重复的Listing标题、图片、描述 |
| 物流信息 | 使用相同发货地址或物流账号 |

### 5.2 防关联实操方案

**网络隔离方案：**
- 每个账号使用独立的宽带线路（不同运营商最佳）
- 或使用专业防关联浏览器（如 OctBrowser、Multilogin、Adacos）
- 严禁在同一个浏览器窗口同时打开多个卖家中心标签页

**设备隔离方案：**
- 每台电脑只登录一个账号
- 使用虚拟机（VMware/VirtualBox）为每个账号建立独立系统环境

**信息隔离方案：**
- 每个账号使用独立的邮箱、电话、联系人姓名
- 收款账户单独申请（不同法人或不同银行卡）
- 产品图片和描述完全原创，避免复制粘贴

---

### 5.3 账号异常处理流程

**场景一：收到"账户健康"警告邮件**
1. 仔细阅读邮件指出的具体问题
2. 准备Plan of Action（POA）文件，包含：
   - 问题原因分析
   - 已采取的纠正措施
   - 预防未来再次发生的机制
3. 通过卖家中心申诉入口提交POA
4. 耐心等待回复（通常1-3个工作日）

**场景二：账号被冻结**
- 立即停止该账号的一切操作
- 尝试联系卖家支持（电话优先级高于邮件）
- 聘请专业申诉服务商（如账号严重问题）
- 评估是否需要重新注册新账号（注意规避关联风险）
