# 第7章 物流与仓储管理 SOP

**文件编号：** SOP-AMZ-007 | **生效日期：** 2026-07-27 | **适用岗位：** 运营专员、库存负责人、采购协调员

---

## 🎯 一、本章目标

掌握 FBA/FBM 物流模式选择流程、头程物流方式决策方法、海外仓使用策略及库存周转管理，确保货品及时入库且不积压。

---

## 📋 二、前置准备

进行物流操作前必备条件：
- [ ] 产品包装完成并通过质检（箱内物品与装箱单一致）
- [ ] 已生成亚马逊 FBA 入仓计划（Delivery Plan）
- [ ] 贴标完成（FNSKU 标签正确粘贴于每件/外箱）
- [ ] 头程货运服务商确定并签订合同

## ⚙️ 三、操作步骤

### 7.1 物流模式选择 SOP

#### 7.1.1 FBA vs FBM 决策矩阵

| 考量维度 | 适合 FBA | 适合 FBM |
|----------|----------|----------|
| 产品尺寸 | 标准尺寸（< 20kg, < 60cm） | 大件/超重件 |
| 利润空间 | 毛利 ≥ 40%（覆盖 FBA 费用） | 高毛利或定制化需求 |
| 竞争程度 | 需要 Prime 标识提升转化率 | 无激烈价格战 |
| 售后处理 | 可接受 FBA 退仓退货上门取件 | 可自行安排海外售后 |
| 资金压力 | 有备货资金周转能力 | 控制库存风险优先 |

**典型组合策略：** 
- 爆款（高转化）→ FBA，获取 Prime 流量和 Buy Box
- 长尾款（低销量、低频）→ FBM，避免长期仓储费
- 定制/非标品 → FBM，灵活应对特殊订单

---

#### 7.1.2 FBA 入仓操作流程

```
步骤1：创建入仓计划
  Seller Central → Inventory → Manage All Content → Create FBA Shipment
  → Choose Products → Enter Quantity → Prepare Labeling
  
步骤2：打包贴标
  每件产品贴 FNSKU 标签（条形码不可模糊/覆盖）
  外箱贴外箱标签（含 PO 号、箱号、内容物清单）
  
步骤3：预约送仓
  选择货运类型：Carrier Delivered（物流公司送货） or Partnered Carrier（亚马逊合作物流）
  确认交货时间和仓库地址
  
步骤4：物流发货
  安排物流公司取货或自行送仓到指定仓库
  
步骤5：入库接收
  货物到达仓库后，系统会在 24-72 小时内更新状态（Available / In Progress / Receiving）
```

**贴标注意事项：**
- FNSKU 标签必须清晰完整，覆盖原有厂商条码
- 标签粘贴位置在盒子侧面平整处，不被胶带覆盖
- 同一 SKU 多个箱子需分别编号（Box 1 of 3, Box 2 of 3...）

### 7.2 头程物流方式选择指南

#### 7.2.1 三大头程方式对比

| 方式 | 时效 | 成本 | 适用场景 |
|------|------|------|----------|
| 海运散货 | 25-40天 | $0.8-2/kg（估算） | 大批量备货、非急用品、旺季前补货 |
| 海运整柜 | 30-50天 | $2000-5000/40HQ（估算） | 超大体量、定期大批量出货 |
| 空运 | 5-10天 | $4-8/kg | 新品测款、旺季急补、小批量试销 |
| 铁路中欧班列 | 15-25天 | $2-4/kg | 欧洲线路中等批量运输 |

**成本控制技巧：**
- 提前 45-60 天规划大货海运，避开旺季舱位紧张期
- 多供应商比价至少三家获取报价
- 考虑"海空联运"（中国→目的国港口+最后一公里空运）平衡时效与成本

### 7.3 海外仓使用 SOP

#### 7.3.1 何时使用海外仓？

以下情况建议考虑海外仓备货：
- 产品体积大/重量重（FBA 仓储费过高）
- 复购率高、需频繁补货（海外仓快速调拨）
- 大件家具/家居等需要本地组装服务
- 希望提供更快的本地配送以提升客户体验

#### 7.3.2 海外仓操作流程

1. **选仓：** 根据销售市场选择主要仓库位置（如美国仓选在加州或田纳西州）
2. **发货：** 将货物从国内发往海外仓（可选择海运到港后卡车派送）
3. **上架：** 海外仓收货上架，系统同步库存数据
4. **接单销售：** 在亚马逊/Facebook/独立站等渠道销售，通过 ERP 系统对接海外仓发货
5. **退换处理：** 海外仓提供本地退换货、重新包装、二次销售服务

#### 7.3.3 海外仓服务商评估要点

- [ ] 是否支持 API 接口对接主流电商平台（Shopify、亚马逊、WooCommerce 等）
- [ ] 操作费、仓储费、配送费是否透明无隐性收费
- [ ] 是否有退换货处理能力（维修/翻新/重新打包）
- [ ] 响应速度和问题解决效率（查看客户评价）
- [ ] 是否有保险服务（货物丢失/损坏赔偿）

### 7.4 库存管理与 IPI 优化

#### 7.4.1 IPI（Inventory Performance Index）评分体系

IPI 满分为 1000 分，影响 FBA 仓容配额。评分维度和权重：

| 维度 | 权重 | 说明 |
|------|------|------|
| 过剩库存 | 30% | 库存天数 > 365 天的比例 |
| 在售库存 | 25% | 有库存但有销售的产品比例 |
| 可售库存利用率 | 25% | 可用库容 vs 实际库存 |
| 移除请求率 | 20% | 主动移除/弃置的比例 |

**建议保持 IPI ≥ 550 分**，以获得足够的仓容配额；≥ 750 分可获得无限制仓容。

#### 7.4.2 库存周转计算与补货模型

**安全库存 = （日均销量 × 补货周期）+ 缓冲量**
- 日均销量 = 过去 30 天总销量 ÷ 30
- 补货周期 = 头程运输时间 + 入仓验收时间 + 缓冲时间（建议额外加 7 天）
- 缓冲量 = 日均销量 × 7（应对突发需求）

**例：** 某产品日均销量 50 单，头程海运 30 天 + 入仓 3 天 + 缓冲 7 天 = 40 天周期  
安全库存 = (50 × 40) + (50 × 7) = 2000 + 350 = 2350 件

**补货提醒机制：** 当库存 ≤ 安全库存的 1.5 倍时，即启动补货流程。

#### 7.4.3 滞销品清理流程

发现库存周转异常（如某 SKU 连续 60 天无销售）时，按以下步骤处理：

1. **低价促销：** 设置 Coupon 或折扣，尝试清仓
2. **捆绑销售：** 与热销品捆绑打包出售
3. **站内 Deal：** 申请 Lightning Deal 或 Best Deal 活动曝光
4. **站外引流：** 发布Deal站促销码清库存
5. **退回国内/销毁：** 若成本允许，申请运回国内或委托销毁（注意税务影响）

## ✅ 四、检查清单（Checklist）

每次发货前核对：

- [ ] 所有产品已贴正确 FNSKU 标签
- [ ] 外箱标签清晰可见且内容准确
- [ ] 装箱单与实际货物一致（数量、SKU、箱号）
- [ ] 货运单号已填入亚马逊入仓计划
- [ ] 货物按时交付至指定仓库
- [ ] 收到入库确认通知（Inventory Adjustment Report）

## 🛠 五、常见问题排查（Q&A）

### Q1：FBA 货物被拒收怎么办？
可能原因：标签错误、产品损坏、申报数量不符、违禁品。处理步骤：
1. 查看卖家中心"库存调整报告"，确认拒收数量和原因
2. 联系货运商确认是否为运输途中损坏
3. 选择后续处理方式：重新入库（补发）、销毁（支付销毁费）、退回国内（承担运费）
4. 加强下次发货前的自查环节，避免重复错误

### Q2：IPI 分数下降导致仓容受限怎么快速提升？
短期措施：
- 立即清理滞销品（促销 + 撤回 + 弃置）
- 停止新的大额采购，控制入库量
- 尽快让现有库存产生销售（加大广告投入）
长期改进：
- 建立月度 IPI 监控仪表盘
- 设定目标 IPI ≥ 650 分作为红线预警

### Q3：海运货物迟迟不到仓怎么办？
- 首先联系货运代理查询船期和ETA
- 如果延误超过预期 10 天以上，考虑紧急空运补货避免断货
- 未来选择更稳定的货运服务商，购买货物运输保险
