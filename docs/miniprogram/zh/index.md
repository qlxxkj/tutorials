# 微信小程序实战

> 从零到上线，16 节课 + 3 个实战项目
> 无需编程基础，会用 AI 就能做出可发布的小程序

---

## 课程简介

微信小程序是微信生态内最轻量的产品形态——13 亿月活用户，扫码即用，无需安装。它特别适合独立开发者和一人公司：开发成本低、审核快、变现路径清晰，而且结构简洁，AI 生成准确率高。

这门课**不讲深奥的底层原理**，只讲**怎么做**。

- 你会从注册、备案到开发、云函数、微信支付、审核上线，走完整条链路
- 学完 16 节课后，你有能力独立完成一个可发布的微信小程序
- 3 个实战项目从简到难：天气查询（只读 API）→ 家谱管理（CRUD + 树视图）→ 预约咨询（完整商业流程）

---

## 学完你能做到什么？

- ✅ 注册小程序并完成 ICP 备案
- ✅ 理解 WXML / WXSS / JS / JSON 四件套，独立写页面
- ✅ 使用云开发（云函数 + 云数据库）免后端完成完整业务
- ✅ 实现微信登录、手机号授权、微信支付
- ✅ 通过审核并上线发布
- ✅ 独立完成 3 个可交付的完整项目

---

## 课程结构

本课程共 **6 个模块，16 节课 + 3 个实战项目**，总计约 **8-12 小时**：

| 模块 | 内容 | 预计时长 |
|------|------|----------|
| 模块一 | 认识微信小程序（3 课） | 45 分钟 |
| 模块二 | 原生小程序开发（4 课） | 90 分钟 |
| 模块三 | 云开发（4 课） | 90 分钟 |
| 模块四 | 用户体系（3 课） | 75 分钟 |
| 模块五 | 上线（2 课） | 45 分钟 |
| 模块六 | 实战项目（3 个） | 240 分钟 |

---

## 前置条件

- 一台电脑（Windows / macOS / Linux 均可）
- 微信开发者工具（免费）
- 一个已注册的小程序账号（模块一教你注册）
- 不需要任何编程基础——课程用 AI 生成代码，你只需要会描述需求
