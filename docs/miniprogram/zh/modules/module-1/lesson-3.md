# 第 3 课：注册、备案与开发工具配置

## 3.1 注册小程序账号

1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com)，点击"立即注册"
2. 选择"小程序"，填写邮箱（一个邮箱只能注册一次）
3. 选择主体类型：
   - **个人**：免费，但**不能开通微信支付**，类目有限（不能做电商、金融、医疗等）
   - **企业**：300 元/年认证费，功能完整，可接入微信支付
4. 完成主体信息填写（企业需营业执照）
5. 等待微信审核（通常 1 个工作日内）

> **建议**：有变现需求选企业主体；纯学习/练手可用个人主体。

## 3.2 ICP 备案（2023 年起必须）

所有小程序上线前必须完成 ICP 备案：

1. 在微信公众平台"设置" → "备案"入口发起
2. 填写主体信息、域名（使用微信分配的域名）
3. 上传身份证 / 营业执照照片
4. 工信部审核 5-20 个工作日
5. 备案通过前，小程序处于"开发中"状态，不能发布上线

> 备案期间可以正常开发，只是不能发布。

## 3.3 安装配置开发工具

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 安装后登录微信号
3. 点击"导入项目" → 填写 AppID（注册后在"设置"页面找到）
4. 创建项目目录，开发者工具会生成初始模板

## 3.4 合法域名配置

小程序请求数据只能访问已备案的 **HTTPS 域名**（白名单）：

1. 在"设置" → "开发" → "开发管理" → "服务器域名"
2. 填入你的 API 域名（需完成 ICP 备案 + SSL 证书）
3. 云开发域名自动配置，无需手动添加

> 本地调试可以勾选"不校验合法域名"，但上线前必须配置好。

---

**小结**：注册 1 天，备案 5-20 天。备案期间可以开发，上线前完成即可。开发工具配置 10 分钟搞定。
