# FAQ

## 开发工具

**Q：微信开发者工具支持哪些系统？**
A：Windows / macOS / Linux（Linux 版为 Beta，功能略有滞后）。推荐 macOS 或 Windows，审核体验最完整。

**Q：开发工具版本和基础库版本关系？**
A：基础库是微信客户端的版本，开发工具可模拟不同基础库版本。提审时填的"最低基础库版本"决定哪些用户可访问。

**Q：真机预览和模拟器差异？**
A：模拟器不支持定位、扫码、陀螺仪等系统 API，这些功能必须真机预览。

## 云开发

**Q：云开发有免费额度吗？**
A：有。基础版免费额度包括：云函数调用 50 万次/月、云数据库 2GB、云存储 5GB。小型工具类小程序通常够用。

**Q：云开发数据能导出吗？**
A：可以。控制台 → 数据库 → 导出 JSON；云存储文件可单独下载。导出后迁移到自建数据库需手动转换 schema。

**Q：云函数可以同时连多个数据库吗？**
A：云函数通过 `cloud.database()` 连接云开发数据库；通过 `wx.cloud.callFunction` 可调用其他云函数实现跨环境，但建议保持单环境设计。

## 支付与用户

**Q：个人主体能接入微信支付吗？**
A：不能。微信支付要求企业主体，需营业执照 + 对公账户。

**Q：openid 和 unionid 什么时候用哪个？**
A：单小程序用 openid；多产品（小程序 + H5 + 公众号）统一身份用 unionid（需绑定微信开放平台）。

**Q：订阅消息和模板消息区别？**
A：2020 年起模板消息升级为订阅消息。订阅消息需用户每次授权，一次性发送；无需用户授权的场景（如服务通知）走服务通知通道，但限制更多。

## 审核与上线

**Q：个人主体能提审社交/社区类小程序吗？**
A：不能。社交、电商、教育、医疗等类目要求企业主体。个人主体可提审工具、信息查询类。

**Q：被驳回了怎么办？**
A：按驳回原因修改后重新提审，不保留排队位置。建议每次提审前自查 15 课清单，一次通过率最高。

**Q：灰度发布什么时候用？**
A：高风险功能更新（新支付逻辑、新数据模型）先用 10% 灰度，观察 24-48 小时无异常后再放量。

## 性能

**Q：小程序包大小限制？**
A：单个小程序主包 2MB，总包（含分包）20MB。超限会被拒绝发布，需分包加载或云端资源。

**Q：setData 性能瓶颈？**
A：`setData` 每次调用序列化 + 通信到渲染层，频繁调用导致卡顿。减少 `setData` 调用次数（合并多个字段），大数组只更新需要的部分。
