# 第 15 课：画质修复与放大

> 📌 **学习目标**：学会对生成图片进行画质修复和超分辨率放大
> ⏱️ **预计时长**：20 分钟
> 🎯 **本节节奏**：放大原理 → 实操方法 → 质量评估

---

## 一、为什么要放大？

ComfyUI 默认生成尺寸有限（通常 512-1024px），但发布到短视频平台需要更高清晰度。

```
生成尺寸 vs 发布需求：
┌──────────────┬──────────────┬─────────────────┐
│ 用途          │ 所需分辨率    │ ComfyUI 默认     │
├──────────────┼──────────────┼─────────────────┤
│ 手机屏幕预览   │ 720×1280     │ 可能不够         │
│ 抖音发布      │ 1080×1920    │ 需要放大         │
│ 印刷输出      │ 3000×5000+   │ 必须放大         │
└──────────────┴──────────────┴─────────────────┘
```

## 二、放大方法对比

### 方法 1：Ultimate SD Upscale（推荐）⭐

```
原理：先放大 latent 空间，再用低 denoise 重新生成细节

优点：
- 保持原始构图不变
- 自动补充细节
- 不会像简单插值那样模糊

缺点：
- 需要较长时间
- 需要较多显存
```

**操作步骤：**
```
1. 安装 "ComfyUI-UIptimizer" 或 "Ultimate SD Upscale" 节点
2. 将生成的图片连接到 Upscale 节点
3. 设置参数：
   - upscale_by: 2.0（放大 2 倍）
   - mask_blur: 0（不需要蒙版）
   - denoise: 0.3-0.4（只添加细节，不改变内容）
   - steps: 20
   - cfg: 7
4. 运行，等待放大完成
```

### 方法 2：4x-UltraSharp（纯放大）

```
原理：使用专门的超分辨率模型直接放大

优点：
- 速度快
- 效果锐利

缺点：
- 不添加新细节
- 可能引入伪影
```

**操作步骤：**
```
1. 下载 4x-UltraSharp 模型到 models/upscaling/
2. 添加 "Image Upscale with Model" 节点
3. 选择 4x-UltraSharp 模型
4. 连接图片，运行
```

### 方法 3：Hires. Fix（高分辨率修复）

```
原理：先生成低分辨率草稿，再放大并修复细节

优点：
- 质量最好
- 细节丰富

缺点：
- 速度较慢
- 需要更多显存
```

## 三、人脸修复

放大后的人脸可能不够清晰，需要额外修复。

### ADetailer 修复

```
1. 确保已安装 ADetailer
2. 在 workflow 中添加 ADetailer 节点
3. 设置：
   - ad_model: face_yolov8
   - denoise: 0.3-0.4
   - dpoe: 0.4
4. 运行，人脸会自动修复
```

### 专用人脸修复节点

```
1. 安装 "FaceDetailer" 节点（Impact Pack 自带）
2. 连接到图片输出
3. 自动检测并修复人脸
4. 可选：同时修复手部
```

---

## 四、完整后期流程

```
生成原图 → 放大 → 人脸修复 → 质量检查 → 保存

具体操作：
1. 生成 768×1024 的原图
2. 用 Ultimate SD Upscale 放大到 1536×2048（2倍）
3. 用 FaceDetailer 修复人脸
4. 检查整体效果
5. 如有需要，用 Inpainting 微调局部
6. 保存为 PNG 或高质量 JPG
```

## 五、放大参数参考

| 目标分辨率 | 放大倍数 | denoise | steps | 备注 |
|-----------|---------|---------|-------|------|
| 1080×1920 | 1.5x | 0.3 | 20 | 适合抖音竖屏 |
| 1536×2048 | 2.0x | 0.35 | 25 | 高清输出 |
| 2048×2048 | 2.5x | 0.4 | 30 | 高质量海报 |
