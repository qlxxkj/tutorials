## 一、ComfyUI 是什么？

**ComfyUI** 是一个基于节点的 Stable Diffusion 图像生成工具。

听起来有点抽象？简单理解：

- **Stable Diffusion** = 一个 AI 图像生成模型（大脑）
- **ComfyUI** = 连接这个大脑的"操作台"（界面）

它不像 Midjourney 那样给你一个输入框直接出图，而是让你**用连线的方式搭建图像处理流程**。

```
文本提示词  →  [LLM编码]  →  [去噪]  →  [VAE解码]  →  最终图片
                ↑               ↑            ↑
             CLIP模型        UNet模型     VAE模型
```

在 ComfyUI 里，每一个方框都是一个"节点"，你用线把它们连起来，告诉 AI 每一步该怎么做。

## 二、ComfyUI 的核心特点

### 特点 1：完全本地运行

```
在线工具（Midjourney/即梦）：  图片在别人的服务器上生成
ComfyUI：                     图片在你的电脑上生成
```

**好处：**
- 完全免费，不用花钱买积分
- 不受限流，想生成多少就生成多少
- 隐私安全，不用上传敏感图片

### 特点 2：节点式工作流

在线工具像"填空题"——你写描述，它给你图。

ComfyUI 像"搭积木"——你自己决定每一步怎么处理：

```
你生成的流程可以是：
提示词 → 生成图 → 人脸修复 → 放大4倍 → 输出

也可以是：
参考图 → 提取特征 → 结合新描述 → 生成图 → 控制构图 → 输出
```

每一张图片生成后，你都能看到完整的处理流程，随时调整任何一个环节。

### 特点 3：角色一致性最强

这是 ComfyUI 做 AI 漫剧最大的优势。

通过 **IP-Adapter** 技术，你可以：
1. 上传一张角色参考图
2. 让 AI 把这个角色的脸、发型、服装"记住"
3. 后续所有画面都参考这张图生成

结果：同一个角色在 20 张图里长得几乎一样。

在线工具也能做角色参考，但 ComfyUI 的控制精度更高、可调整的空间更大。

### 特点 4：ControlNet 精确控制

想让角色摆什么姿势？想让画面什么构图？

ComfyUI 的 **ControlNet** 可以精确控制：
- 人物姿势（输入一张姿势图）
- 画面构图（输入边缘图或深度图）
- 颜色风格（输入色调参考图）

## 四、ComfyUI 适合谁？

### 适合 ✅

- 想做 AI 漫剧，需要角色一致性
- 批量生成图片，不想付 API 费用
- 想精确控制画面构图和风格
- 有 NVIDIA 显卡，愿意花一点时间学习

### 不太适合 ❌

- 完全不想装软件、不想碰技术
- 只有 Mac 电脑（ComfyUI 主要支持 NVIDIA GPU）
- 只需要偶尔生成几张图
