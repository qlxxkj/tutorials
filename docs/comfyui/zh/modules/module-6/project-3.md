# 项目三：批量并行生产

> 📌 **学习目标**：掌握批量并行生成技巧，实现高效量产
> ⏱️ **预计时长**：30 分钟
> 🎯 **本节节奏**：并行策略 → 队列管理 → 效率优化 → 生产规划

---

## 一、为什么需要并行生产？

单张图生成需要 10-30 秒。一部 20 镜头的漫剧：
- 串行生成：20 × 20秒 = 7 分钟（不含调试时间）
- 并行生成：可同时运行多个任务，大幅缩短时间

---

## 二、ComfyUI 的并行能力

### 方法 1：多窗口并行

```
打开多个 ComfyUI 窗口（同一实例的不同标签页）
每个窗口运行不同的任务
互不干扰，充分利用显存

注意：确保总显存使用不超 80%
```

### 方法 2：队列管理器

```
1. 安装 Queue Manager 节点
2. 设置最大并行数（如 3）
3. 连续点击多个 Queue Prompt
4. ComfyUI 会自动排队并并行执行
```

### 方法 3：批量生成 + 筛选

```
1. 设置 Batch Size = 4
2. 一次生成 4 张同一场景的变体
3. 挑选最好的
4. 继续下一张

比串行生成快 3-4 倍
```

## 三、批量生产流程

### 流程设计

```
准备阶段（10分钟）：
  1. 加载风格模板
  2. 上传角色参考图
  3. 准备好所有分镜的提示词

执行阶段（并行生成）：
  Batch 1: 镜头 1-4  →  同时生成 4 张
  Batch 2: 镜头 5-8  →  同时生成 4 张
  Batch 3: 镜头 9-12 →  同时生成 4 张
  ...

后处理阶段（10分钟）：
  1. 批量放大所有图片
  2. 批量人脸修复
  3. 命名和排序
```

### 提示词准备模板

```
将剧本转换为提示词列表：

镜头1: [固定角色描述], [场景1], [动作1], [情绪1]
镜头2: [固定角色描述], [场景2], [动作2], [情绪2]
镜头3: [固定角色描述], [场景3], [动作3], [情绪3]
...

其中 [固定角色描述] 保持不变，只有场景/动作/情绪变化
```

## 四、显存管理

### 显存监控

```
在 ComfyUI 界面底部可以看到显存使用情况。
确保不超过 80% 的显存容量。

RTX A4000 16GB：
  - 安全并行数：3-4 个任务
  - 最高并行数：5 个任务
  - 超出会 OOM（显存溢出）报错
```

### 显存不足时的解决方案

```
方案 A：降低分辨率
  从 768×1024 降到 512×768

方案 B：降低并行数
  同时只跑 2 个任务

方案 C：使用 --lowvram 参数启动
  编辑 run_nvidia_gpu.bat，添加 --lowvram

方案 D：分批生成
  先生成前半部分，清理显存，再生成后半部分
```

## 五、本章小结

| 策略 | 适用场景 | 效率提升 |
|------|---------|---------|
| Batch 批量 | 同一场景多变体 | 3-4x |
| 多窗口并行 | 不同场景同时生成 | 2-3x |
| 队列管理 | 大量任务自动排队 | 节省等待时间 |
| 显存优化 | 显存不足时 | 保证稳定运行 |

**核心原则**：在保证质量的前提下，尽可能提高并行度。
