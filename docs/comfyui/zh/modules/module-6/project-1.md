# 项目一：搭建个人图像生产工作流

> 📌 **学习目标**：将所学整合为一套完整、可复用的图像生产工作流
> ⏱️ **预计时长**：40 分钟
> 🎯 **本节节奏**：需求分析 → 工作流设计 → 搭建测试 → 优化迭代

---

## 一、项目目标

搭建一套完整的 ComfyUI 工作流，能够：
1. 导入角色参考图，保持角色一致
2. 根据分镜提示词批量生成画面
3. 自动进行画质放大和人脸修复
4. 一键保存所有输出图片

---

## 二、工作流设计

### 模块分解

```
┌──────────────────────────────────────────────────────┐
│                  角色参考模块                         │
│  Load Image (角色图) → IPAdapter Apply               │
└──────────────────────────┬───────────────────────────┘
                           │
┌──────────────────────────▼───────────────────────────┐
│                  提示词模块                           │
│  CLIP Text Encode (正)                               │
│  CLIP Text Encode (负)                               │
└──────────────────────────┬───────────────────────────┘
                           │
┌──────────────────────────▼───────────────────────────┐
│                  核心生成模块                         │
│  Empty Latent Image → KSampler → VAE Decode         │
└──────────────────────────┬───────────────────────────┘
                           │
┌──────────────────────────▼───────────────────────────┐
│                  后处理模块                           │
│  Ultimate SD Upscale → FaceDetailer → Save Image     │
└──────────────────────────────────────────────────────┘
```

---

## 三、搭建步骤

### Step 1：搭建基础生成流程

```
1. 添加 Checkpoint Loader，选择动漫模型
2. 添加两个 CLIP Text Encode（正/负）
3. 添加 Empty Latent Image（768×1024）
4. 添加 KSampler（steps=28, cfg=7.5, euler_ancestral）
5. 添加 VAE Decode
6. 添加 Save Image
7. 按基础工作流连线
```

### Step 2：添加 IP-Adapter 角色一致性

```
1. 添加 IPAdapter Apply 节点
2. 添加 Load Image 节点（用于导入角色参考图）
3. 连接：
   Load Image.image → IPAdapter Apply.image
   IPAdapter Apply.output → KSampler.positive
4. 设置 ipadapter_file 和 weight（0.85）
```

### Step 3：添加放大和后处理

```
1. 添加 "Ultimate SD Upscale" 节点
2. 连接：
   VAE Decode.output → Ultimate SD Upscale.input_image
3. 设置放大参数：
   - upscale_by: 2.0
   - denoise: 0.35
4. 添加 "FaceDetailer" 节点
5. 连接放大后的图片到 FaceDetailer
6. 添加 Save Image 保存最终结果
```

### Step 4：测试运行

```
1. 上传一张角色参考图
2. 输入提示词
3. 点击 Queue Prompt
4. 检查输出图片质量和一致性
```

## 四、批量生成设置

### 方法：使用 Queue Manager

```
1. 安装 Queue Manager 节点
2. 添加后连接到工作流
3. 设置批量数量（如 10）
4. 点击 Queue Prompt 多次或一次提交多个任务
```

### 批量提示词管理

```
建议方式：
1. 将提示词写在一个文本文件中
2. 每个分镜一行
3. 逐个复制粘贴到 CLIP Text Encode 节点
4. 或用批量节点自动读取提示词文件
```

---

## 五、保存与分享

### 保存工作流

```
菜单 → Workflow → Save
→ 保存为 .json 文件
→ 文件名：图像生产流_v1.json
```

### 分享工作流

```
将 .json 文件分享给其他人：
1. 对方导入你的 .json 文件
2. 如果有缺失节点，会提示安装
3. 如果有缺失模型，会提示下载
4. 即可直接使用
```
